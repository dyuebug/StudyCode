📚 核心概念

什么是ES6+？

ES6（ECMAScript 2015）是JavaScript的重大更新，引入了大量新特性。ES6+指ES6及之后版本的统称。

为什么学习ES6+？

  • 现代标准：现代前端开发的必备技能
  • 代码简洁：用更少的代码完成同样的功能
  • 可读性强：代码意图更清晰
  • 框架必备：React、Vue都大量使用ES6+
  • 面试必考：高频考点

核心特性列表

  1. let/const 块级作用域
  2. 箭头函数

1️⃣ let/const - 块级作用域 ⭐⭐⭐⭐⭐

【概念卡片】

var的问题：

  • 函数作用域（不是块级作用域）
  • 变量提升（hoisting）
  • 可以重复声明

let/const的优势：

  • 块级作用域（{}内有效）
  • 无变量提升（必须先声明后使用）
  • 不能重复声明
  • const声明的是常量（不能重新赋值）

示例：作用域对比

⚠️ 重要区别：

  • let：可以重新赋值
  • const：不能重新赋值（但对象/数组的内容可以修改）

2️⃣ 箭头函数 ⭐⭐⭐⭐⭐

【函数卡片】

语法：

// 传统函数
function add(a, b) {
    return a + b;
}

// 箭头函数
const add = (a, b) => a + b;

简写规则：

  • 单个参数：括号可省略 x => x * 2
  • 单行返回：花括号和return可省略 (a, b) => a + b
  • 返回对象：用括号包裹 () => ({ name: 'Tom' })

this绑定：

  • 传统函数：this取决于调用方式
  • 箭头函数：this继承外层作用域（词法作用域）

3️⃣ 解构赋值 ⭐⭐⭐⭐⭐

【概念卡片】

什么是解构赋值？

从数组或对象中提取值，赋给变量的简洁语法。

数组解构：

const [a, b, c] = [1, 2, 3];  // a=1, b=2, c=3

对象解构：

const { name, age } = { name: 'Tom', age: 25 };  // name='Tom', age=25

4️⃣ 展开运算符（...） ⭐⭐⭐⭐⭐

【概念卡片】

作用：将数组或对象"展开"成独立的元素

数组展开：

const arr1 = [1, 2, 3];
const arr2 = [...arr1, 4, 5];  // [1, 2, 3, 4, 5]

对象展开：

const obj1 = { a: 1, b: 2 };
const obj2 = { ...obj1, c: 3 };  // { a: 1, b: 2, c: 3 }

常见用途：

  • 复制数组/对象（浅拷贝）
  • 合并数组/对象
  • 函数参数传递

示例：展开运算符

5️⃣ 模板字符串 ⭐⭐⭐⭐

【概念卡片】

语法：使用反引号（`）代替引号

const name = 'Tom';
const greeting = `Hello, ${name}!`;  // Hello, Tom!

特点：

  • 支持变量插值：${变量}
  • 支持表达式：${1 + 1}
  • 支持多行字符串
  • 可以嵌套模板

示例：模板字符串

6️⃣ 默认参数和剩余参数 ⭐⭐⭐⭐

【概念卡片】

默认参数：函数参数可以设置默认值

function greet(name = 'Guest') {
    return `Hello, ${name}!`;
}

剩余参数（...args）：收集多余参数为数组

function sum(...numbers) {
    return numbers.reduce((a, b) => a + b, 0);
}

示例：默认参数和剩余参数

7️⃣ 对象简写 ⭐⭐⭐⭐

【概念卡片】

属性简写：变量名和属性名相同时可简写

const name = 'Tom';
const age = 25;

// 传统写法
const user = { name: name, age: age };

// 简写
const user = { name, age };

方法简写：对象方法可以省略: function

const obj = {
    // 传统写法
    sayHi: function() { return 'Hi'; },
    // 简写
    sayHello() { return 'Hello'; }
};

示例：对象简写

⚠️ 常见错误和陷阱

错误1：const不是真正的常量

❌ 误解：const声明的变量完全不可变

✅ 真相：const保证变量指向的地址不变，但对象/数组的内容可以修改

const arr = [1, 2, 3];
arr.push(4);  // ✅ 可以修改内容
arr = [5, 6];  // ❌ 报错！不能重新赋值

错误2：箭头函数没有this

❌ 错误使用：在需要动态this的场景用箭头函数

const btn = document.querySelector('button');
btn.addEventListener('click', () => {
    console.log(this);  // ❌ this不是btn，而是外层作用域的this
});

✅ 正确：需要动态this时用传统函数

错误3：解构时变量名必须匹配

❌ 错误代码：

const { userName } = { name: 'Tom' };  // userName是undefined

✅ 正确写法：

const { name: userName } = { name: 'Tom' };  // userName='Tom'

错误4：展开运算符是浅拷贝

⚠️ 陷阱：嵌套对象不会深拷贝

const obj1 = { a: 1, b: { c: 2 } };
const obj2 = { ...obj1 };
obj2.b.c = 999;  // obj1.b.c也变成999！
