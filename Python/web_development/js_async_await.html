什么是async/await？

async/await是ES2017引入的语法糖，让异步代码看起来像同步代码，更易读易写。

核心要点：

  • async函数总是返回Promise
  • await只能在async函数内使用
  • await会暂停函数执行，等待Promise完成
  • 是Promise的语法糖，本质还是Promise

1️⃣ async函数基础 ⭐⭐⭐⭐⭐

语法：

async function 函数名() {
    return 值;  // 自动包装成Promise
}

特点：

  • async函数总是返回Promise
  • return值会被Promise.resolve()包装
  • 抛出错误会被Promise.reject()包装

示例：async函数

2️⃣ await关键字 ⭐⭐⭐⭐⭐

语法：

const result = await promise;

作用：

  • 等待Promise完成
  • 返回Promise的结果值
  • 只能在async函数内使用

示例：await用法

3️⃣ 错误处理 ⭐⭐⭐⭐⭐

try/catch：

async function fn() {
    try {
        const result = await promise;
    } catch (error) {
        // 处理错误
    }
}
