📚 核心概念

什么是数组高级方法？

数组高级方法是JavaScript内置的一组强大的数组操作函数，用于处理和转换数组数据。

为什么需要数组高级方法？

  • 简化代码：用一行代码替代多行循环
  • 提高可读性：方法名清晰表达意图（map=映射、filter=过滤）
  • 函数式编程：不改变原数组，返回新数据
  • 链式调用：多个方法连续调用，代码优雅
  • 面试必考：JavaScript开发者必备技能

核心特点

✅ 函数式编程风格
  • 不修改原数组（immutable）
  • 返回新数组或新值
  • 可以链式调用
  • 代码更简洁、更易测试

1️⃣ map() - 映射转换 ⭐⭐⭐⭐⭐

【函数卡片】

函数名：array.map()

作用：对数组每个元素执行函数，返回新数组

类型：数组实例方法

完整语法：

array.map((element, index, array) => { return newValue })

参数详解：

  • element（必需）：当前遍历的元素
  • index（可选）：当前元素的索引
  • array（可选）：原数组本身

返回值：新数组（长度与原数组相同）

特点：

  • 不改变原数组
  • 新数组长度 = 原数组长度
  • 每个元素都会被转换

2️⃣ filter() - 筛选过滤 ⭐⭐⭐⭐⭐

【函数卡片】

函数名：array.filter()

作用：筛选出符合条件的元素，返回新数组

完整语法：

array.filter((element, index, array) => { return 布尔值 })

返回值：新数组（只包含符合条件的元素）

特点：

  • 回调函数返回true，元素保留
  • 回调函数返回false，元素过滤掉
  • 新数组长度 ≤ 原数组长度

3️⃣ reduce() - 累积计算 ⭐⭐⭐⭐⭐

【函数卡片】

函数名：array.reduce()

作用：将数组累积计算为单个值

完整语法：

array.reduce((accumulator, current, index, array) => { return newAccumulator }, initialValue)

参数详解：

  • accumulator（累加器）：上一次回调的返回值
  • current（当前值）：当前遍历的元素
  • index（可选）：当前索引
  • array（可选）：原数组
  • initialValue（初始值）：第一次调用时的accumulator值

返回值：单个值（数字、字符串、对象等）

工作原理：

  1. 第1次：accumulator = initialValue，current = 数组第1个元素
  2. 第2次：accumulator = 第1次返回值，current = 数组第2个元素
  3. 第3次：accumulator = 第2次返回值，current = 数组第3个元素
  4. ...依此类推
  5. 最后返回最终的accumulator

5️⃣ 链式调用 ⭐⭐⭐⭐⭐

什么是链式调用？

将多个数组方法连续调用，每个方法的返回值作为下一个方法的输入。

为什么使用链式调用？

  • 代码更简洁优雅
  • 逻辑更清晰（数据流式处理）
  • 避免中间变量
  • 函数式编程风格

⚠️ 常见错误和陷阱

错误1：忘记return

❌ 错误代码：

const doubled = [1, 2, 3].map(n => { n * 2 });  // [undefined, undefined, undefined]

原因：使用了花括号{}，但没有return语句

✅ 正确代码：

const doubled = [1, 2, 3].map(n => n * 2);  // 简写形式，自动return
// 或
const doubled = [1, 2, 3].map(n => { return n * 2; });  // 完整形式

错误2：混淆map和forEach

❌ 错误思维：forEach会返回新数组

真相：

  • forEach：无返回值（undefined），用于执行副作用（打印、修改外部变量）
  • map：返回新数组，用于数据转换

错误3：reduce忘记初始值

⚠️ 危险代码：

[].reduce((a, b) => a + b);  // 报错！空数组没有初始值

✅ 安全写法：

[].reduce((a, b) => a + b, 0);  // 返回0，不报错

错误4：filter条件写错

❌ 错误代码：

const adults = users.filter(user => user.age);  // 过滤掉age为0的人

✅ 正确代码：

const adults = users.filter(user => user.age >= 18);  // 明确条件
