📚 核心概念

什么是Fetch API？

Fetch是浏览器提供的现代HTTP请求API，用于替代传统的XMLHttpRequest，基于Promise设计。

特点：

  • 基于Promise，支持async/await
  • 语法简洁，易于使用
  • 支持跨域请求（CORS）
  • 功能强大，支持各种HTTP方法

1️⃣ GET请求 ⭐⭐⭐⭐⭐

基本语法：

const response = await fetch(url);
const data = await response.json();

示例：获取用户列表

2️⃣ POST请求 ⭐⭐⭐⭐⭐

基本语法：

const response = await fetch(url, {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json'
    },
    body: JSON.stringify(data)
});

示例：创建新用户

3️⃣ 错误处理 ⭐⭐⭐⭐⭐

重要提示：

  • fetch只在网络错误时reject
  • HTTP错误（404、500等）不会reject
  • 需要检查response.ok属性
