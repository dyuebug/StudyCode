# Web 开发教程页面（web_development）

> 对应第 43～45 天的 JavaScript 与综合页面材料。全部为静态 HTML，无需构建。

## 文件

| 文件 | 主题 |
|---|---|
| `js_advanced_arrays.html` | 数组高级方法（map/filter/reduce/find/some/every） |
| `js_async_basics.html` | 同步与异步、事件循环、宏任务与微任务、回调 |
| `js_promise.html` | Promise 状态、链式调用、错误处理 |
| `js_async_await.html` | async/await、串行与并行、异常捕获 |
| `js_fetch_api.html` | Fetch、GET/POST、错误处理 |
| `js_es6_features.html` | ES6 语法特性 |
| `message_board_v5_modern_js.html` | 留言板 v5 前端示例 |

## 打开方式

直接双击任意 HTML 即可。

涉及 `fetch` 的页面如果请求本地 API，需要先启动对应后端（留言板 v4 默认端口 5000），否则会看到网络错误——这是预期行为，不是页面缺陷。

## 学习建议

1. 打开浏览器开发者工具（F12），在 Console 中观察输出。
2. 修改示例代码后刷新页面，对比结果。
3. 异步相关页面重点观察任务执行顺序，而不是只记结论。
