📚 核心概念

什么是Promise？

Promise是JavaScript中处理异步操作的对象，代表一个异步操作的最终完成（或失败）及其结果值。

为什么需要Promise？

Promise解决的问题：

  • 回调地狱：Promise用链式调用代替嵌套回调
  • 错误处理：统一的catch()捕获错误
  • 代码可读性：扁平化结构，更易理解
  • 并行控制：Promise.all()等方法简化并行操作

Promise的三种状态

pending（进行中）
    ↓
    ├─→ fulfilled（已成功）resolve(value)
    │
    └─→ rejected（已失败）reject(error)

✅ 状态只能改变一次
✅ 状态改变后不可逆

1️⃣ 创建Promise ⭐⭐⭐⭐⭐

【语法卡片】

基本语法：

const promise = new Promise((resolve, reject) => {
    // 异步操作
    if (成功) {
        resolve(结果值);  // 状态变为fulfilled
    } else {
        reject(错误信息);  // 状态变为rejected
    }
});

参数说明：

  • resolve：成功时调用，传递结果值
  • reject：失败时调用，传递错误信息

示例：创建Promise

2️⃣ then / catch / finally ⭐⭐⭐⭐⭐

【方法卡片】

then(onFulfilled, onRejected)：

  • 第一个参数：成功时的回调
  • 第二个参数（可选）：失败时的回调
  • 返回新的Promise，支持链式调用

catch(onRejected)：

  • 捕获Promise链中的错误
  • 等同于 then(null, onRejected)
  • 推荐用catch而不是then的第二个参数

finally(onFinally)：

  • 无论成功或失败都会执行
  • 不接收参数
  • 用于清理操作（如关闭加载动画）

示例：then/catch/finally

3️⃣ Promise链式调用 ⭐⭐⭐⭐⭐

【核心概念】

链式调用原理：

  • then()返回新的Promise
  • 可以连续调用多个then()
  • 上一个then的返回值传给下一个then
  • 扁平化代码，避免回调地狱

示例：用Promise改写回调地狱

4️⃣ Promise静态方法 ⭐⭐⭐⭐

【方法列表】

Promise.all([p1, p2, p3])：

  • 并行执行多个Promise
  • 全部成功才成功，返回结果数组
  • 任意一个失败就失败

Promise.race([p1, p2, p3])：

  • 竞速，返回最快完成的结果
  • 无论成功或失败

Promise.allSettled([p1, p2, p3])：

  • 等待所有Promise完成（无论成功或失败）
  • 返回状态数组

Promise.resolve(value)：

  • 返回成功的Promise

Promise.reject(error)：

  • 返回失败的Promise

示例：Promise.all()
