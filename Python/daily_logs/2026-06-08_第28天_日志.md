## 📖 学到的知识点

### Jinja2 模板
1. **变量渲染**：`{{ 变量名 }}` 输出变量值，自动 HTML 转义防 XSS
2. **循环**：`{% for item in list %}...{% endfor %}`，`loop.index` 获取序号
3. **条件**：`{% if %}...{% elif %}...{% else %}...{% endif %}`
4. **过滤器**：`{{ name|upper }}`、`{{ score|round(1) }}`、`{{ list|length }}`
5. **模板继承**：`{% extends 'base.html' %}`、`{% block 内容 %}{% endblock %}`
6. **render_template_string()**：直接渲染字符串模板，开发学习时无需外部文件

### Flask + SQLite
1. **数据库初始化**：`CREATE TABLE IF NOT EXISTS` 避免重复建表
2. **连接管理**：`with sqlite3.connect(db_path) as conn` 自动提交/关闭
3. **参数化查询**：`cursor.execute(sql, (值,))` 防止 SQL 注入
4. **PRG 模式**：POST 后 redirect，防止刷新重复提交
5. **数据持久化**：SQLite 文件存储，重启后数据不丢失
6. **路径处理**：`os.path.dirname(__file__)` 确保数据库路径正确
