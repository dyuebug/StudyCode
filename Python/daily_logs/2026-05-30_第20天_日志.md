## 📖 学到的知识点

### 上下文管理器
1. **with 语句原理**：调用 `__enter__` 进入，调用 `__exit__` 退出，无论是否异常
2. **__enter__**：进入 with 块时执行，返回值赋给 as 变量
3. **__exit__ 参数**：`exc_type, exc_val, exc_tb`，无异常时全为 None
4. **吞掉异常**：`__exit__` 返回 True 则异常不再传播
5. **@contextmanager**：用生成器函数简化上下文管理器，yield 前=__enter__，yield 后=__exit__
6. **try/finally**：contextmanager 中必须用 try/finally 确保清理代码执行

### 迭代器协议
1. **可迭代对象**：实现了 `__iter__` 方法，可以用 for 循环遍历
2. **迭代器**：同时实现 `__iter__` 和 `__next__`，`__iter__` 返回自身
3. **StopIteration**：`__next__` 没有更多元素时抛出此异常，for 循环据此停止
4. **iter() / next()**：内置函数，手动驱动迭代器
5. **生成器是迭代器**：生成器自动实现了迭代器协议
6. **一次性**：迭代器耗尽后不能重置，需重新创建
