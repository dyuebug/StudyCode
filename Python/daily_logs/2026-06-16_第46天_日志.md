### 五、事件处理高级技巧 ⭐⭐⭐⭐⭐

**1. 事件委托（Event Delegation）**
```javascript
// 在父元素监听
this.elements.taskList.addEventListener('click', (e) => {
    // 判断点击的是哪个子元素
    if (e.target.classList.contains('task-delete')) {
        const id = e.target.dataset.id;
        this.deleteTask(id);
    }
});
```
- **原理**：利用事件冒泡机制
- **优势**：
  1. 只需一个事件监听器（性能更好）
  2. 动态添加的元素自动有事件
  3. 代码更简洁

**2. DOM元素缓存**
```javascript
constructor() {
    // 缓存DOM查询（提升性能）
    this.elements = {
        taskInput: document.getElementById('taskInput'),
        addTaskBtn: document.getElementById('addTaskBtn'),
        taskList: document.getElementById('taskList')
    };
}
```
- **避免重复查询**：DOM查询开销较大
- **提升性能**：查询一次，多次使用

**3. 自定义data属性**


- **data-***：自定义数据属性

### 六、LocalStorage数据持久化 ⭐⭐⭐⭐⭐

**1. LocalStorage核心API**
```javascript
// 保存数据
localStorage.setItem(key, value);

// 读取数据
const data = localStorage.getItem(key);

// 删除数据
localStorage.removeItem(key);

// 清空所有
localStorage.clear();
```

**2. JSON序列化与反序列化**
```javascript
// 保存对象（序列化）
const tasks = [{id: 1, text: "任务"}];
localStorage.setItem('tasks', JSON.stringify(tasks));

// 读取对象（反序列化）
const tasksJSON = localStorage.getItem('tasks');
const tasks = JSON.parse(tasksJSON);
```
- **JSON.stringify()**：对象 → JSON字符串
- **JSON.parse()**：JSON字符串 → 对象
- **必须转换**：LocalStorage只能存字符串

**3. 错误处理**
```javascript
static loadTasks() {
    try {
        const tasksJSON = localStorage.getItem(this.STORAGE_KEY);
        
        if (!tasksJSON) {
            return [];  // 没有数据，返回空数组
        }
        
        const tasks = JSON.parse(tasksJSON);
        
        // 验证数据格式
        if (!Array.isArray(tasks)) {
            return [];
        }
        
        return tasks;
    } catch (error) {
        console.error('加载失败:', error);
        return [];  // 出错返回空数组（降级方案）
    }
}
```
- **try/catch**：捕获异常
- **数据验证**：防止数据损坏
- **降级方案**：出错时返回默认值

**4. LocalStorage特点**

**优点**：
- 简单易用（只有4个API）
- 数据持久化（浏览器关闭后仍存在）
- 无需服务器（纯前端存储）
- 同源共享（同域名下页面共享数据）

**缺点**：
- 容量有限（5-10MB）
- 只能存字符串（需要序列化）
- 同步API（大数据可能阻塞）
- 不够安全（不适合存敏感信息）

**适用场景**：
- 用户偏好设置
- 简单数据缓存
- 离线应用数据
- 购物车数据

### 七、设计模式应用 ⭐⭐⭐⭐⭐

**1. 单一职责原则（SRP）**
```javascript
// Storage类：只负责数据存储
class Storage {
    static saveTasks() { }
    static loadTasks() { }
}

// TodoApp类：只负责业务逻辑

    addTask() { }
    deleteTask() { }
    render() { }
}
```
- **原则**：一个类只做一件事
- **优势**：代码清晰，易于维护

**2. 数据驱动UI**
```javascript
// 流程：用户操作 → 更新数据 → 保存 → 渲染UI
addTask(text) {
    this.tasks.push(task);     // 1. 更新数据
```

- **优势**：数据和UI始终同步

**3. 模块化设计**
```
项目结构：
├── storage.js    → 数据持久化模块
├── app.js        → 应用逻辑模块
├── style.css     → 样式模块

```
- **职责分离**：每个文件负责一块功能
- **代码复用**：模块可以在其他项目使用
- **易于维护**：修改一个模块不影响其他

### 八、安全防护 ⭐⭐⭐⭐

**XSS防护（跨站脚本攻击）**
```javascript
// 转义HTML特殊字符
escapeHTML(text) {
    const div = document.createElement('div');
    div.textContent = text;  // textContent自动转义
    return div.innerHTML;
}

// 使用
const safeText = this.escapeHTML(userInput);
```

**为什么需要？**
```javascript
// 用户输入：<script>alert('XSS')</script>

// 不转义（危险）：
innerHTML = `<span>${userInput}</span>`;  // 脚本会执行！

// 转义后（安全）：
innerHTML = `<span>${escapeHTML(userInput)}</span>`;
// 显示为文本：<script>alert('XSS')</script>
```
