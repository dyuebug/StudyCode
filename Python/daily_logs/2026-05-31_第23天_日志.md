## 📖 学到的知识点

### zipfile 模块
1. **创建 ZIP 文件**：
   - 模式：'w'（写入）、'a'（追加）、'r'（读取）
   - 压缩级别：ZIP_STORED（不压缩）、ZIP_DEFLATED（标准压缩）
   - arcname 参数：指定压缩包内的文件名
2. **读取 ZIP 文件**：
   - namelist()：列出所有文件
   - getinfo()：获取文件信息（大小、压缩率）
   - read()：读取文件内容
3. **解压 ZIP 文件**：
   - extractall()：解压所有文件
   - extract()：解压单个文件
4. **常见错误**：忘记用 with 语句、路径问题（需要 arcname）

### hashlib 模块
1. **哈希算法**：
   - MD5（128位）：快速，不安全
   - SHA-1（160位）：已被破解
   - SHA-256（256位）：推荐，安全性高
   - SHA-512（512位）：最安全
2. **计算文件哈希**：
   - 分块读取（8192字节）：适合大文件
   - hexdigest()：返回十六进制字符串
3. **哈希的应用**：
   - 文件完整性校验
   - 检测文件变化
   - 去重（相同内容哈希相同）
   - 密码存储
4. **常见错误**：忘记用二进制模式（'rb'）、大文件一次性读入内存

### 数据备份工具项目
1. **BackupTool 类**：
   - full_backup()：完整备份（压缩所有文件）
   - incremental_backup()：增量备份（只备份修改的文件）
   - restore()：恢复备份
   - verify()：验证文件完整性
2. **元数据管理**：
   - 使用 JSON 存储文件哈希、大小、修改时间、备份文件名
   - _load_metadata() 和 _save_metadata()
3. **增量备份原理**：
   - 计算当前文件哈希值
   - 对比元数据中的哈希值
   - 哈希不同 = 文件已修改
   - 只备份修改和新增的文件
4. **命令行接口**：
   - full 子命令：完整备份
   - incremental 子命令：增量备份
   - restore 子命令：恢复备份
   - verify 子命令：验证完整性

## 💭 今日心得

今天用半小时完成了第三个实战项目——数据备份工具。

zipfile 和 hashlib 是数据备份的核心模块。zipfile 用于压缩文件节省存储空间，hashlib 用于计算文件哈希值检测文件变化。两者结合，实现了完整的备份解决方案。

增量备份是这个项目的亮点。通过对比文件哈希值，只备份修改过的文件，大大节省了存储空间和备份时间。这种智能检测文件变化的方式，在实际工作中非常实用。

元数据管理也很重要。使用 JSON 存储每个文件的哈希值、大小、修改时间等信息，不仅可以实现增量备份，还可以验证文件完整性。
