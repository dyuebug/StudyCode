## 📖 学到的知识点

### 调试技巧基础
1. **调试的概念**：调试是发现和修复程序错误（bug）的过程，是软件开发中最重要的技能之一。
2. **调试的黄金法则**：重现问题 → 定位问题 → 理解原因 → 修复问题 → 验证效果。
3. **常见 bug 类型**：语法错误（SyntaxError）、逻辑错误（Logic Error）、运行时错误（RuntimeError）、性能问题（Performance Issue）。

### print 调试技巧
1. **基本方法**：在关键位置打印变量值、类型、长度，观察程序执行流程。
2. **高级技巧**：使用 f-string 格式化输出、添加分隔线和标记、打印位置信息。
3. **优缺点**：简单直接、容易上手，但需要手动添加删除、输出信息混乱、不适合生产环境。

### logging 模块
1. **日志级别**：DEBUG（调试）、INFO（信息）、WARNING（警告）、ERROR（错误）、CRITICAL（严重）。
2. **basicConfig 配置**：设置日志级别、格式、输出文件等。
3. **优势**：可以控制日志级别、输出到文件、自动添加时间戳、不需要删除代码。
4. **使用场景**：print 适合快速调试，logging 适合生产环境和长期使用。

### 调试技巧综合练习
1. **调试计算器**：修复语法错误、除零检查、返回值处理等多个 bug。
2. **数据处理器**：使用 logging 记录所有操作，处理空数据、类型错误等异常。
3. **排序算法调试**：使用 print 调试找出逻辑错误（升序变降序）。
4. **文件读取调试**：使用 logging 记录文件操作，处理文件不存在、格式错误等异常。
5. **性能优化**：从 O(n³) 优化到 O(n)，使用时间测量对比性能。
6. **学生成绩分析系统**：综合运用 print 和 logging，处理复杂业务逻辑。

## 🎯 重要收获

1. **调试能力是程序员的核心竞争力**：写代码只占20%的时间，调试代码占80%的时间。
2. **print 调试简单有效**：适合快速排查问题，在关键位置打印变量值和类型。
3. **logging 模块更专业**：适合生产环境，可以控制日志级别，输出到文件，不需要删除代码。
4. **系统的调试思维**：不要盲目修改代码，先定位问题，理解原因，再修复验证。
5. **学会阅读错误信息**：Python 的错误信息很详细，90%的问题都能从错误信息中找到答案。
