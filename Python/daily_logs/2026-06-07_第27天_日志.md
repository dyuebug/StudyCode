## 📖 学到的知识点

### Flask 基础
1. **应用实例**：`app = Flask(__name__)` 创建应用
2. **路由装饰器**：`@app.route('/路径', methods=['GET','POST'])` 绑定 URL 到函数
3. **路径变量**：`/user/<name>`、`/square/<int:n>` 自动类型转换
4. **request 对象**：`request.args.get()` 获取 GET 参数，`request.form.get()` 获取 POST 表单
5. **响应类型**：返回字符串（HTML）、`jsonify()` 返回 JSON、`redirect()` 重定向
6. **url_for()**：根据函数名生成 URL，避免硬编码路径
7. **调试模式**：`app.run(debug=True)` 开发时自动重载

### Flask Web 应用项目
1. **页面路由**：首页、列表、详情、添加、统计 5 个页面
2. **GET 搜索**：`/students?q=关键词`，用 `request.args.get('q')` 接收
3. **POST 表单**：添加学生，用 `request.form.get()` 接收，验证后存入内存数据
4. **RESTful API**：`GET /api/students`、`POST /api/students`、`GET /api/stats`
5. **状态码**：404（未找到）、400（参数错误）、201（创建成功）
6. **HTML 模板函数**：`render_page()` 统一生成页面结构，避免重复
