## 📖 学到的知识点

### 第三方库基础
1. **第三方库的概念**：第三方库是由 Python 社区开发的扩展包，托管在 PyPI 上，需要额外安装。
2. **PyPI**：Python Package Index，Python 第三方库的官方仓库，托管了超过 40 万个包。
3. **第三方库 vs 标准库**：标准库无需安装，第三方库需要用 pip 安装；标准库功能基础，第三方库功能专业。

### pip 包管理工具
1. **pip 的作用**：Python 的包管理工具，用于安装、卸载、管理第三方库。
2. **常用命令**：pip install（安装）、pip uninstall（卸载）、pip list（查看）、pip freeze（导出依赖）。
3. **国内镜像源**：使用清华、阿里云等镜像源加速下载。

### 虚拟环境（venv）
1. **为什么需要虚拟环境**：不同项目可能需要不同版本的库，虚拟环境隔离依赖，避免版本冲突。
2. **创建和使用**：python -m venv venv 创建，venv\\Scripts\\activate 激活，deactivate 退出。
3. **最佳实践**：每个项目一个虚拟环境，使用 requirements.txt 记录依赖。

### requests 库基础
1. **requests 的作用**：用于发送 HTTP 请求的第三方库，比标准库 urllib 更简单易用。
2. **基本用法**：requests.get() 发送 GET 请求，requests.post() 发送 POST 请求。
3. **响应处理**：response.status_code 查看状态码，response.text 获取文本，response.json() 解析 JSON。
4. **异常处理**：使用 try-except 处理网络错误、超时、HTTP 错误等。

### pandas 库入门
1. **pandas 的作用**：用于数据处理和分析的第三方库，提供类似 Excel 的表格操作。
2. **Series**：带标签的一维数组，可以存储任意类型的数据。
3. **DataFrame**：带标签的二维表格，是 pandas 的核心数据结构。
4. **基本操作**：创建 DataFrame、访问列和行、数据筛选、数据统计。

### 第三方库综合练习
1. **requests 基础使用**：模拟 HTTP 请求，处理响应数据。
2. **pandas 数据处理**：创建 DataFrame、数据筛选、统计分析、排序。
3. **requests + pandas 综合应用**：从 API 获取数据，转换为 DataFrame，进行数据分析。
4. **虚拟环境实践**：完整的虚拟环境创建和使用流程。
5. **错误处理实践**：处理网络错误、超时、HTTP 错误、JSON 解析错误。
6. **pandas 数据清洗**：处理缺失值、删除重复数据、数据类型转换。

## 🎯 重要收获

1. **第三方库是 Python 生态的核心优势**：几乎任何需求都能找到对应的第三方库，大大提高开发效率。
