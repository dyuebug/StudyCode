## 📖 学到的知识点

### 一、JavaScript 基础语法
1. **三件套分工**：HTML(结构) + CSS(样式) + JS(行为)，JS 让网页"动"起来
2. **变量声明**：`let`（可变）、`const`（常量，推荐默认用），语句结尾加分号
3. **数据类型**：Number/String/Boolean/Array/Object，布尔值小写 `true`/`false`
4. **模板字符串**：反引号 + `${变量}`（类比 Python 的 f-string）
5. **函数三写法**：`function`、箭头函数 `() => {}`（最常用）
6. **判断/循环**：`if(){} else if(){}`、`for...of`、逻辑用 `&& || !`
7. **关键安全点**：永远用 `===`（严格相等）而非 `==`

### 二、DOM 操作
1. **DOM 概念**：浏览器把 HTML 解析成"树"，每个标签是一个节点
2. **三步套路**：选中元素 → 操作元素 → 绑定事件
3. **选中**：`getElementById`（不带#）、`querySelector`（CSS语法，万能）
4. **修改**：`textContent`(文字)、`style.xxx`(样式，驼峰)、`classList.toggle`(切换class)
5. **读取输入**：`input.value` 获取用户输入
6. **事件监听**：`addEventListener("click", fn)`，事件名不带 on，函数不加 ()
7. **事件驱动思想**：平时等待，用户触发事件 → 执行对应函数
