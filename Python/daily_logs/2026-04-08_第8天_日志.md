## 📖 学到的知识点

### 模块基础
1. **模块的概念**：模块是一个 Python 文件，用来组织代码、复用功能。
2. **import 导入方式**：掌握了 `import 模块名`、`from 模块名 import 名称`、`import 模块名 as 别名` 三种常见写法。
3. **常用标准库**：学习了 `os`、`math`、`random` 等标准库的基础用途。
4. **模块化思维**：通过拆分功能到不同模块，代码会更清晰、更容易维护。

### 文件操作
1. **open() 函数**：知道了打开文件时需要关注文件模式和编码。
2. **读文件方法**：学习了 `read()`、`readline()`、`readlines()` 的区别。
3. **写文件方法**：学习了 `write()` 和追加写入的基本使用。
4. **with 语句**：理解了 why 推荐使用 `with`，因为它能自动关闭文件，减少出错。
5. **文件模式**：理解了 `r`（读）、`w`（写/覆盖）、`a`（追加）的区别。
6. **编码意识**：知道文本文件通常要指定 `encoding="utf-8"`。

### 综合练习
1. **数据持久化**：通过文件保存学生成绩，理解了“程序关闭后数据还能保留”的意义。
2. **读写结合**：练习了先读取、再分析、再写入结果的完整流程。
3. **基础应用能力**：把模块和文件操作知识结合到了一个小项目里。
