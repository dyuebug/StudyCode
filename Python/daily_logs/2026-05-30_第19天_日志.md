## 📖 学到的知识点

### 装饰器
1. **装饰器的本质**：接收函数、返回新函数的高阶函数
2. **@语法糖**：`@decorator` 等价于 `func = decorator(func)`
3. **functools.wraps**：保留被装饰函数的 `__name__`、`__doc__` 等元信息
4. **处理任意参数**：wrapper 用 `*args, **kwargs` 接收并传递所有参数
5. **带参数的装饰器**：三层嵌套（参数层 → decorator层 → wrapper层）
6. **类装饰器**：实现 `__init__` 和 `__call__` 方法，适合需要维护状态的场景
7. **多个装饰器叠加**：装饰时从下到上，调用时从上到下

### 生成器
1. **yield 关键字**：暂停函数执行，返回值，下次调用从暂停处继续
2. **惰性计算**：生成器不一次性生成所有数据，按需计算，节省内存
3. **生成器表达式**：`(x for x in ...)` 圆括号，惰性；`[x for x in ...]` 方括号，立即生成
4. **生成器只能遍历一次**：耗尽后不能重置，需重新创建
5. **yield from**：委托给另一个可迭代对象，逐个 yield 其元素
6. **数据处理管道**：多个生成器串联，每步惰性处理，内存高效

### 综合应用
1. **日志装饰器**：记录函数调用信息和异常
2. **缓存装饰器**：用字典存储 `{参数: 结果}`，相同参数直接返回缓存
3. **计时装饰器（类实现）**：统计调用次数、总耗时、平均耗时
4. **带参数的重试装饰器**：失败时自动重试指定次数
5. **生成器管道 + 装饰器**：用装饰器给生成器添加日志，构建可观测的数据处理框架
