## 📖 复习内容总结

### 一、面向对象基础回顾

**1. 类和对象**
- 类（Class）：对象的模板/蓝图
- 对象（Object）：类的实例
- 定义类：`class ClassName:`
- 创建对象：`obj = ClassName()`
- 属性：对象的数据
- 方法：对象的行为

**2. __init__() 初始化方法**
- 作用：创建对象时自动调用
- 参数：self + 自定义参数
- 用途：初始化对象属性
- 示例：
  ```python
  class Person:
      def __init__(self, name, age):
          self.name = name
          self.age = age
  ```

**3. self 的作用**
- 代表对象本身
- 第一个参数必须是 self
- 通过 self 访问属性和方法
- 调用时自动传入，不需要手动传

**4. 三种方法类型**
- 实例方法：`def method(self):`
  - 第一个参数是 self
  - 访问实例属性和方法
- 类方法：`@classmethod def method(cls):`
  - 第一个参数是 cls（类本身）
  - 访问类属性，常用于工厂方法
- 静态方法：`@staticmethod def method():`
  - 不需要 self 或 cls
  - 与类相关但不访问类或实例数据

### 二、面向对象三大特性

**1. 封装（Encapsulation）**
- 概念：隐藏内部实现，暴露接口
- 私有属性：`__attribute`（双下划线开头）
- 私有方法：`__method()`
- 访问：只能在类内部访问
- 优点：保护数据、降低耦合
- Python实现：名称改写（name mangling）

**2. 继承（Inheritance）**
- 概念：子类继承父类的属性和方法
- 语法：`class Child(Parent):`
- super()：调用父类方法
  - `super().__init__()`
- 方法重写：子类重新定义父类方法
- 优点：代码复用、扩展功能
- 多继承：`class Child(Parent1, Parent2):`

**3. 多态（Polymorphism）**
- 概念：不同对象响应相同方法时表现不同
- 实现：方法重写（override）
- 鸭子类型：不关心类型，只关心行为
- 优点：灵活性、可扩展性
- Python特点：动态类型自然支持多态

### 三、高级特性回顾

**1. 特殊方法（魔法方法）**
- `__str__(self)`：print() 时调用，返回字符串
- `__repr__(self)`：repr() 时调用，用于调试
- `__len__(self)`：len() 时调用，返回长度
- `__getitem__(self, key)`：obj[key] 时调用
- `__add__(self, other)`：+ 运算符
- `__eq__(self, other)`：== 运算符
- `__hash__(self)`：hash() 时调用

**2. 属性装饰器（@property）**
- 作用：将方法转换为属性访问
- getter：`@property`
- setter：`@property_name.setter`
- deleter：`@property_name.deleter`
- 优点：提供受控访问、验证数据
- 示例：
  ```python
  class Circle:
      @property
      def radius(self):
          return self._radius
      
      @radius.setter
      def radius(self, value):
          if value < 0:
              raise ValueError("半径不能为负")
          self._radius = value
  ```

**3. 类方法和静态方法**
- 类方法：`@classmethod`
  - 第一个参数 cls
  - 访问类属性
  - 工厂方法模式
- 静态方法：`@staticmethod`
  - 无需 self 或 cls
  - 工具函数
  - 逻辑上属于类但不访问类数据

### 四、面向对象 vs 面向过程

| 特性 | 面向过程 | 面向对象 |
|------|----------|----------|
| 核心 | 函数 | 对象（类） |
| 数据 | 全局变量 | 对象属性 |
| 思想 | 步骤流程 | 对象交互 |
| 优点 | 简单直观 | 易维护、可扩展 |
| 适用 | 小程序、脚本 | 大型项目 |

### 五、面向对象编程思想

**1. 核心思想**
- 万物皆对象
- 对象有属性（数据）和方法（行为）
- 对象之间通过消息传递交互

**2. 设计原则**
- 单一职责：一个类只负责一件事
- 开闭原则：对扩展开放，对修改封闭
- 里氏替换：子类可以替换父类
- 接口隔离：接口应该小而专
- 依赖倒置：依赖抽象而不是具体

**3. 何时使用面向对象**
- ✅ 大型项目、复杂系统
- ✅ 需要代码复用和扩展
- ✅ 多人协作开发
- ✅ 需要建模真实世界对象
- ❌ 简单脚本、一次性任务

### 六、重要概念回顾

**1. 类 vs 对象**
- 类：模板、蓝图（设计图）
- 对象：实例、具体的（房子）
- 一个类可以创建多个对象

**2. 实例属性 vs 类属性**
- 实例属性：每个对象独有，通过 self 定义
- 类属性：所有对象共享，类内直接定义
- 访问：对象.属性 / 类.属性

**3. 方法重写 vs 方法重载**
- 方法重写：子类重新定义父类方法（Python支持）
- 方法重载：同名方法不同参数（Python不支持，用默认参数代替）

**4. 鸭子类型**
- "如果它走起来像鸭子，叫起来像鸭子，那它就是鸭子"
- Python不关心对象的类型，只关心是否有需要的方法
- 支持多态的灵活方式

## 💭 今日心得

今天复习了面向对象编程，这是Python从基础到进阶的重要一步。

面向对象编程（OOP）是一种编程范式，核心思想是"万物皆对象"。对象有属性（数据）和方法（行为），对象之间通过消息传递交互。相比面向过程编程，面向对象更适合大型项目和复杂系统，因为它提供了更好的代码组织、复用和扩展能力。

封装、继承、多态是面向对象的三大特性。封装通过私有属性（__attribute）隐藏内部实现，保护数据，降低耦合。继承让子类可以复用父类的代码，通过 super() 调用父类方法，通过方法重写扩展功能。多态让不同对象可以响应相同方法但表现不同，Python的鸭子类型天然支持多态，不关心对象类型，只关心是否有需要的方法。

特殊方法（魔法方法）是Python面向对象的强大特性。通过定义 __str__、__len__、__add__ 等方法，可以让自定义类的行为更像内置类型。比如定义 __add__ 后可以用 + 运算符，定义 __len__ 后可以用 len() 函数。这种设计让Python的语法更加统一和优雅。

@property 装饰器是属性访问的最佳实践。它将方法转换为属性访问，既保留了封装的优势（可以验证数据），又提供了简洁的语法（直接用 obj.attr 而不是 obj.get_attr()）。通过 getter、setter、deleter 可以完全控制属性的访问、修改和删除。

类方法和静态方法提供了不同层次的抽象。类方法用 @classmethod 装饰，第一个参数是 cls（类本身），常用于工厂方法模式。静态方法用 @staticmethod 装饰，不需要 self 或 cls，逻辑上属于类但不访问类或实例数据，常用于工具函数。

面向对象的设计原则（SOLID）是写好代码的指导。单一职责原则让每个类只负责一件事，代码更清晰。开闭原则让代码对扩展开放、对修改封闭，增强稳定性。里氏替换原则保证子类可以替换父类，继承才有意义。接口隔离原则让接口小而专，降低耦合。依赖倒置原则让代码依赖抽象而不是具体，提高灵活性。

Python的鸭子类型是灵活性的体现。不像Java那样强制类型检查，Python只关心对象是否有需要的方法。这种"如果它走起来像鸭子，叫起来像鸭子，那它就是鸭子"的哲学，让代码更灵活，也更容易扩展。这是Python动态类型语言的优势。

经过三天的基础复习，已经系统回顾了Python的核心语法：基础语法、数据结构、控制流、函数、模块、面向对象。这些知识构成了Python编程的完整体系。下一步可以复习异常处理、标准库、调试技巧等进阶内容，或者直接进入项目实战，在实践中巩固和应用这些知识。

面向对象编程是软件工程的基础。理解了类、对象、封装、继承、多态，就理解了现代软件开发的核心思想。无论是Web开发、数据分析还是机器学习，面向对象都是组织代码的主要方式。掌握面向对象，Python编程才算真正入门。
