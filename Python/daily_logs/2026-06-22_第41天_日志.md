## 📖 复习内容总结

### 一、函数基础回顾

**1. 函数定义和调用**
- 定义：`def function_name(parameters):`
- 调用：`function_name(arguments)`
- 返回值：`return value`（没有return返回None）
- 函数是第一类对象：可以赋值、作为参数、作为返回值

**2. 三种参数类型**
- 位置参数：按顺序传递，`func(a, b, c)`
- 关键字参数：按名称传递，`func(a=1, b=2)`
- 默认参数：定义时指定默认值，`def func(a, b=10):`
- 混合使用：位置参数必须在关键字参数前面

**3. 可变参数（*args、**kwargs）**
- *args：接收任意数量的位置参数，打包成元组
  - `def func(*args):` → args是元组
- **kwargs：接收任意数量的关键字参数，打包成字典
  - `def func(**kwargs):` → kwargs是字典
- 组合使用：`def func(a, b, *args, **kwargs):`
- 参数顺序：位置 → 默认 → *args → **kwargs

**4. 返回值**
- 单个返回值：`return value`
- 多个返回值：`return a, b, c`（实际返回元组）
- 无返回值：返回None
- 提前返回：`return`可以在任何地方

**5. 作用域**
- 局部作用域：函数内部定义的变量
- 全局作用域：函数外部定义的变量
- global 关键字：在函数内修改全局变量
- LEGB 规则：Local → Enclosing → Global → Built-in
- 闭包：内部函数访问外部函数的变量

### 二、模块和文件回顾

**1. 模块导入方式**
- 完整导入：`import module`
  - 使用：`module.function()`
- 导入特定内容：`from module import function`
  - 使用：`function()`
- 导入全部：`from module import *`（不推荐）
- 别名导入：`import module as alias`
  - 使用：`alias.function()`

**2. 常用标准库**
- os 模块：操作系统接口
  - os.getcwd()：当前目录
  - os.listdir()：列出文件
  - os.path.join()：路径拼接
  - os.path.exists()：检查存在
- math 模块：数学函数
  - math.sqrt()：平方根
  - math.pi：圆周率
  - math.ceil()、math.floor()：取整
- random 模块：随机数
  - random.randint(a, b)：随机整数
  - random.choice(list)：随机选择
  - random.shuffle(list)：打乱顺序

**3. 文件读写操作**
- 打开文件：`open(file, mode, encoding='utf-8')`
  - mode：'r'读、'w'写、'a'追加
- 读取：
  - read()：读取全部
  - readline()：读取一行
  - readlines()：读取所有行（列表）
- 写入：
  - write(str)：写入字符串
  - writelines(list)：写入多行
- 关闭：`file.close()`

**4. with 语句（推荐）**
- 自动管理资源：
  ```python
  with open('file.txt', 'r', encoding='utf-8') as f:
      content = f.read()
  # 自动关闭文件
  ```
- 优点：即使出错也会关闭文件
- 适用：文件、数据库连接等资源

### 三、重要概念回顾

**1. 函数的优势**
- 代码复用：一次编写，多次调用
- 模块化：将复杂问题分解
- 可维护：修改一处，全局生效
- 可测试：独立测试每个函数

**2. 作用域规则**
- 局部变量：函数内定义，函数外不可访问
- 全局变量：函数外定义，函数内可读取
- 修改全局变量：需要 global 声明
- 避免：尽量少用全局变量

**3. 模块化编程**
- 一个文件 = 一个模块
- 模块名 = 文件名（不含.py）
- 好处：代码组织、命名空间隔离、代码复用
- `if __name__ == '__main__':`：判断是否直接运行

**4. 文件操作最佳实践**
- 使用 with 语句
- 指定 encoding='utf-8'（中文）
- 异常处理：try-except 捕获文件错误
- 检查文件存在：os.path.exists()

## 💭 今日心得

今天复习了函数和模块，这是Python编程从基础到进阶的关键一步。

函数是代码复用和模块化的核心。通过函数，可以将复杂问题分解成小的、可管理的部分。函数的参数传递非常灵活：位置参数按顺序传递，关键字参数按名称传递，默认参数提供默认值，*args接收任意数量的位置参数，**kwargs接收任意数量的关键字参数。这种灵活性让函数能够适应各种场景。

作用域是理解函数的关键。局部变量在函数内定义，函数外不可访问。全局变量在函数外定义，函数内可以读取但修改需要global声明。LEGB规则（Local→Enclosing→Global→Built-in）决定了变量的查找顺序。闭包是函数式编程的重要概念，内部函数可以访问外部函数的变量，即使外部函数已经返回。

模块化编程是大型项目的基础。一个文件就是一个模块，通过import导入可以使用其他模块的功能。这样代码组织清晰、命名空间隔离、代码复用方便。Python的标准库提供了丰富的模块：os处理文件系统、math提供数学函数、random生成随机数。理解如何使用这些模块，可以大大提高开发效率。

文件操作是数据持久化的基础。open()打开文件，read()/write()读写内容，close()关闭文件。最佳实践是使用with语句，它会自动管理资源，即使出错也会关闭文件。指定encoding='utf-8'确保中文正常处理。文件操作要注意异常处理，文件可能不存在、权限不足、磁盘满等。

复习的价值在于强化记忆和深化理解。第一次学习时可能只是"会用"，复习时可以思考"为什么这样设计"、"有什么替代方案"、"在什么场景使用"。比如函数参数的设计，为什么要区分位置参数和关键字参数？因为位置参数简洁但不灵活，关键字参数灵活但冗长，两者结合兼顾了简洁和灵活。这种设计哲学贯穿Python的方方面面。

经过两天的基础复习，对Python的核心语法有了更系统的理解。从变量、数据类型、字符串、运算符，到列表、字典、元组、集合，再到条件判断、循环、函数、模块，这些基础知识构成了Python编程的基石。基础扎实，后续的面向对象、异常处理、Web开发才能游刃有余。
