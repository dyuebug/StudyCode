## 📖 学到的知识点

### 一、Web 开发阶段总结（第27-29天回顾）
1. **完整请求链路**：浏览器请求 → 路由匹配 → 视图函数 → 数据库查询 → 模板渲染 → HTTP 响应
2. **Flask 路由**：`@app.route()` 装饰器、动态路由 `<int:id>`、GET/POST 方法区分
3. **Jinja2 模板**：`{{ }}` 变量输出、`{% %}` 逻辑控制、`|` 过滤器
4. **SQLite 五步法**：连接 → row_factory → 游标 → 执行SQL → commit/close
5. **CRUD SQL**：CREATE/INSERT/SELECT/UPDATE/DELETE
6. **安全铁律**：SQL 永远用 `?` 占位符，禁止 f-string 拼接（防注入）

### 二、HTML/CSS 前端基础（第30天新知）
1. **HTML 骨架**：`<!DOCTYPE>` + `<html>` + `<head>`（配置）+ `<body>`（内容）
2. **常用标签**：标题、段落、列表、链接、图片、表单、div/span 容器
3. **CSS 选择器**：`.class`（批量可重复）、`#id`（唯一）、标签选择器
4. **盒模型**：content → padding → border → margin（由内到外四层）
5. **Flexbox 布局**：`display: flex` + `justify-content` + `align-items`（居中三件套）
6. **前后端联系**：`<input name="x">` 的 name = 后端 `request.form["x"]` 的键名

## ❓ 遇到的问题与解决

**问题**：运行学习文件时报错 `UnicodeEncodeError: 'gbk' codec can't encode`。
**解决**：这是 Windows 终端默认 GBK 编码无法输出 emoji（如 ⚠️）导致的，**不是代码问题**。加上 `PYTHONIOENCODING=utf-8` 环境变量即可正常运行；VS Code 终端默认 UTF-8 不受影响。
