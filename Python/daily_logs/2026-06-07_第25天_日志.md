## 📖 学到的知识点

### requests 高级用法
1. **Session 复用连接**：requests.Session() 保持 cookie 和 headers，提高多请求性能
2. **API 认证**：API Key（headers/params传参）、Bearer Token（Authorization头）
3. **超时控制**：timeout=(connect_timeout, read_timeout)
4. **重试机制**：HTTPAdapter + Retry 自动重试失败请求
5. **错误处理**：response.raise_for_status()、ConnectionError、Timeout、HTTPError

### JSON API 客户端项目
