## 📖 学到的知识点

### 异常处理基础
1. **异常的概念**：异常是程序运行时发生的错误，异常处理是捕获和处理这些错误的机制。
2. **常见异常类型**：ZeroDivisionError、ValueError、TypeError、FileNotFoundError、IndexError、KeyError、AttributeError。
3. **try-except 基本语法**：try 块尝试执行可能出错的代码，except 块捕获并处理异常。
4. **捕获多个异常**：可以用多个 except 分别捕获，或用元组一次捕获多个异常。
5. **else 子句**：只在 try 块没有发生异常时执行，用于"成功后的操作"。
6. **finally 子句**：无论是否发生异常都会执行，用于资源清理（关闭文件、释放连接）。
7. **raise 主动抛出异常**：在代码中检测到不合理的情况时主动抛出异常，用于参数验证和业务逻辑检查。

### 异常处理综合练习
1. **安全的除法计算器**：处理除零异常和类型错误，提供友好的错误提示。
2. **文件读取工具**：处理文件不存在和权限异常，使用 finally 确保文件关闭。
3. **用户输入验证器**：使用 raise 主动抛出异常，验证年龄必须是正整数且在合理范围内。
4. **列表和字典安全访问**：处理索引越界和键不存在异常，提供默认值机制。
5. **学生成绩管理器**：综合运用异常处理，设计健壮的成绩管理系统。

## 🎯 重要收获

1. **异常处理让程序更健壮**：避免程序因错误而崩溃，提供友好的错误提示。
2. **区分"预防错误"和"处理异常"**：能预防的用 if 判断，无法预防的用 try-except 处理。
3. **finally 保证资源清理**：无论是否发生异常都会执行，保证资源正确释放。
4. **不要滥用异常处理**：只在必要时使用，捕获具体的异常类型，不要用异常处理代替正常逻辑。
