## 📖 学到的知识点

### psutil 模块
1. **CPU 监控**：cpu_count()（核心数）、cpu_percent(interval=1)（使用率）、percpu=True（每个核心）
2. **内存监控**：virtual_memory()（total/available/used/percent）、swap_memory()
3. **磁盘监控**：disk_partitions()（分区列表）、disk_usage()（使用情况）、disk_io_counters()（IO统计）
4. **网络监控**：net_io_counters()（bytes_sent/bytes_recv）
5. **进程管理**：pids()（所有进程ID）、Process(pid)（进程对象）、name/cpu_percent/memory_info
6. **单位转换**：字节 → GB：/ (1024**3)
7. **常见错误**：cpu_percent 需要 interval、进程操作要捕获 NoSuchProcess/AccessDenied

### 系统监控工具项目
1. **SystemMonitor 类**：get_cpu_info、get_memory_info、get_disk_info、get_network_info
2. **实时监控**：monitor_once()（单次采集）、monitor_realtime()（定时循环）
3. **告警机制**：check_alerts()，阈值 CPU>80%、内存>85%、磁盘>90%
4. **历史记录**：save_log()，按日期保存 JSON 文件
5. **进程管理**：get_top_processes()（按内存/CPU排序）、search_process()（关键词搜索）、kill_process()
6. **命令行接口**：monitor、snapshot、top、search、kill 五个子命令
