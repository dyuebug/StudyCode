## 📖 学到的知识点

### 面向对象补充 - 封装
1. **封装的核心概念**：隐藏细节 + 暴露接口，保护对象内部数据不被随意修改。
2. **私有属性**：使用 `__属性名` 定义私有属性，防止外部直接访问和修改关键数据。
3. **私有方法**：使用 `__方法名` 定义私有方法，只在类内部使用的辅助方法。
4. **getter/setter 思想**：通过公开方法安全地读取和修改私有数据，可以在方法中加入验证逻辑。
5. **封装的价值**：数据保护、降低耦合、提高可维护性、让类的接口更清晰。

### 面向对象综合练习
1. **银行账户类设计**：使用私有属性保护余额和密码，提供存款、取款、查询余额等公开方法。
2. **密码验证机制**：查看余额和取款操作需要密码验证，体现了封装的安全性。
3. **数据校验**：存款金额必须大于0，取款时检查余额是否足够，修改密码时验证旧密码。
4. **多对象独立性**：多个账户对象各自维护独立的数据，互不影响。
5. **封装的实际应用**：通过银行账户系统，深刻理解了封装如何保证对象状态合理、防止错误使用。
