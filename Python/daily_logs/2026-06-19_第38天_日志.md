## 📖 学到的知识点

### 一、Python sqlite3 模块基础
1. **模块导入**：import sqlite3（Python内置，无需安装）
2. **数据库文件**：.db文件，第一次运行自动创建
3. **内存数据库**：':memory:' 临时数据库，程序结束销毁

### 二、连接数据库 ⭐⭐⭐⭐⭐
1. **sqlite3.connect()**：连接或创建数据库
   - 参数：数据库文件路径
   - 返回：Connection对象
   - 作用：建立与数据库的连接
2. **自动创建**：如果数据库文件不存在，自动创建
3. **连接对象**：后续所有操作基于此连接

### 三、游标（Cursor）⭐⭐⭐⭐⭐
1. **游标概念**：数据库操作的"遥控器"
2. **创建游标**：cursor = conn.cursor()
3. **游标作用**：
   - 执行SQL：cursor.execute()
   - 获取结果：cursor.fetchall()、fetchone()
   - 批量操作：cursor.executemany()
4. **Connection vs Cursor**：
   - Connection：连接数据库、管理事务（commit/close）
   - Cursor：执行SQL、获取结果（execute/fetch）

### 四、执行SQL操作
1. **execute()**：执行单条SQL语句
   - 语法：cursor.execute(sql, params)
   - 参数化查询：使用?占位符
2. **executemany()**：批量执行（插入多条数据）
3. **参数化查询**：
   - cursor.execute("SELECT * FROM messages WHERE id = ?", (id,))
   - 防止SQL注入，安全第一

### 五、获取查询结果
1. **fetchall()**：获取所有结果（列表）
2. **fetchone()**：获取一条结果（元组）
3. **fetchmany(n)**：获取n条结果
4. **结果格式**：元组的列表，每个元组代表一行

### 六、事务管理 ⭐⭐⭐⭐⭐
1. **commit()**：提交事务
   - INSERT/UPDATE/DELETE后必须commit()
   - 不commit，修改不生效
   - SELECT不需要commit
2. **rollback()**：回滚事务（撤销未提交的修改）
3. **自动提交 vs 手动提交**：
   - 默认：手动提交（需要显式调用commit）
   - 优点：可以控制事务边界

### 七、资源管理
1. **close()**：关闭连接
   - 释放资源，避免泄漏
   - 顺序：先关cursor，再关connection
2. **with语句**：自动管理（推荐）
   ```python
   with sqlite3.connect('db.db') as conn:
       cursor = conn.cursor()
       # 操作...
   # 自动commit和close
   ```
3. **错误处理**：try-except-finally确保资源释放

### 八、CREATE TABLE 创建表
1. **基本语法**：
   ```python
   cursor.execute('''
       CREATE TABLE IF NOT EXISTS messages (
           id INTEGER PRIMARY KEY AUTOINCREMENT,
           name TEXT NOT NULL,
           content TEXT NOT NULL,
           time TEXT NOT NULL
       )
   ''')
   ```
2. **字段类型**：INTEGER、TEXT、REAL、BLOB
3. **PRIMARY KEY**：主键，唯一标识
4. **AUTOINCREMENT**：自动自增
5. **NOT NULL**：不能为空
6. **IF NOT EXISTS**：表不存在才创建（避免重复创建报错）

### 九、增删改查（CRUD）Python实现
1. **INSERT插入**：
   ```python
   cursor.execute(
       "INSERT INTO messages (name, content, time) VALUES (?, ?, ?)",
       (name, content, time)
   )
   conn.commit()
   ```
2. **SELECT查询**：
   ```python
   cursor.execute("SELECT * FROM messages ORDER BY time DESC")
   results = cursor.fetchall()
   ```
3. **UPDATE更新**：
   ```python
   cursor.execute(
       "UPDATE messages SET content = ? WHERE id = ?",
       (new_content, id)
   )
   conn.commit()
   ```
4. **DELETE删除**：
   ```python
   cursor.execute("DELETE FROM messages WHERE id = ?", (id,))
   conn.commit()
   ```

### 十、留言板数据库升级思路
1. **初始化数据库**：启动时创建表（IF NOT EXISTS）
2. **GET接口**：SELECT查询，fetchall()获取所有，转JSON返回
3. **POST接口**：INSERT插入，commit()提交，id自动生成
4. **DELETE接口**：DELETE删除，参数化查询，commit()提交
5. **优势**：
   - 不需要load/save_messages函数
   - 不需要手动管理next_id
   - 查询更灵活（ORDER BY、WHERE）
   - 并发更安全

## 💭 今日心得

今天学习了Python sqlite3模块，将昨天学的SQL语法应用到Python代码中。最大的收获是理解了连接（Connection）、游标（Cursor）、提交（commit）三个核心概念。

连接和游标的关系很清晰：连接是打开数据库的大门，游标是进门后的操作工具。连接负责管理事务（commit、rollback、close），游标负责执行SQL和获取结果（execute、fetch）。这种分工很合理，连接管理整体，游标处理细节。

commit()的重要性必须强调。INSERT/UPDATE/DELETE执行后，数据只是在内存中修改，必须调用commit()才真正写入数据库。这是事务机制的体现，可以在出错时rollback()回滚。SELECT查询不需要commit，因为只读不修改。初学容易忘记commit，导致修改不生效，要养成习惯。

参数化查询在Python中的使用和SQL语法一致，用?占位符，传入元组参数。cursor.execute("SELECT * FROM messages WHERE id = ?", (id,))，这样既安全（防SQL注入）又清晰。批量插入用executemany()，传入列表参数，效率更高。

资源管理要注意。数据库连接是有限资源，用完必须close()释放。顺序是先关游标，再关连接。更好的做法是用with语句，自动管理资源，即使出错也能保证释放。

CREATE TABLE创建表的语法要掌握。IF NOT EXISTS避免重复创建报错，PRIMARY KEY AUTOINCREMENT实现id自增，NOT NULL保证字段必填。字段类型有INTEGER、TEXT、REAL、BLOB，SQLite的类型系统很灵活。

留言板升级到数据库版本，改动不大但收益明显。不需要load_messages()和save_messages()，数据库自动持久化。不需要手动管理next_id，AUTOINCREMENT自动生成。查询更灵活，可以ORDER BY排序、WHERE筛选、LIMIT分页。并发更安全，数据库内部有锁机制。

从JSON文件到数据库，是数据存储的质变。文件适合小数据、简单操作，数据库适合大数据、复杂查询。掌握了sqlite3模块，就具备了开发真正实用项目的能力。留言板项目从v1.0到v4.0的演进，见证了从简单到完善的过程：v1.0内存存储、v2.0 JSON持久化、v3.0 RESTful API、v4.0数据库升级。每一步都是技能的积累和项目的完善。
