## 📖 学到的知识点

### 标准库基础
1. **标准库的概念**：Python 自带的模块集合，无需安装，开箱即用，功能强大。
2. **标准库的优势**：避免重复造轮子，提高开发效率，功能稳定可靠，跨平台兼容。

### os 模块 - 文件和目录操作
1. **文件路径操作**：os.path.join（拼接路径，跨平台兼容）、os.path.exists（检查路径是否存在）、os.path.dirname（获取目录名）、os.path.basename（获取文件名）。
2. **目录操作**：os.listdir（列出目录内容）、os.mkdir（创建单个目录）、os.makedirs（创建多级目录）。
3. **文件操作**：os.remove（删除文件）、os.rename（重命名文件）。
4. **路径判断**：os.path.isfile（是否是文件）、os.path.isdir（是否是目录）。

### datetime 模块 - 日期和时间处理
1. **获取当前时间**：datetime.now() 获取当前日期和时间对象。
2. **日期格式化**：strftime() 将日期对象转换为字符串，常用格式符号（%Y、%m、%d、%H、%M、%S）。
3. **日期解析**：strptime() 将字符串转换为日期对象，格式必须与字符串完全匹配。
4. **时间差计算**：timedelta 表示时间差，支持日期加减运算，.days 获取天数，.total_seconds() 获取总秒数。

### json 模块 - JSON 数据处理
1. **JSON 的概念**：轻量级的数据交换格式，易于人阅读和编写，常用于 API 接口和配置文件。
2. **序列化**：json.dumps() 将 Python 对象转换为 JSON 字符串，ensure_ascii=False 支持中文，indent 美化输出。
3. **反序列化**：json.loads() 将 JSON 字符串转换为 Python 对象。
4. **文件操作**：json.dump() 写入文件，json.load() 读取文件。

### 标准库综合练习
1. **文件管理工具**：使用 os 模块列出目录文件、获取文件信息、跨平台路径处理。
2. **日志记录器**：使用 datetime 模块记录带时间戳的日志，格式化日志信息。
3. **配置文件管理器**：使用 json 模块读取和保存配置文件，支持中文数据。
4. **数据导入导出工具**：综合运用 os、datetime、json 模块，实现数据的导入导出和时间戳记录。
5. **日期计算工具**：计算日期差、日期加减、获取星期几等实用功能。
