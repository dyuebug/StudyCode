## 📖 学到的知识点

### 一、数据库核心概念
1. **什么是数据库**：结构化存储数据的仓库，支持高效查询、修改、删除
2. **数据库 vs 文件对比**：
   - JSON文件：简单、小数据（<100条）、顺序读写、单用户
   - 数据库：强大、大数据（>1000条）、索引查询、并发安全、数据完整性
3. **使用场景**：数据量大、复杂查询、多用户并发、数据完整性要求高时用数据库

### 二、SQLite 特点
1. **轻量级**：Python 内置 sqlite3 模块，无需安装
2. **嵌入式**：数据库就是一个文件（.db），不需要服务器
3. **零配置**：不需要配置，开箱即用
4. **跨平台**：Windows、Mac、Linux 通用
5. **适用场景**：桌面应用、移动应用、小型Web应用、学习原型

### 三、SQL 四大操作（CRUD）⭐⭐⭐⭐⭐
1. **SELECT - 查询**：
   - 语法：SELECT 字段 FROM 表名 WHERE 条件
   - 示例：SELECT * FROM messages WHERE id = 1
   - 变体：SELECT COUNT(*)、SELECT DISTINCT
2. **INSERT - 插入**：
   - 语法：INSERT INTO 表名 (字段) VALUES (值)
   - 示例：INSERT INTO messages (name, content) VALUES ('Alice', 'Hello')
3. **UPDATE - 更新**：
   - 语法：UPDATE 表名 SET 字段=值 WHERE 条件
   - 示例：UPDATE messages SET content = 'Hi' WHERE id = 1
   - ⚠️ 必须加WHERE，否则更新所有记录
4. **DELETE - 删除**：
   - 语法：DELETE FROM 表名 WHERE 条件
   - 示例：DELETE FROM messages WHERE id = 1
   - ⚠️ 必须加WHERE，否则删除所有记录

### 四、WHERE 条件查询 ⭐⭐⭐⭐⭐
1. **比较运算符**：=（等于）、!=（不等于）、>、<、>=、<=
2. **逻辑运算符**：AND（并且）、OR（或者）、NOT（非）
3. **优先级**：NOT > AND > OR（建议用括号明确）
4. **BETWEEN**：范围查询，WHERE id BETWEEN 1 AND 10
5. **LIKE 模糊查询**：
   - % 匹配任意多个字符
   - _ 匹配单个字符
   - 示例：WHERE content LIKE '%Python%'（包含Python）

### 五、ORDER BY 排序
1. **升序**：ORDER BY 字段 ASC（默认）
2. **降序**：ORDER BY 字段 DESC
3. **多字段**：ORDER BY name ASC, id DESC
4. **留言板应用**：ORDER BY time DESC（最新在前）

### 六、LIMIT 限制数量
1. **限制数量**：LIMIT 10（前10条）
2. **跳过数量**：LIMIT 10 OFFSET 10（跳过前10条，取10条）
3. **分页公式**：OFFSET = (page - 1) * page_size
4. **示例**：第3页每页20条 → LIMIT 20 OFFSET 40

### 七、参数化查询（防SQL注入）⭐⭐⭐⭐⭐
1. **SQL注入**：用户输入包含恶意SQL代码，拼接字符串导致执行意外SQL
2. **危险示例**：
   - 用户输入：Alice' OR '1'='1
   - 拼接SQL：f"SELECT * FROM messages WHERE name = '{name}'"
   - 实际执行：WHERE name = 'Alice' OR '1'='1'（返回所有数据）
3. **安全做法**：使用占位符 ?
   - cursor.execute("SELECT * FROM messages WHERE name = ?", (name,))
   - 原理：SQL和数据分离，数据库自动转义特殊字符
4. **Python使用**：
   - 单个参数：cursor.execute("... WHERE id = ?", (id,))
   - 多个参数：cursor.execute("... VALUES (?, ?)", (name, content))
   - 命名参数：cursor.execute("... VALUES (:name, :content)", {"name": name, "content": content})
5. **记住**：永远使用参数化查询，不要拼接SQL字符串！

### 八、SQL语法规则
1. **大小写**：不区分大小写，但习惯关键字用大写
2. **分号**：每条语句以分号结尾（Python中可省略）
3. **星号**：* 表示所有字段
4. **字符串**：用单引号
5. **注释**：-- 单行注释，/* */ 多行注释

## 💭 今日心得

今天学习了数据库基础和SQL语法，理解了数据库相比文件存储的优势。最大的收获是掌握了SQL四大操作（SELECT/INSERT/UPDATE/DELETE）和参数化查询的重要性。

数据库不只是换个存储方式，是质的提升。JSON文件适合小数据量、简单增删改查，但遇到复杂查询（搜索、筛选、排序）就力不从心。数据库通过索引实现高效查询，支持复杂的WHERE条件、JOIN关联、聚合统计，还能保证并发安全和数据完整性。SQLite作为轻量级数据库，Python内置、零配置、单文件，非常适合学习和小项目。

SQL语法简洁强大，声明式语言的特点是"说要什么，不说怎么做"。SELECT查询、INSERT插入、UPDATE更新、DELETE删除，四大操作覆盖了绝大部分需求。WHERE条件是SQL的精髓，支持比较运算（=、>、<）、逻辑组合（AND、OR）、模糊匹配（LIKE、%），能精确筛选数据。ORDER BY排序和LIMIT限制让分页查询变得简单。

参数化查询是今天的重点，必须牢记。SQL注入是严重的安全问题，用户输入如果直接拼接到SQL字符串，恶意代码可能被执行，导致数据泄露、删除、篡改。参数化查询用占位符（?）把SQL语句和数据分离，数据库自动转义特殊字符，用户输入不会被当作SQL代码。Python的sqlite3模块用元组传参，简单但有效。

SQL语法规则要注意：UPDATE和DELETE必须加WHERE条件，否则会误操作全部数据。建议先SELECT确认要操作哪些记录，再执行UPDATE/DELETE。关键字习惯用大写（SELECT、FROM、WHERE），提高可读性。

留言板从JSON文件升级到数据库，不只是存储方式改变，查询能力大幅提升。原来要遍历列表筛选，现在一条SQL搞定。原来要手动管理id，现在数据库自增。原来担心并发问题，现在数据库保证安全。这就是数据库的价值。
