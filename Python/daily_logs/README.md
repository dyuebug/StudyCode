# 每日学习日志（daily_logs）

## 命名规则

```
YYYY-MM-DD_第X天_日志.md
```

- `X` 是**学习序号**，不是自然日序号。
- 文件名日期是实际记录日期，必须与正文“日期”字段一致。
- 序号唯一；新增前先检查现有最大序号。

## 当前状态

- 已完成序号：**1～46**，无重复、无缺号。
- 第 47 天只有任务、没有完成日志，状态仍为“计划中/待核验”。
- 第 47～52 天另有 **示例日志**（`2026-10-30_第47天_日志.md` ～ `第52天_日志.md`）：
  - 文件头标记为“示例日志（非真实学习记录，不计入统计）”；
  - 只用于演示日志格式与知识点写法，不代表学习已发生；
  - 不计入学习天数、累计时长、完成度与周报，统计脚本和测试自动跳过。
- 有效累计时长：**57.16 小时**（逐日字段求和，只含 1～46 天）。
- 日志与底稿清单见 `INDEX.md`；第 47～52 天底稿位于 `_drafts/`，字段为“待填写”。
- 自动化：
  - `scripts/generate_learning_logs.py --check` 检查示例日志覆盖；
  - `scripts/generate_learning_logs.py --write` 为缺失任务生成示例日志，不覆盖真实日志。

## 示例日志规则

1. 文件名仍使用正式格式，便于对照任务；正文第一段必须是统计口径声明。
2. 必须包含 `**文档性质**：示例日志（非真实学习记录，不计入统计）` 这一行，作为脚本与测试的识别标记。
3. 时长字段写“示例值”，不写真实计时数字；完成度写“示例内容，不代表完成度”。
4. 不得把示例日志复制为真实日志后只删除标记；真实日志仍必须在学习结束后按实际结果填写。

## 不可做的事

1. 不要把任务清单当成完成日志。
2. 不要根据文件修改时间推断学习日期。
3. 不要为了让天数连续而补造日志。
4. 不要在没有用户确认时填写“遇到的问题”“学习心得”或完成度。
