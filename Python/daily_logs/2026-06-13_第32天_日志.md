## 📖 学到的知识点

### 一、异步编程核心概念
1. **同步 vs 异步**：同步像排队买票（等前面的人），异步像点餐拿号（不干等）
2. **JavaScript 单线程**：一次只能做一件事，所以必须用异步避免页面卡住
3. **Promise 对象**：代表"未来会完成的操作"，三种状态（pending/fulfilled/rejected）
4. **事件循环机制**：异步操作放入队列，同步代码先执行，回头再处理队列

### 二、fetch() 异步请求
1. **基本语法**：`fetch(url)` 返回 Promise，不等待立即返回
2. **两步解析**：
   - 第一步：`response.json()` 解析响应（也返回 Promise）
   - 第二步：拿到真正的数据
3. **.then() 链式调用**：`fetch(url).then(res => res.json()).then(data => ...)`
4. **错误处理**：`.catch()` 捕获网络错误

### 三、async/await 语法（推荐）⭐⭐⭐⭐⭐
1. **async 函数**：用 `async` 标记异步函数，自动返回 Promise
2. **await 等待**：暂停当前函数，等 Promise 完成，拿到结果
3. **try/catch**：捕获异步错误，比 .catch() 更直观
4. **代码更清晰**：看起来像同步代码，易读易写

### 四、实用技巧
1. **response.ok**：检查状态码是否 200-299，避免解析错误响应
2. **Promise.all()**：并行发送多个请求，比循环 await 快
3. **加载状态**：请求前显示"加载中..."，完成后显示数据
4. **公开 API**：JSONPlaceholder、Dog API 用于测试

## 💭 今日心得

今天学习了前端最核心的异步编程，终于理解了为什么 JavaScript 必须异步——单线程 + 网络慢，如果同步等待会让页面"冻住"。Promise 和 async/await 是异步的两种写法，async/await 更推荐，代码看起来像同步，但实际是异步执行。

fetch() 是前端调用 API 的标准方法，记住两步：response.json() 解析响应，然后拿到数据。错误处理很重要，必须加 try/catch 或 .catch()，否则网络错误时用户不知道发生了什么。

最大的收获是理解了"等数据回来再处理"的思想——发出请求后不干等，页面继续响应用户，数据到了再执行回调函数。这是前后端分离的基础，下一步就是调用自己的 Flask API，打通前后端数据交互。
