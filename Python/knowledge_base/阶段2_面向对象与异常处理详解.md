## 1. 类与实例

```python
class Task:
    """一条待办事项。"""

    total_created = 0  # 类属性：所有实例共享

    def __init__(self, text: str, done: bool = False) -> None:
        self.text = text      # 实例属性
        self.done = done
        Task.total_created += 1

    def toggle(self) -> None:
        self.done = not self.done
```

- `__init__` 负责初始化实例，不负责创建对象；`__new__` 才负责创建。
- 类属性通过类名修改：`Task.total_created += 1`；通过实例赋值会创建同名实例属性，不再影响类属性。
- `self` 是实例引用，不是关键字，但约定不改名。

### 1.1 实例方法、类方法、静态方法

```python
class Task:
    def toggle(self):          # 实例方法：第一个参数是 self
        ...

    @classmethod
    def from_text(cls, text):  # 类方法：第一个参数是 cls，常用于替代构造器
        return cls(text.strip())

    @staticmethod
    def is_valid(text):        # 静态方法：不依赖实例或类
        return bool(text.strip())
```

| 类型 | 第一个参数 | 能访问实例 | 能访问类 | 典型用途 |
|---|---|---|---|---|
| 实例方法 | `self` | 是 | 通过 `self.__class__` | 操作单个对象 |
| 类方法 | `cls` | 否 | 是 | 工厂方法、读取类级配置 |
| 静态方法 | 无 | 否 | 否 | 纯工具函数 |

### 1.2 属性装饰器

```python
class Temperature:
    def __init__(self, celsius: float) -> None:
        self._celsius = celsius

    @property
    def celsius(self) -> float:
        return self._celsius

    @celsius.setter
    def celsius(self, value: float) -> None:
        if value < -273.15:
            raise ValueError("温度不能低于绝对零度")
        self._celsius = value
```

- `@property` 让方法可以像属性一样读取，便于后续加入校验而不改变调用方。
- 下划线前缀是约定，不是访问控制；Python 没有真正的私有成员。
- 不要为每个字段都写 getter/setter，只在需要校验、计算或兼容旧接口时使用。

## 2. 继承与多态

```python
class Animal:
    def speak(self) -> str:
        raise NotImplementedError

class Dog(Animal):
    def speak(self) -> str:
        return "woof"

class Cat(Animal):
    def speak(self) -> str:
        return "meow"

for animal in (Dog(), Cat()):
    print(animal.speak())
```

- 多态依赖“同一接口、不同实现”，调用方不需要判断具体类型。
- 子类调用父类方法用 `super()`，避免硬编码父类名，支持多继承的 MRO。
- 方法解析顺序（MRO）可用 `Cls.__mro__` 查看；菱形继承时按 C3 线性化。
- 组合通常优于继承：当关系是“有一个”而不是“是一个”时，把对象作为属性。

```python
class Repository:
    def __init__(self, storage):
        self.storage = storage   # 组合：Repository 有一个 storage
```

### 2.1 抽象基类

```python
from abc import ABC, abstractmethod

class Storage(ABC):
    @abstractmethod
    def save(self, data: dict) -> None: ...

class JsonStorage(Storage):
    def save(self, data: dict) -> None:
        ...
```

抽象方法未实现时，实例化子类会抛 `TypeError`。适合定义稳定的扩展点，不要为单一实现引入抽象层。

## 3. 魔法方法

| 方法 | 触发场景 | 注意 |
|---|---|---|
| `__init__` | 实例初始化 | 不返回值 |
| `__repr__` | 调试输出、`repr()` | 应尽可能可重建对象 |
| `__str__` | `str()`、`print()` | 面向用户 |
| `__eq__` | `==` | 定义后通常也要定义 `__hash__` |
| `__len__` | `len()` | 必须返回非负整数 |
| `__iter__` | `for`、`iter()` | 返回迭代器 |
| `__enter__`/`__exit__` | `with` | `__exit__` 返回 `True` 会吞掉异常 |
| `__call__` | 把实例当函数调用 | 谨慎使用，避免语义不清 |

```python
class Money:
    def __init__(self, cents: int) -> None:
        self.cents = cents

    def __repr__(self) -> str:
        return f"Money({self.cents})"

    def __eq__(self, other: object) -> bool:
        if not isinstance(other, Money):
            return NotImplemented
        return self.cents == other.cents

    def __hash__(self) -> int:
        return hash(self.cents)
```

`__eq__` 返回 `NotImplemented` 而不是 `False`，让 Python 有机会尝试反向比较。

## 4. 异常处理

```python
try:
    value = int(user_input)
except ValueError as error:
    raise ValueError("输入必须是整数") from error
else:
    print("解析成功", value)
finally:
    print("无论成功失败都会执行")
```

- `except` 尽量捕获具体异常，不要裸 `except:`。
- `raise ... from error` 保留原始异常链，便于定位。
- `else` 只在 `try` 未抛异常时执行，适合放“成功后的逻辑”。
- `finally` 用于释放资源；文件与连接优先用 `with`。
- 不要用异常做常规流程控制。

### 4.1 自定义异常

```python
class StorageError(Exception):
    """存储层错误基类。"""

class CorruptedFileError(StorageError):
    """文件内容损坏。"""
```

自定义异常应继承 `Exception`（不是 `BaseException`），并在消息中带上可定位的上下文。

### 4.2 常见错误

| 写法 | 问题 |
|---|---|
| `except Exception: pass` | 吞掉所有错误，问题被隐藏 |
| `except:` | 连 `KeyboardInterrupt` 也捕获 |
| 在 `finally` 中 `return` | 会覆盖 `try` 中的返回值或异常 |
| 捕获后不记录 | 排障时没有线索 |

## 5. 装饰器

装饰器是“接收函数、返回函数”的可调用对象，用于在不修改原函数的前提下增加行为。

```python
import functools
import time

def timed(function):
    @functools.wraps(function)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        try:
            return function(*args, **kwargs)
        finally:
            elapsed = time.perf_counter() - start
            print(f"{function.__name__} 用时 {elapsed:.4f}s")
    return wrapper

@timed
def slow_task():
    time.sleep(0.1)
```

- `functools.wraps` 保留原函数的 `__name__`、`__doc__`，否则调试信息会变成 `wrapper`。
- 带参数的装饰器需要三层：`def decorator(arg): def outer(func): def wrapper(...)`。
- 装饰器在函数定义时执行一次，不是在每次调用时执行。
- 多个装饰器从下往上应用，从上往下执行包装后的调用。

**常见陷阱**：装饰器忘记返回 `wrapper`，导致被装饰函数变成 `None`。

## 6. 生成器与迭代器

### 6.1 迭代器协议

```python
class Countdown:
    def __init__(self, start: int) -> None:
        self.current = start

    def __iter__(self):
        return self

    def __next__(self) -> int:
        if self.current <= 0:
            raise StopIteration
        value = self.current
        self.current -= 1
        return value
```

迭代器必须实现 `__iter__`（返回自身）和 `__next__`；耗尽后持续抛 `StopIteration`。

### 6.2 生成器

```python
def read_lines(path):
    with open(path, encoding="utf-8") as handle:
        for line in handle:
            yield line.rstrip("\n")

def fibonacci(limit):
    a, b = 0, 1
    while a < limit:
        yield a
        a, b = b, a + b
```

- 生成器函数调用时不会执行函数体，只在 `next()` 时推进。
- `yield` 自动保存局部状态，适合大文件、无限序列和流式处理。
- 生成器只能遍历一次；需要重复使用时应返回列表或重新创建。
- `yield from` 委托给另一个可迭代对象。

**常见陷阱**：在生成器内部修改外部可变状态，可能让调用方难以预测；生成器耗尽后再 `next()` 会抛 `StopIteration`。

## 7. 上下文管理器

```python
from contextlib import contextmanager

@contextmanager
def open_database(path):
    connection = connect(path)
    try:
        yield connection
    finally:
        connection.close()
```

- `with` 保证退出时执行清理，即使发生异常。
- 类实现需要 `__enter__` 与 `__exit__`；`__exit__` 接收异常类型、值和回溯。
- `__exit__` 返回 `True` 表示异常已处理，不再向外传播；除非明确需要，否则不要返回 `True`。
- 多个资源用 `with A() as a, B() as b:`，退出顺序与进入顺序相反。
