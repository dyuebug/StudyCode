## 2. Linux 常用命令

| 场景 | 命令 |
|---|---|
| 查文件 | `find /opt -name "*.py" -type f` |
| 看权限 | `ls -l`、`chmod 640`、`chown forum:forum` |
| 查进程 | `pgrep -af gunicorn` |
| 查端口 | `ss -tlnp \| grep 8000` |
| 看服务日志 | `journalctl -u study-forum -n 100 --no-pager` |
| 跟踪日志 | `journalctl -u study-forum -f` |
| 压缩 | `tar -czf backup.tar.gz /var/lib/study-forum` |
| 同步 | `rsync -av --dry-run src/ user@host:dst/` |

**陷阱**：`rsync --delete` 会删除目标端多余文件，先 `--dry-run`。

## 3. systemd

```bash
sudo systemctl daemon-reload
sudo systemctl start study-forum
sudo systemctl status study-forum
sudo systemctl enable study-forum
```

```ini
[Service]
User=forum
WorkingDirectory=/opt/study-forum
EnvironmentFile=/etc/study-forum/forum.env
ExecStart=/opt/study-forum/.venv/bin/gunicorn --bind 127.0.0.1:8000 --workers 1 --threads 4 "forum_project:create_app()"
Restart=on-failure
```

| 错误码 | 含义 |
|---|---|
| `203/EXEC` | ExecStart 路径不可执行 |
| `200/CHDIR` | WorkingDirectory 不存在 |

**SQLite 取舍**：1 worker + 多线程，避免并发写锁；迁移 PostgreSQL 后再加 worker。

## 4. Nginx

```nginx
location /static/ {
    alias /opt/study-forum/forum_project/static/;
    expires 7d;
}
location / {
    proxy_pass http://127.0.0.1:8000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

```bash
sudo nginx -t          # 必须先通过
sudo systemctl reload nginx
```

| 状态码 | 常见原因 |
|---|---|
| 502 | 上游未启动、端口不对 |
| 504 | 上游处理超时 |
| 静态 404 | `alias` 路径错误 |

## 5. Docker

```bash
docker build -f deployment/docker/Dockerfile -t study-forum:1.0 .
docker run --rm -p 127.0.0.1:8000:8000 \
  -e SECRET_KEY=change-me -v forum-data:/data study-forum:1.0
docker compose -f deployment/docker/docker-compose.yml up -d --build
docker compose logs -f forum
docker compose down          # 保留卷
docker compose down -v       # 删除卷，数据丢失
```

| 概念 | 要点 |
|---|---|
| 构建上下文 | 最后参数 `.`；Dockerfile 中 `COPY` 相对上下文 |
| 层缓存 | 先复制依赖清单，再复制代码 |
| 数据卷 | 容器内数据不持久，SQLite 必须挂载 |

## 6. 备份与恢复

```bash
# 备份（在线）
sqlite3 /var/lib/study-forum/forum.db ".backup '/var/backups/forum.db'"
gzip -f /var/backups/forum.db

# 校验
gzip -t /var/backups/forum.db.gz

# 恢复
gunzip -c /var/backups/forum.db.gz > /var/lib/study-forum/forum.db
chown forum:forum /var/lib/study-forum/forum.db
sudo systemctl restart study-forum
```

**恢复后必须执行健康检查**，不要只看文件是否存在。
