## 维护规则

1. 新增内容注明整理日期与数据范围。
2. 速查表包含：适用场景、关键命令/API、最小示例、常见陷阱、对应文件路径。
3. 不删除旧内容；纠正时追加“待修正内容”或更新说明。
4. 未实际运行验证的内容标注“示例”或“计划中”。

## 状态区分

- **已实现**：代码存在且测试或运行结果可核对，例如论坛项目、留言板 v4。
- **学习材料**：讲解与示例已生成，但对应学习序号尚无完成日志，例如第 47 天 JavaScript 进阶笔记。
- **计划中**：只有路线描述，没有代码或材料，例如论坛扩展功能、服务器实机部署。

知识笔记的存在不代表对应内容已经学会；判断学习进度仍以 `daily_logs/` 和可运行代码为准。
