# 周报目录

本目录的周报由脚本从 `daily_logs/` 自动生成，不是新的学习记录。

## 生成方式

```bash
# 仓库根目录
python scripts/generate_weekly_reports.py
```

脚本只做四件事：

1. 按 ISO 周（周一至周日）分组真实日志。
2. 汇总日志中明确写出的时长、完成度和已勾选任务。
3. 提取知识点小节标题、问题与解决段落。
4. 标记同日多份日志、序号与日期倒挂、已知记账偏差。

## 阅读约定

- `INDEX.md` 是周报索引，先看它。
- 单周文件命名为 `YYYY-Www.md`，年份与周次均按 ISO 8601。
- 日志中缺少的字段写“日志未记录”，脚本不补默认值。
- “下周重点”固定为“待确认”，学习计划由用户决定，不由脚本推断。
- 周报中的时长合计只累加日志自报的“学习时长”，与 `docs/学习进度与统计口径.md` 一致。
- 文件头含“示例日志（非真实学习记录，不计入统计）”标记的文件会被跳过；生成时会打印跳过数量。

## 维护要求

- 新增日志后重新运行脚本即可覆盖更新，不需要手工编辑单周文件。
- 如果手工改过周报，下次生成会被覆盖；需要长期保留的补充说明应写入 `docs/`。
