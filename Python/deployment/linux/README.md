# Linux 学习导航

## 文件

| 文件 | 主题 | 建议时长 |
|---|---|---|
| `01_Linux基础命令.md` | 目录、查找、权限、进程、日志 | 45 分钟 |
| `02_进程与服务管理.md` | Gunicorn + systemd | 45 分钟 |
| `03_Nginx反向代理.md` | 反向代理、静态资源、HTTPS、限流 | 45 分钟 |

## 学习方式

1. 在 WSL、虚拟机或云服务器上操作，不要只读不练。
2. 每条命令执行前先说明预期结果，执行后对比。
3. 遇到报错保留原文，记录到学习日志的“问题与解决”部分。

## 验收

完成三份材料后，应能独立完成一次从代码上传到 Nginx 对外提供服务的完整部署，并保存以下证据：

- `systemctl status study-forum` 输出。
- `curl -i http://127.0.0.1:8000/api/posts` 输出。
- 浏览器访问域名的截图或状态码。
