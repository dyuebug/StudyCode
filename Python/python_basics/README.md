## 依赖说明

`matplotlib`、`pandas`、`numpy` 仅部分文件使用；未安装时对应文件会报 `ModuleNotFoundError`，按 `requirements.txt` 安装即可。

## 学习建议

1. 先读文件开头的“项目说明”，再运行。
2. 交互式文件（含 `input()`）按提示输入，不要直接回车跳过。
3. HTTP 相关文件会访问网络或启动端口，运行前确认端口未被占用。
4. 练习题默认不提供答案；需要时先看思路与验证方法。
