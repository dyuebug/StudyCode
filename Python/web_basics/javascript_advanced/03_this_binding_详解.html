📖 核心概念

什么是this？

this是函数运行时的上下文对象，指向调用函数的对象。

关键点：

  • this的值不是在函数定义时确定，而是在调用时确定
  • 同一个函数在不同的调用方式下，this指向不同
  • 箭头函数例外：this在定义时确定（词法作用域）

this的4种绑定规则（优先级从低到高）

  1. 默认绑定：独立函数调用 → 全局对象（严格模式下是undefined）
  2. 隐式绑定：对象方法调用 → 调用对象
  3. 显式绑定：call/apply/bind → 指定的对象
  4. new绑定：构造函数调用 → 新创建的对象

优先级：new绑定 > 显式绑定 > 隐式绑定 > 默认绑定
