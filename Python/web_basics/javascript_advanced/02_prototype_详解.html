📖 核心概念

什么是原型链？

原型链（Prototype Chain）是JavaScript实现继承的机制。每个对象都有一个内部链接指向另一个对象（原型），形成一条链。

三个核心概念：

  • prototype：构造函数的原型对象（只有函数有）
  • __proto__：对象的原型指针（所有对象都有）
  • constructor：原型对象指向构造函数

为什么需要原型链？

  • 实现继承：子类继承父类的属性和方法
  • 节省内存：方法定义在原型上，所有实例共享
  • 动态扩展：可以动态添加方法到原型

🔍 原型链图示

┌─────────────┐
│   Person    │ (构造函数)
│ (Function)  │
└──────┬──────┘
       │ prototype
       ↓
┌─────────────────────┐
│ Person.prototype    │ (原型对象)
│ - constructor ──────┼─→ Person
│ - sayHello()        │
└──────┬──────────────┘
       ↑ __proto__
       │
┌──────┴──────┐
│   person1   │ (实例对象)
│ - name      │
│ - age       │
└─────────────┘

查找 person1.sayHello() 的过程：
1. 在 person1 自身查找 sayHello → 没有
2. 沿着 __proto__ 到 Person.prototype 查找 → 找到！
3. 如果还没找到，继续沿着原型链向上查找
4. 直到 Object.prototype（原型链顶端）
5. 还没找到返回 undefined
