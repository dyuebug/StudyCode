📖 核心概念

什么是闭包？

闭包（Closure）是指一个函数可以访问其外部函数作用域中的变量，即使外部函数已经执行完毕。

简单理解：

  • 函数 + 函数能够访问的自由变量 = 闭包
  • 内部函数引用了外部函数的变量
  • 外部函数返回了内部函数

为什么需要闭包？

  • 数据私有化：创建私有变量
  • 状态保持：在回调中保存状态
  • 函数工厂：生成定制函数
  • 模块化：封装代码
