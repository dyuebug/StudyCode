📖 核心概念

什么是模块化？

模块化（Module）是将大型程序拆分成独立的、可复用的模块，每个模块负责一个功能。

为什么需要模块化？

  • 代码组织：按功能拆分，结构清晰
  • 作用域隔离：避免全局变量污染
  • 依赖管理：明确模块间的依赖关系
  • 代码复用：模块可以在多个项目中使用
  • 按需加载：提升性能

ES6模块 vs CommonJS

特性 ES6模块（import/export） CommonJS（require/module.exports）
环境 浏览器 + Node.js Node.js
加载 静态（编译时） 动态（运行时）
导出 export / export default module.exports / exports
导入 import require()
this undefined module对象
⚠️ 重要提示：
  • ES6模块必须在服务器环境运行（不能直接用file://协议）
  • HTML中使用 <script type="module">
  • 模块代码自动运行在严格模式
  • 每个模块有独立的作用域

💡 核心知识点

1. 导出方式（Export）

// 命名导出（可以有多个）
export const name = "value";
export function func() {}
export class MyClass {}

// 默认导出（只能有一个）
export default function() {}
export default class {}
export default "value";

// 混合导出
export const func1 = () => {};
export default class MyClass {}

2. 导入方式（Import）

// 导入命名导出
import { name, func } from './module.js';

// 导入默认导出
import MyClass from './module.js';

// 导入全部
import * as utils from './module.js';

// 重命名导入
import { name as myName } from './module.js';

// 只执行模块（不导入）
import './module.js';

// 动态导入（异步）
const module = await import('./module.js');
