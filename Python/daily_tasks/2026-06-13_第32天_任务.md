### 任务1：fetch 异步请求基础（预计60分钟）⭐⭐⭐⭐⭐
**文件**：`python_basics/75_fetch异步请求_详解.py`

**学习内容**：
1. **异步概念**
   - 同步 vs 异步的生活例子（餐厅点餐）
   - JavaScript 为什么需要异步（单线程 + 网络请求慢）

4. **实际示例**

**重点难点**：
- 异步的"等数据回来再处理"思想
- Promise 是什么（代表未来会返回的结果）
- fetch().then().then() 的链式调用顺序

## 💡 学习建议

1. **异步是难点**：多用生活例子理解
   - 同步：排队买票，前面的人不走你不能买
   - 异步：点餐后拿号，叫号了再取，期间可以玩手机

2. **fetch 返回 Promise**：
   - Promise 是"承诺书"，代表未来会返回的结果
   - .then() 是"拿到结果后做什么"
   - async/await 是更直观的异步写法

3. **前后端联动关键**：
   - 后端路由 = 前端 fetch 的 URL
   - Flask 返回 JSON = 前端 .json() 解析
   - 数据流向：Flask → JSON → fetch → DOM 渲染

4. **实践为主**：
   - 先跑通示例代码
   - 再自己修改参数测试
   - 最后独立写一个小功能
