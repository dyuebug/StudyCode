### 任务1：类方法和静态方法（预计30分钟）⭐⭐⭐⭐⭐
**文件**：`python_basics/42_类方法和静态方法_详解.py`

**学习内容**：
1. **三种方法的概念**
   - 实例方法：操作实例数据，第一个参数是self
   - 类方法：操作类数据，第一个参数是cls，使用@classmethod装饰
   - 静态方法：不操作实例或类数据，使用@staticmethod装饰

2. **类方法（@classmethod）**
   - 定义和使用
   - 第一个参数是cls（类本身）
   - 可以访问类属性
   - 常用于工厂方法（创建实例的替代方式）

3. **静态方法（@staticmethod）**
   - 定义和使用
   - 没有self或cls参数
   - 不能访问实例或类属性
   - 常用于工具函数

4. **使用场景**
   - 实例方法：需要访问实例数据
   - 类方法：需要访问类数据，或作为工厂方法
   - 静态方法：不需要访问实例或类数据，逻辑上属于这个类

**学习重点**：
- ⭐⭐⭐⭐⭐ 理解三种方法的区别
- ⭐⭐⭐⭐⭐ 掌握使用场景
- ⭐⭐⭐⭐ 理解装饰器的作用
- ⭐⭐⭐⭐ 掌握工厂方法模式

### 任务2：属性装饰器（预计30分钟）⭐⭐⭐⭐⭐
**文件**：`python_basics/43_属性装饰器_详解.py`

**学习内容**：
1. **@property装饰器**
   - 将方法转换为属性
   - 提供优雅的属性访问方式
   - 替代getter方法

2. **@属性名.setter装饰器**
   - 设置属性值
   - 可以添加验证逻辑
   - 替代setter方法

3. **@属性名.deleter装饰器**
   - 删除属性
   - 清理资源

4. **只读属性**
   - 只定义@property，不定义setter
   - 属性不可修改

5. **属性验证**
   - 在setter中添加验证逻辑
   - 确保数据有效性

**学习重点**：
- ⭐⭐⭐⭐⭐ 理解@property的作用
- ⭐⭐⭐⭐⭐ 掌握getter和setter的使用
- ⭐⭐⭐⭐ 掌握属性验证
- ⭐⭐⭐⭐ 理解只读属性

### 任务3：魔法方法（预计40分钟）⭐⭐⭐⭐⭐
**文件**：`python_basics/44_魔法方法_详解.py`

**学习内容**：
1. **字符串表示**
   - __str__()：用户友好的字符串表示（print时调用）
   - __repr__()：开发者友好的字符串表示（调试时使用）

2. **容器类型方法**
   - __len__()：返回长度（len()函数调用）
   - __getitem__()：索引访问（obj[key]）
   - __setitem__()：索引赋值（obj[key] = value）
   - __delitem__()：索引删除（del obj[key]）
   - __contains__()：成员测试（in运算符）

3. **运算符重载**
   - __add__()：加法（+）
   - __sub__()：减法（-）
   - __mul__()：乘法（*）
   - __truediv__()：除法（/）

4. **比较运算符**
   - __eq__()：等于（==）
   - __ne__()：不等于（!=）
   - __lt__()：小于（<）
   - __le__()：小于等于（<=）
   - __gt__()：大于（>）
   - __ge__()：大于等于（>=）

5. **其他常用魔法方法**
   - __init__()：初始化
   - __del__()：析构函数
   - __call__()：让对象可调用
   - __iter__()和__next__()：迭代器

**学习重点**：
- ⭐⭐⭐⭐⭐ 理解魔法方法的作用
- ⭐⭐⭐⭐⭐ 掌握常用魔法方法
- ⭐⭐⭐⭐ 理解运算符重载
- ⭐⭐⭐⭐ 让自定义类更加Pythonic
