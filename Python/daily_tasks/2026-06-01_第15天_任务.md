## 🎯 学习建议

1. **第三方库是 Python 生态的核心优势**
   - Python 之所以强大，很大程度上是因为丰富的第三方库
   - 几乎任何需求都能找到对应的第三方库
   - 学会使用第三方库能大大提高开发效率

2. **pip 是必须掌握的工具**
   - pip 是 Python 的包管理工具
   - 安装、卸载、更新第三方库都靠它
   - 学会使用 pip 是使用第三方库的前提

3. **虚拟环境很重要**
   - 不同项目可能需要不同版本的库
   - 虚拟环境隔离不同项目的依赖
   - 避免版本冲突和污染全局环境

4. **requests 和 pandas 是最常用的库**
   - requests：网络请求、API 调用
   - pandas：数据处理、数据分析
   - 这两个库在实际项目中使用频率极高

5. **学会查阅官方文档**
   - 第三方库功能丰富，不可能全部记住
   - 学会查阅官方文档和示例
   - 遇到问题先查文档，再搜索

## 💡 温馨提示

1. **第三方库需要安装**
   - 标准库无需安装，第三方库需要用 pip 安装
   - 第一次使用某个库前，记得先安装
   - 安装命令：`pip install 库名`

2. **网络连接很重要**
   - pip 安装包需要从网络下载
   - requests 发送请求需要网络连接
   - 确保网络畅通

3. **虚拟环境的使用**
   - 建议为每个项目创建独立的虚拟环境
   - 虚拟环境在项目目录下，不要提交到 git
   - 使用 requirements.txt 记录依赖

4. **requests 库很简单**
   - 比标准库 urllib 简单很多
   - API 设计优雅，易于使用
   - 是 Python 中最受欢迎的 HTTP 库

5. **pandas 功能强大**
   - 专门用于数据处理和分析
   - 提供了类似 Excel 的表格操作
   - 是数据科学的必备工具
