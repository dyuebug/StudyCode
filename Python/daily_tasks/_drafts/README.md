## 日志底稿的使用规则

1. 日志底稿不是学习日志，不能计入学习天数与时长。
2. 学习结束后复制为 `daily_logs/YYYY-MM-DD_第X天_日志.md`，填写真实时长、完成情况、问题与结果。
3. 不得把底稿中的“待填写”替换为猜测内容。
4. 底稿中的 `[ ]` 只有用户确认完成后才能改为 `[x]`。

## 统计口径

- 草案与底稿都不计入“已完成学习天数”“累计时长”“任务完成数”。
- 正式任务只证明“计划存在”，不证明“已经学习”。
