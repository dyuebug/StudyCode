## 💡 学习建议

1. **理解数据流向**（最重要）：
   ```
   前端表单 → fetch POST → Flask 接收 → 保存到列表
                                          ↓
   前端显示 ← DOM 渲染 ← fetch GET ← Flask 返回 JSON
   ```

2. **CORS 跨域**：
   - 浏览器安全机制，防止恶意网站
   - 前端(file://) 调用后端(localhost:5000) 算跨域
   - 用 flask-cors 一行解决：`CORS(app)`

3. **GET vs POST**：
   - GET：获取数据，参数在 URL
   - POST：提交数据，数据在 body
   - POST 需要设置 `Content-Type: application/json`

4. **调试技巧**：
   - 先用浏览器直接访问后端 API（GET）
   - 用控制台 Network 标签看请求详情
   - console.log 打印每一步的数据
