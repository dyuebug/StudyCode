### 任务1：RESTful API 设计详解（预计30分钟）⭐⭐⭐⭐⭐
**文件**：`python_basics/78_RESTful_API设计_详解.py`

**学习内容**：
1. **什么是 RESTful API**
   - REST 设计思想（资源导向）
   - URL 代表资源，HTTP 方法代表操作
   - 统一接口、无状态、可缓存

2. **四种 HTTP 方法（CRUD）**
   - GET：查询（Read）
   - POST：创建（Create）
   - PUT：更新（Update）
   - DELETE：删除（Delete）

3. **URL 设计规范**
   - 资源用名词复数：/api/messages
   - 操作用 HTTP 方法，不要动词：DELETE /api/messages/1（不是 /api/deleteMessage/1）
   - 路径参数：/api/messages/:id

4. **HTTP 状态码**
   - 200 OK：成功
   - 404 Not Found：资源不存在
   - 400 Bad Request：请求错误
   - 500 Internal Server Error：服务器错误

**重点难点**：
- REST 设计思想（资源导向）
- URL 设计规范（名词 vs 动词）
- 状态码的正确使用
