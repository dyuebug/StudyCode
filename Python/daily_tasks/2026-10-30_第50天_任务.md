### 任务2：编写最小代理配置（30 分钟）

**目标**：不修改生产配置，另建练习配置 `/tmp/nginx-practice.conf`。

参考结构：

```nginx
server {
    listen 80;
    server_name _;

    location /static/ {
        alias /srv/static/;
        expires 1h;
    }

    location / {
        proxy_pass http://backend:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

**完成标准**：配置能通过：

```bash
docker run --rm -v /tmp/nginx-practice.conf:/etc/nginx/conf.d/default.conf:ro nginx:1.27-alpine nginx -t
```

预期：`syntax is ok`、`test is successful`。

### 任务4：故障与限流验证（30 分钟）

**故障 1：后端未启动**

```bash
docker stop practice-backend
curl -I http://127.0.0.1:8088/
```

记录状态码，解释为什么是 502。

**故障 2：静态路径错误**

把 `alias` 改成不存在的目录，`nginx -s reload` 后访问 `/static/style.css`，记录 404 与日志。

**限流（可选）**

在练习配置中加入：

```nginx
limit_req_zone $binary_remote_addr zone=practice:10m rate=1r/s;
```

在 `location /` 中加入 `limit_req zone=practice burst=2 nodelay;`，用循环请求观察 503。

**完成标准**：能根据状态码和错误日志判断问题在 Nginx 还是后端。
