# 每日学习任务（daily_tasks）

## 目录约定

| 路径 | 含义 |
|---|---|
| `daily_tasks/YYYY-MM-DD_第X天_任务.md` | 当前有效任务，每个学习序号最多 1 份 |
| `daily_tasks/_模板_学习任务.md` | 新建任务时复制的模板 |
| `daily_tasks/_archive/` | 重复序号的历史任务，仅保留查阅，不参与统计 |
| `daily_tasks/_补记说明_第39_41_42天.md` | 有日志但无任务文件的说明 |

## 当前状态

- 有效任务序号：1～38、40、43～52。
- 第 39、41、42 天缺少任务文件，日志为补记，见说明文件。
- 第 47 天任务尚未勾选完成（10 项 `[ ]`）。
- 第 48～52 天任务于 2026-10-30 提前生成，状态为“正式任务（计划）”，不代表已完成；记录日期是生成日期，实际学习日期待定。
- 序号异常说明：按默认规则，下一有效序号应为 47；第 48～52 天是在用户明确确认后提前规划，文件内已注明，未覆盖或删除任何历史任务。

## 规则

1. 新建任务前先读取 `daily_logs/` 与 `daily_tasks/`，确定最大已用序号。
2. 新序号 = 最大已确认完成序号 + 1；存在冲突时先说明，不覆盖。
3. 任务中的 `[ ]` 只有用户确认完成后才能改为 `[x]`。
4. 重复文件移入 `_archive/`，并在归档 `README.md` 登记，不删除。
