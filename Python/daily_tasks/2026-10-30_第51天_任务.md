### 任务4：非 root 与数据持久化（30 分钟）

**验证用户**：

```bash
docker exec forum-test id
docker exec forum-test whoami
```

预期：不是 `root`。

**写入数据**：

```bash
docker exec forum-test python -c "
import sqlite3
conn = sqlite3.connect('/data/forum.db')
conn.execute(\"INSERT INTO users (username, password_hash) VALUES ('persist_user', 'x')\")
conn.commit()
print(conn.execute('SELECT COUNT(*) FROM users').fetchone()[0])
"
```

**重启容器后验证**：

```bash
docker restart forum-test
docker exec forum-test python -c "
import sqlite3
conn = sqlite3.connect('/data/forum.db')
print(conn.execute(\"SELECT username FROM users WHERE username='persist_user'\").fetchone())
"
```

**完成标准**：重启后仍能查到 `persist_user`，说明卷生效。

**清理**：

```bash
docker rm -f forum-test
docker volume rm forum-data
```
