**文件**：`python_basics/32_标准库_详解.py`

**学习内容**：
1. **标准库的概念**
   - 什么是标准库？
   - 为什么需要标准库？
   - 标准库的优势

2. **os 模块**
   - 文件路径操作（os.path.join、os.path.exists、os.path.dirname）
   - 目录操作（os.listdir、os.mkdir、os.rmdir）
   - 文件操作（os.remove、os.rename）
   - 环境变量（os.environ、os.getenv）

3. **datetime 模块**
   - 日期和时间对象（datetime.datetime、datetime.date、datetime.time）
   - 获取当前时间（datetime.now()）
   - 日期格式化（strftime）
   - 日期解析（strptime）
   - 时间差计算（timedelta）

4. **json 模块**
   - JSON 的概念
   - 序列化（json.dumps、json.dump）
   - 反序列化（json.loads、json.load）
   - 处理中文和缩进

**学习重点**：
- ⭐⭐⭐⭐⭐ 标准库是 Python 的强大武器，无需安装，开箱即用

## 💡 温馨提示

1. **标准库的概念可能一开始不太好理解**
   - 把它想象成 Python 自带的工具箱
   - 每个模块都是一个专门的工具

2. **os 模块的路径操作很重要**
   - 跨平台兼容性
   - 避免硬编码路径
   - 使用 os.path.join 拼接路径

3. **datetime 模块的格式化很实用**
   - strftime：将日期转换为字符串
   - strptime：将字符串转换为日期
   - 记住常用的格式符号

4. **json 模块是数据交换的标准**
   - API 接口常用 JSON 格式
   - 配置文件常用 JSON 格式
   - 注意处理中文编码
