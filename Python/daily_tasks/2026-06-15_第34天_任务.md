## 💡 学习建议

1. **理解持久化的价值**：
   - 内存数据：快但易失（重启丢失）
   - 磁盘数据：慢但持久（永久保存）
   - 权衡：重要数据必须持久化

2. **启动加载 + 操作保存模式**：
   ```python
   # 启动时：从文件加载到内存
   messages = load_messages()
   
   # 操作时：修改内存 + 保存到文件
   messages.append(new_msg)
   save_messages()
   ```

3. **异常处理很重要**：
   - 第一次运行：文件不存在 → 返回空列表
   - 文件损坏：JSON 解析失败 → 备份 + 重置
   - 权限问题：无法写入 → 提示用户

4. **测试要彻底**：
   - 添加留言 → 重启 → 验证
   - 多次重启测试
   - 检查 JSON 文件格式
