### 任务3：补一个 Node 测试任务（30 分钟）

**目标**：在 CI 中加入前端测试，但不破坏现有 Python 任务。

建议结构：

```yaml
  frontend-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: "22"
          cache: npm
          cache-dependency-path: web_projects/todo_app/package-lock.json
      - run: npm ci
        working-directory: web_projects/todo_app
      - run: npm test
        working-directory: web_projects/todo_app
```

**完成标准**：

- YAML 语法正确（可用 `python -c "import yaml; yaml.safe_load(open(...))"` 检查）。
- 本地等价命令 `npm ci && npm test` 通过。
- 说明 `npm ci` 与 `npm install` 的区别。

**注意**：修改 `.github/workflows/ci.yml` 属于真实代码变更，需在日志中记录。
