## 🎓 学习建议

### 1. 函数式编程思想
- 数组方法都是函数式编程的体现
- 核心：不改变原数组，返回新数据
- 好处：代码更清晰、更易测试、更少bug

### 2. 链式调用技巧
```javascript
// 传统写法
const numbers = [1, 2, 3, 4, 5];
const doubled = numbers.map(n => n * 2);
const filtered = doubled.filter(n => n > 5);
const sum = filtered.reduce((a, b) => a + b, 0);

// 链式调用（推荐）
const sum = numbers
  .map(n => n * 2)
  .filter(n => n > 5)
  .reduce((a, b) => a + b, 0);
```

### 3. reduce的理解
- reduce最难理解，但最强大
- 核心：累加器（accumulator）+ 当前值（current）
- 用途：求和、统计、分组、扁平化等

### 4. ES6+的实用性
- 解构赋值：简化变量声明
- 展开运算符：复制数组/对象、合并数据
- 箭头函数：简化代码、解决this问题
- 这些特性是现代JavaScript的标配
