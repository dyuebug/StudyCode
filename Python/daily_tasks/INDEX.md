## 三、命名与状态规则

1. 文件名格式：`YYYY-MM-DD_第X天_任务.md`。
2. 日期是生成日期；实际学习日期以开始当天为准。
3. 任务项保持 `[ ]`，只有用户确认完成后才改为 `[x]`。
4. 任务与日志一一对应；日志可以补记，但必须在补记说明中注明。
5. 新增任务前先运行审计工具，确认序号未重复。
