## 💡 学习建议

1. **理解数据库的价值**：
   - JSON 文件：简单、够用、小数据
   - 数据库：强大、复杂查询、大数据、并发安全
   - 留言板：100条以内 JSON 够用，1000条以上数据库更好

2. **SQL 语法记忆**：
   - SELECT：查
   - INSERT：增
   - UPDATE：改
   - DELETE：删
   - WHERE：条件

3. **参数化查询必须用**：
   ```python
   # ❌ 危险：SQL 注入
   cursor.execute(f"SELECT * FROM users WHERE name = '{name}'")
   
   # ✅ 安全：参数化查询
   cursor.execute("SELECT * FROM users WHERE name = ?", (name,))
   ```

4. **资源管理**：
   - 打开连接 → 操作 → 提交 → 关闭
   - 可以用 with 语句自动管理
