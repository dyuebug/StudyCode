## 📝 具体任务

### 任务1：Bootstrap 基础入门（预计60分钟）⭐⭐⭐⭐⭐

**学习内容**：

1. **Bootstrap 简介**
   - 什么是Bootstrap？最流行的CSS框架
   - 为什么使用Bootstrap？快速开发、响应式、组件丰富
   - Bootstrap版本（推荐Bootstrap 5）

2. **引入Bootstrap**
   - CDN方式（最简单）
   - 下载本地文件
   - npm安装（高级）

3. **栅格系统（Grid System）**
   - 12列布局
   - 容器：.container、.container-fluid
   - 行：.row
   - 列：.col、.col-md-6等
   - 响应式断点（xs、sm、md、lg、xl）

4. **常用工具类**
   - 间距：m-3（margin）、p-3（padding）
   - 文本：text-center、text-primary
   - 背景：bg-primary、bg-light
   - 边框：border、rounded

**学习方法**：
- 访问Bootstrap官网：https://getbootstrap.com/
- 阅读快速入门文档
- 在浏览器中实验

---

### 任务2：Bootstrap 常用组件（预计60分钟）⭐⭐⭐⭐⭐

**学习内容**：

1. **按钮（Buttons）**
   - 样式：btn-primary、btn-success、btn-danger
   - 大小：btn-sm、btn-lg
   - 轮廓按钮：btn-outline-primary

2. **卡片（Cards）**
   - 结构：card、card-header、card-body、card-footer
   - 用途：展示内容块（如留言）

3. **表单（Forms）**
   - form-control：美化输入框
   - form-label：标签样式
   - form-text：帮助文本

4. **导航栏（Navbar）**
   - navbar：导航容器
   - navbar-brand：品牌/标题
   - navbar-nav：导航链接

5. **警告框（Alerts）**
   - alert、alert-success、alert-danger
   - 用途：显示提示信息

**学习方法**：
- 浏览Bootstrap组件文档
- 复制示例代码实验
- 理解class命名规则

### 任务3：用Bootstrap美化留言板（预计60分钟）⭐⭐⭐⭐

**改造内容**：

创建 `index_v5_bootstrap版.html`

1. **引入Bootstrap**
   ```html
   <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
   ```

2. **页面布局**
   - 使用.container包裹内容
   - 使用.row和.col布局
   - 响应式设计（手机和电脑都好看）

3. **表单美化**
   - 使用.form-control美化输入框
   - 使用.form-label美化标签
   - 使用.btn美化按钮

4. **留言展示**
   - 使用.card展示每条留言
   - 使用.card-header显示姓名和时间
   - 使用.card-body显示内容
   - 使用.btn-sm美化删除按钮

5. **整体美化**
   - 添加导航栏（navbar）
   - 使用间距工具类（m-3、p-3）
   - 使用颜色类（bg-light、text-primary）

**效果目标**：
- ✅ 界面美观专业
- ✅ 响应式（手机端自适应）
- ✅ 无需自己写CSS
- ✅ 用户体验提升

## 💡 学习建议

1. **理解响应式设计**
   - 一套代码，多端适配
   - 手机、平板、电脑都好看
   - 核心：栅格系统 + 断点

2. **Bootstrap的价值**
   - 快速开发：不用自己写CSS
   - 统一风格：遵循设计规范
   - 响应式：自动适配屏幕
   - 组件丰富：常用组件开箱即用

3. **学习技巧**
   - 先学栅格系统（布局）
   - 再学常用组件（内容）
   - 最后学工具类（细节）
   - 多看官方示例，直接复制修改

4. **实战导向**
   - 边学边用
   - 从留言板开始
   - 不求完美，先能用
   - 后续慢慢优化
