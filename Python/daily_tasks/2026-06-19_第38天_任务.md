## 💡 学习建议

1. **理解游标（cursor）**：
   - 游标 = 数据库操作的"遥控器"
   - 连接 = 打开数据库
   - 游标 = 执行SQL、获取结果

2. **commit() 很重要**：
   - INSERT/UPDATE/DELETE 后必须 commit()
   - 不commit，修改不生效
   - SELECT 不需要 commit

3. **用 with 语句**：
   ```python
   with sqlite3.connect('db.db') as conn:
       cursor = conn.cursor()
       # 操作...
   # 自动commit和close
   ```

4. **错误处理**：
   ```python
   try:
       conn = sqlite3.connect('db.db')
       # 操作...
       conn.commit()
   except Exception as e:
       conn.rollback()
       print(f"错误：{e}")
   finally:
       conn.close()
   ```
