# 测试数据目录说明

仓库根目录下的 `test_source/`、`test_batch/`、`test_backup/`、`test_data/`、`test_restore/` 是第 57～61 天学习“文件批量处理、压缩备份、日志分析”时生成的**运行时测试数据**，不是项目源码，也不是学习日志。

| 目录 | 生成来源 | 内容 | 是否可删除 |
|---|---|---|---|
| `test_source/` | `57_文件批量处理工具.py` | 4 个示例文本文件 | 可删除，重新运行脚本可再生成 |
| `test_batch/` | `57_文件批量处理工具.py` | 批量处理后的 4 个文件 | 可删除 |
| `test_backup/` | `59_数据备份工具.py` | 备份元数据与两个 zip | 可删除；zip 已被 `.gitignore` 排除 |
| `test_restore/` | `59_数据备份工具.py` | 恢复出的 3 个文件 | 可删除 |
| `test_data/` | `55_日志分析工具.py` | 示例日志 `sample.log` | 可删除 |
| `monitor_logs/` | `61_系统监控工具.py` | 运行时输出的监控日志目录 | 可删除 |

## 约定

- 这些目录不参与 pytest 收集。
- 不把运行时数据当作学习成果或项目产物。
- 如需保留一次实验记录，复制关键输出到学习日志，而不是长期堆积临时文件。
