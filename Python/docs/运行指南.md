## 7. 周报生成

```bash
python_basics/.venv/Scripts/python.exe scripts/generate_weekly_reports.py
```

输出：

- 单周文件：`weekly_reports/YYYY-Www.md`
- 索引：`weekly_reports/INDEX.md`

脚本只统计 `daily_logs/` 中已记录的内容。新增日志后重新运行即可覆盖更新；手工修改周报会在下次生成时丢失。

### 学习日志生成

```bash
# 检查第 47～52 天是否都有日志（不写文件）
python_basics/.venv/Scripts/python.exe scripts/generate_learning_logs.py --check

# 为缺失的任务生成示例日志（已存在的真实日志不会被覆盖）
python_basics/.venv/Scripts/python.exe scripts/generate_learning_logs.py --write --days 47-52
```

生成器只输出带“示例日志（非真实学习记录，不计入统计）”标记的文件，任务项保持 `[ ]`，不伪造时长与完成度。真实学习结束后，应删除示例标记并按实际结果重写。

## 9. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `ModuleNotFoundError: forum_project` | 不在仓库根目录 | `cd` 到仓库根目录再执行 |
| `ModuleNotFoundError: flask` | 未使用虚拟环境 | 显式调用 `.venv` 中的 Python |
| 端口被占用 | 已有实例运行 | `ss -tlnp` 或 `netstat -ano` 查找并停止 |
| ES Module 报 CORS 错误 | 用 `file://` 打开 | 改用 `http.server` |
| 测试数据库被污染 | 未使用临时库 | 测试夹具已使用 `tmp_path`，检查是否自行改了配置 |
