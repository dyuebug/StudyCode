## 📖 学到的知识点

### 迭代器基础

1. **Iterator trait**：
   - 核心方法：`fn next(&mut self) -> Option<Self::Item>`
   - 每次调用返回 Some(item) 或 None（迭代结束）
   - 所有其他方法都基于 next 实现
   - for 循环是迭代器的语法糖

2. **迭代器的本质**：
   - 实现了 Iterator trait 的类型
   - 可以逐个访问集合中的元素
   - Rust 中几乎所有集合都实现了迭代器

### 三种迭代方法

3. **iter() - 不可变引用**：
   - 返回：`Iterator<Item = &T>`
   - 元素类型：&T（不可变引用）
   - 所有权：不消耗集合，集合仍可用
   - 使用场景：只需读取元素

4. **into_iter() - 获取所有权**：
   - 返回：`Iterator<Item = T>`
   - 元素类型：T（拥有所有权）
   - 所有权：消耗集合，集合不再可用
   - 使用场景：需要移动元素、集合不再使用

5. **iter_mut() - 可变引用**：
   - 返回：`Iterator<Item = &mut T>`
   - 元素类型：&mut T（可变引用）
   - 所有权：可变借用集合，可以修改元素
   - 使用场景：需要修改元素

### 消费器（Consumers）

6. **消费器的特点**：
   - 消耗迭代器，产生最终结果
   - 调用 next() 直到返回 None
   - 触发实际的迭代执行
   - 迭代器被消耗，不能再使用

7. **常用消费器**：
   - `collect()`：收集到集合（Vec、HashMap等）
   - `sum()`、`product()`：求和、求积
   - `fold()`：折叠操作（累积计算）
   - `count()`：计数
   - `any()`、`all()`：判断是否有/全部满足条件

### 适配器（Adapters）

8. **适配器的特点**：
   - 产生新的迭代器
   - 不会立即执行（惰性求值）
   - 可以链式调用多个适配器
   - 必须调用消费器才会实际迭代

9. **常用适配器**：
   - `map()`：转换元素
   - `filter()`：过滤元素
   - `take()`：取前N个
   - `skip()`：跳过前N个
   - `enumerate()`：添加索引
   - `zip()`：合并两个迭代器

### 高级概念

10. **惰性求值（Lazy Evaluation）**：
    - 适配器只是构建操作链，不会立即执行
    - 调用消费器时才实际迭代
    - 好处：性能优化、避免不必要的计算、节省内存

11. **链式调用**：
    - 多个适配器可以链式组合
    - 模式：`collection.iter().adapter1().adapter2().consumer()`
    - 优势：代码简洁、可读性高、表达力强

12. **零成本抽象**：
    - 迭代器编译后和手写循环性能完全一样
    - 编译器会内联优化
    - Rust 惯用写法：迭代器 > 手写循环

### 实用技巧

13. **选择指南**：
    - 只读集合？→ `iter()`
    - 修改元素？→ `iter_mut()`
    - 消耗集合？→ `into_iter()`
    - 转换数据？→ `map()`
    - 筛选数据？→ `filter()`
    - 聚合数据？→ `fold()`、`sum()`

14. **迭代器与闭包的配合**：
    - map、filter 等方法接受闭包作为参数
    - 闭包可以捕获环境
    - 这是函数式编程的典型模式

## 💭 今日心得

迭代器是 Rust 最常用、最强大的特性之一，与闭包配合使用，是 Rust 函数式编程的精髓。

**关键理解**：
- 迭代器不仅仅是遍历工具，它是一种编程范式
- 三种迭代方法对应所有权系统的三种模式：&T、T、&mut T
- 消费器和适配器的分离设计非常优雅：适配器构建操作链（惰性），消费器触发执行

**设计哲学**：
- **零成本抽象**：迭代器性能和手写循环完全一样
- **组合性**：通过链式调用组合多个操作
- **惰性求值**：只在需要时才计算，避免浪费
- **类型安全**：编译期保证正确性

**实用价值**：
- 代码更简洁：用声明式风格描述"做什么"而不是"怎么做"
- 可读性更好：`map`、`filter` 等方法名直接表达意图
- 更安全：编译器保证不会越界、不会忘记更新索引
- 更灵活：可以轻松组合各种操作

**与其他语言对比**：
- Python 的列表推导式：`[x*2 for x in list if x > 10]`
- Rust 的迭代器链：`list.iter().filter(|x| *x > 10).map(|x| x*2).collect()`
- Rust 的优势：零成本抽象 + 类型安全 + 所有权保证

迭代器体现了 Rust 的核心价值：
1. 高性能：零成本抽象，编译后和手写循环一样快
2. 高安全：类型系统保证不会出错
3. 高表达力：函数式风格，代码简洁清晰

学完迭代器后，对 Rust 函数式编程特性有了完整的理解（闭包 + 迭代器），这两者的结合非常强大。迭代器是 Rust 日常开发中最常用的特性，务必熟练掌握。
