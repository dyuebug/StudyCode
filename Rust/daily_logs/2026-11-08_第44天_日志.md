## 📖 学到的知识点

### 1. 索引的职责是导航，不是叙述

写 `Rust/README.md` 时最容易犯的错，是把 `学习总结.md` 复制一遍。
判据很简单：**这段话删掉后，读者还能不能找到该看的文件？**
能——那就是叙述，该留在总结里；不能——那才是索引该有的东西。

DRY 在这里不是"少写"，而是"同一件事只有一个权威位置"。
所以 README 里写"叙事版见 `学习总结.md`"，而不是重述。

### 2. 抽象要按"怎么发现它没生效"分组，不按工具分组

10 个静默失败案例分布在 Docker、YAML、Shell、cargo、C# 生态的路径转换、
Windows 文件句柄——按工具分组会得到 10 个互不相干的小故事，下次遇到第 11 种工具就归不了类。

按"**你是怎么发现它的**"分组才有复用价值：

| 发现方式 | 对应防御 |
|---|---|
| 输出是空的 | 命令前后各打标记，确认被执行过 |
| 快得反常 | 对比历史耗时，解释不了的当作没执行 |
| 通过了但什么都没证明 | 断言数量 / 产物内容，不只断言退出码 |
| 文件在、格式对、没效果 | 查权威发现规则，不靠目录结构猜 |

这四行能套到任何工具上，那 10 个故事只是它们的实例。

### 3. 检查必须能被证伪——"这条断言会不会红"

清单里的每一条防御都要能回答：**我能不能故意造出它该拦的东西，让它红一次？**
不会红的检查等于没有检查（第 43 天的 `cargo test` 0 用例就是活例：
它"通过"了，但它什么也没检查）。

这条反过来也是筛选器：写不出"怎么让它红"的措施，多半是空话，删掉。

### 4. 证据分级：实测 / 查证 / 推定

本次统一成三档并写进文档：

- **【实测】**：有运行输出，能贴出退出码或日志
- **查证**：来自官方文档（如 GitHub 只读仓库根 `.github/workflows/`）
- **【推定】**：估算值，不能当证据用

关键结论：**没有来源的"实测"，比没有数据更糟。**
前者会让人停止怀疑，后者至少还知道自己不知道。

### 5. 已知局限写得越具体，整份文档越可信

README §7 列了 5 条：CI 从未云端运行、时长为推定、第 27–32 天是模板、
第 38 天动手项 A–D 未做、所有项目都是单机无鉴权。

写这些不舒服，但它们决定了读者对前面 6 节的信任度——
**一份只讲成绩的作品集，读者会默认它藏了东西；一份主动交代边界的，读者才愿意信剩下的部分。**

### 6. 文档过时得比代码快，一致性必须主动核对

收口时一次核对就揪出三处历史不一致（详见问题表）。
文档不会自己保持一致：`进度统计.md` 停在 6 月的结论，
`README.md` 写的是第 43 天的数字，`剩余课程规划.md` 的清单少一阶段。
三处各自都"没错"，放在一起就矛盾了。

对策不是"以后注意"，而是**把核对写进流程**：
每次「学习结束」固定核对 `CLAUDE.md` / `进度统计.md` / `剩余课程规划.md` 三处。

### 7. 自己给的标签也会撒谎

复核仓库规模时，我写了一条命令 `ls -d */ | wc -l` 并把它 echo 成"项目目录数：20"。
实际输出 20 是真的，但它统计的是 `Rust/` 下**所有**子目录
（`daily_logs`、`daily_tasks`、`knowledge_base`、`weekly_reports` 都在里面），
而项目数是 10。

数字没错，**标签错了**。这和清单第 7 条（测量工具自己丢数据）是同一类问题：
读数正确不等于含义正确。所以本次日志里只写"24 个 .rs"这种定义无歧义的量。

## 💭 今日心得

今天没有新知识，全是**整理**，但整理暴露出一个比知识更麻烦的问题：**数字和结论会过期。**

三处不一致都不是谁写错了——每一处都曾经是对的。
`进度统计.md` 的「异步编程：待学习」是第 13 天的真实状态，
`README.md` 的 43 天是第 43 天的真实状态。它们只是没跟着变。
而文档最危险的地方恰好在这里：**它不会报错，它只会安静地给出过时的答案。**

这和这周反复撞上的「静默失败」是同一个内核——
一个该更新的东西没更新，而我们默认「没报错 = 还是对的」。

所以这份收口真正的产出不是两份文档，而是把**核对**变成了流程的一步：
以后每次「学习结束」，三处状态必须互相读一遍。

第二个收获是"24 个 .rs"这个数字。它是我在复核时唯一敢直接写进文档的规模数字，
因为它的定义没有歧义。而"20 个目录"虽然也是实测输出，
标签一错就变成了误导——**数据的可信度不只取决于它是不是量的，还取决于标签是不是对的。**
