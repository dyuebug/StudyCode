## 📖 学到的知识点

### 闭包基础

1. **闭包语法**：
   - 基本形式：`|param| expression`
   - 多参数：`|x, y| x + y`
   - 代码块：`|x| { let y = x + 1; y * 2 }`
   - 类型标注：`|x: i32| -> i32 { x + 1 }`

2. **闭包 vs 函数**：
   - 闭包可以捕获环境，函数不能
   - 闭包有类型推断，函数必须显式标注类型
   - 每个闭包都有唯一的匿名类型
   - 闭包适合短小逻辑，函数适合通用逻辑

3. **类型推断**：
   - 闭包的参数和返回值类型通常可以省略
   - 第一次调用时确定类型
   - 后续调用必须使用相同类型
   - 编译器为每个闭包生成唯一的匿名类型

### 环境捕获机制

4. **不可变借用捕获**（默认）：
   - 闭包捕获环境变量的不可变引用（&T）
   - 可以读取环境变量
   - 不能修改环境变量
   - 可以有多个闭包同时捕获
   - 实现 Fn trait

5. **可变借用捕获**：
   - 当闭包修改环境变量时自动使用
   - 捕获环境变量的可变引用（&mut T）
   - 可以修改环境变量
   - 同一时间只能有一个可变借用
   - 闭包本身需要声明为 mut
   - 实现 FnMut trait

6. **获取所有权（move）**：
   - 使用 move 关键字强制闭包获取所有权
   - 环境变量被移动到闭包中
   - 原环境不能再使用这些变量
   - 实现 FnOnce trait（或 Fn/FnMut）

### move 关键字

7. **move 的行为**：
   - 对 Copy 类型（如 i32）：复制值，原变量仍可用
   - 对非 Copy 类型（如 Vec、String）：移动所有权，原变量不可用

8. **move 的使用场景**：
   - 闭包在新线程中执行（必须用 move）
   - 闭包生命周期超过环境变量
   - 需要明确获取所有权

### 高级概念

9. **Fn trait 族**（初步理解）：
   - `Fn`：可被多次调用，不可变借用环境
   - `FnMut`：可被多次调用，可变借用环境
   - `FnOnce`：只能被调用一次，获取环境所有权
   - 继承关系：`Fn: FnMut: FnOnce`

10. **闭包的优势**：
    - 代码简洁，无需定义独立函数
    - 类型推断，减少冗余类型标注
    - 可以捕获环境，灵活性高
    - 零成本抽象，性能和手写函数一样

## 💭 今日心得

闭包是 Rust 函数式编程的核心特性，它让代码更加简洁和表达力强。

**关键理解**：
- 闭包不是简单的匿名函数，它的核心特性是**能够捕获环境**
- Rust 的闭包非常智能：它会根据闭包内部的使用自动选择最小权限的捕获方式
- 三种捕获方式对应三种使用场景：只读、修改、移动

**设计哲学**：
- **零成本抽象**：闭包编译后性能和手写函数完全一样
- **内存安全**：借用检查器保证闭包捕获的安全性
- **灵活性**：三种捕获方式提供不同的权限选择

**实用技巧**：
- 默认情况下让编译器自动选择捕获方式
- 只有在多线程或生命周期需要时才使用 move
- 闭包特别适合与迭代器配合使用（如 map、filter）

闭包体现了 Rust "灵活性与安全性兼得" 的设计理念：
- 通过 Fn/FnMut/FnOnce 三个 trait 提供不同权限
- 通过借用检查器保证内存安全
- 通过类型推断减少代码冗余

理解闭包后，对 Rust 函数式编程特性有了更深的认识，也为下一步学习迭代器打下了基础。

### 学习重点
- **Iterator trait**：`fn next(&mut self) -> Option<Self::Item>`
- **三种迭代方法**：
  - `iter()`：不可变引用迭代
  - `into_iter()`：获取所有权
  - `iter_mut()`：可变引用迭代
- **消费器 vs 适配器**：
  - 消费器：消耗迭代器，产生结果（collect、sum、fold）
  - 适配器：产生新的迭代器（map、filter、take）
- **惰性求值**：迭代器适配器是惰性的，必须调用消费器才执行
- **零成本抽象**：迭代器和手写循环性能一样
