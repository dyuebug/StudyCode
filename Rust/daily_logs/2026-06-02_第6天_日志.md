### 学习重点

1. **切片的本质**
   - 切片 = 指针 + 长度
   - 切片不拥有数据
   - 切片遵循借用规则

2. **&str vs String**
   
   | 特性 | String | &str |
   |------|--------|------|
   | 所有权 | 拥有数据 | 引用数据 |
   | 可变性 | 可变 | 不可变 |
   | 存储 | 堆 | 任意位置 |
   | 场景 | 需要修改 | 函数参数 |

3. **生命周期的作用**
   - 防止悬垂引用
   - 确保引用有效
   - 编译时检查

4. **生命周期注解语法**
   ```rust
   fn foo<'a>(x: &'a str) -> &'a str
   struct Foo<'a> { x: &'a str }
   ```
