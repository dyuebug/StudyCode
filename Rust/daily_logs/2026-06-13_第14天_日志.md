## 📖 学到的知识点

1. **泛型（Generics）**：用 `<T>` 代表任意类型，实现代码复用
2. **泛型函数**：`fn largest<T: PartialOrd + Copy>(list: &[T]) -> T`
3. **泛型结构体**：`struct Point<T> { x: T, y: T }`，多个泛型参数 `<T, U>`
4. **泛型方法**：`impl<T> Point<T> { fn x(&self) -> &T { &self.x } }`
5. **Trait 定义**：`trait Summary { fn summarize(&self) -> String; }`
6. **Trait 实现**：`impl Summary for NewsArticle { ... }`
7. **Trait 默认方法**：trait 可以提供默认实现，类型可选择覆盖
8. **Trait 约束（Trait Bound）**：`<T: PartialOrd>` 限制泛型必须实现某些能力
9. **多个 Trait 约束**：`<T: Display + Clone>` 用 `+` 连接
10. **where 子句**：复杂约束时更清晰的语法
11. **impl Trait 返回类型**：返回"实现了 Trait 的某种类型"，但只能返回单一具体类型
12. **零成本抽象**：泛型在编译期单态化，运行时零开销
13. **静态分发 vs 动态分发**：泛型（编译期）vs trait 对象（运行时）
14. **孤儿规则**：trait 或类型至少一个在当前 crate

## 💭 今日心得

泛型与 trait 是 Rust 类型系统的精华。通过泛型实现代码复用，通过 trait 约束保证类型安全，两者结合让代码既灵活又高效。零成本抽象的设计理念非常优雅——泛型代码编译后和手写代码性能完全一样，这是 Rust 的核心优势之一。

特别印象深刻的是 trait 约束的作用：`<T: PartialOrd>` 不仅是语法糖，它在编译期就保证了类型具有比较能力，避免了运行时错误。孤儿规则虽然有些限制，但防止了不同 crate 之间的冲突，体现了 Rust 的深思熟虑。

完成12道练习题后，对泛型和 trait 的理解更深入了，能够灵活运用它们解决实际问题。
