## 📖 学到的知识点

### Actix-web 框架核心

1. **HttpServer 创建和配置**：
   ```rust
   HttpServer::new(move || {
       App::new()
           .app_data(web::Data::new(state.clone()))
           .route("/todos", web::get().to(handlers::get_all))
   })
   .bind(("127.0.0.1", 8888))?
   .run()
   .await
   ```
   - HttpServer::new 接受闭包（工厂函数）
   - 每个工作线程调用闭包创建 App
   - move 关键字捕获外部变量

2. **App 实例配置**：
   ```rust
   App::new()
       .app_data(web::Data::new(state))  // 注入状态
       .route(path, handler)              // 配置路由
   ```
   - app_data() 注入共享状态
   - route() 配置路由规则
   - 每个线程独立的 App 实例

3. **异步 Handler 函数**：
   ```rust
   pub async fn get_all(state: web::Data<AppState>) -> impl Responder {
       // 处理逻辑
       HttpResponse::Ok().json(response)
   }
   ```
   - 必须是 async fn
   - 参数通过 Extractor 自动注入
   - 返回 impl Responder

4. **web::Data<T> 状态提取器**：
   ```rust
   state: web::Data<AppState>
   ```
   - Actix-web 自动注入
   - 内部是 Arc<T>，线程安全
   - 通过 .app_data() 传入

5. **web::Json<T> JSON 提取器**：
   ```rust
   new_todo: web::Json<CreateTodo>
   ```
   - 自动解析请求体
   - 自动反序列化为结构
   - 解析失败返回 400

### 状态管理模式

6. **Arc<Mutex<Vec<Todo>>> 组合**：
   ```rust
   pub type AppState = Arc<Mutex<Vec<Todo>>>;
   ```
   - Vec<Todo>: 存储数据
   - Mutex<T>: 线程安全（互斥锁）
   - Arc<T>: 多线程共享（原子引用计数）

7. **为什么需要这个组合？**
   - Web 服务器是多线程的
   - 多个请求可能同时访问数据
   - Mutex 防止数据竞争
   - Arc 允许多所有者

8. **Mutex 锁的使用**：
   ```rust
   let mut todos = state.lock().unwrap();  // 获取锁
   todos.push(todo);                        // 修改数据
   // 锁守卫离开作用域自动释放
   ```

9. **为什么要 clone()？**
   ```rust
   let todos_clone = todos.clone();
   ```
   - 锁守卫不能跨 .await 点
   - 克隆数据后立即释放锁
   - 减少锁持有时间

### 数据模型设计

10. **Todo 结构设计**：

11. **CreateTodo 请求结构**：

    ```rust
    }
    ```
    - 泛型支持任意数据类型
    - 统一的响应格式

### ID 生成策略

18. **自增 ID 实现**：
    ```rust
    let new_id = todos.iter()
        .map(|t| t.id)
        .max()
        .unwrap_or(0) + 1;
    ```
    - iter() 遍历所有任务
    - map() 提取 id 字段
    - max() 找到最大 id
    - unwrap_or(0) 处理空列表
    - +1 生成新 id
