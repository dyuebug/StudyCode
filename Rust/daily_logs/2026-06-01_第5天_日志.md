### 学习重点

1. **切片是引用的特殊形式（核心！）**
   - 切片 = 指针 + 长度
   - 切片不拥有数据，只是借用
   - 切片遵循借用规则
   - 理解切片的内存布局

2. **&str vs String（重要！）**
   
   | 特性 | String | &str |
   |------|--------|------|
   | 所有权 | 拥有数据 | 引用数据 |
   | 可变性 | 可变 | 不可变 |
   | 存储位置 | 堆 | 可以在堆/栈/静态区 |
   | 使用场景 | 需要修改字符串 | 函数参数、只读 |
   | 转换 | &s 或 s.as_str() | s.to_string() |

3. **生命周期注解（核心！）**
   - 生命周期是引用有效的作用域
   - 生命周期注解描述引用之间的关系
   - 生命周期注解不改变实际生命周期
   - 编译器通过生命周期防止悬垂引用

4. **为什么需要生命周期注解**
   - 函数返回引用时，编译器需要知道返回值与哪个参数相关
   - 结构体包含引用时，需要说明引用的生命周期
   - 帮助编译器验证引用的有效性

5. **生命周期注解语法**
   ```rust
   // 函数
   fn longest<'a>(x: &'a str, y: &'a str) -> &'a str
   
   // 结构体
   struct Foo<'a> { x: &'a str }
   
   // 多个生命周期
   fn foo<'a, 'b>(x: &'a str, y: &'b str) -> &'a str
   ```

6. **编译器错误信息是最好的老师**
   - Rust编译器的错误信息非常详细
   - 错误信息会指出问题所在
   - 学会读懂错误信息是学习Rust的关键
   - 按照编译器的建议修复错误
