## 📖 学到的知识点

### 三库组合实战

1. **clap 子命令实现**：
   ```rust
   #[derive(Subcommand)]
   enum Commands {
       Get { city: String, verbose: bool },
       History { limit: usize },
       Clear,
   }
   ```
   - 使用 enum 定义子命令
   - 每个子命令有独立的参数
   - 类型安全的命令结构

2. **子命令匹配处理**：
   ```rust
   match cli.command {
       Commands::Get { city, verbose } => { /* ... */ }
       Commands::History { limit } => { /* ... */ }
       Commands::Clear => { /* ... */ }
   }
   ```
   - 模式匹配解构参数
   - 编译期类型检查
   - 清晰的代码结构

3. **参数注解高级用法**：
   ```rust
   #[arg(short, long, default_value_t = 10)]
   limit: usize,
   ```
   - 短选项和长选项
   - 默认值设置
   - 类型自动转换

4. **命令描述**：
   ```rust
   #[command(name = "weather")]
   #[command(about = "🌤️  天气查询 CLI 工具")]
   #[command(version)]
   ```
   - 程序名称
   - 描述信息
   - 版本信息

### 复杂数据结构处理

9. **嵌套结构定义**：

## 💭 今日心得

### 关于三库组合

**这是 Rust CLI 开发的黄金组合！**

**完美的分工**：
- **clap**：用户界面层 —— 处理命令行输入
- **reqwest**：网络通信层 —— 处理 HTTP 请求
- **serde**：数据转换层 —— 处理 JSON 数据

**数据流**：
```
用户输入
  ↓ (clap 解析)
命令和参数
  ↓ (reqwest 请求)
API 响应（JSON）
  ↓ (serde 反序列化)
Rust 结构体
  ↓ (业务逻辑)
处理和显示
  ↓ (serde 序列化)
保存到文件
```

每个库都在自己的层次发挥作用，配合完美！

### 关于子命令

**子命令让 CLI 更专业！**

**对比**：

**传统方式**：
```bash
myapp --get Beijing
myapp --history
myapp --clear
```
- 参数混乱
- 不易扩展

**子命令方式**：
```bash
myapp get Beijing
myapp history
myapp clear
```
- 清晰直观
- 类似 git 的体验
- 易于扩展

**实现简单**：
```rust
enum Commands {
    Get { /* ... */ },
    History { /* ... */ },
    Clear,
}
```
- 用 enum 就能实现
- 类型安全
- 编译期检查
