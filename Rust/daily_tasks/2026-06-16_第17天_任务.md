## 🎯 学习重点

1. **Iterator trait**：
   - 核心方法：`fn next(&mut self) -> Option<Self::Item>`
   - 返回 Some(item) 或 None（迭代结束）
   - 其他所有方法都基于 next 实现

2. **三种迭代方法**：
   - `iter()`：`&T`，不可变引用，不消耗集合
   - `into_iter()`：`T`，获取所有权，消耗集合
   - `iter_mut()`：`&mut T`，可变引用，可修改元素

3. **消费器 vs 适配器**：
   - **消费器**：消耗迭代器，产生最终结果
     - `collect()`：收集到集合
     - `sum()`、`product()`：求和、求积
     - `fold()`、`reduce()`：折叠操作
   - **适配器**：产生新的迭代器（惰性）
     - `map()`：映射转换
     - `filter()`：过滤元素
     - `take()`、`skip()`：取前N个、跳过N个
     - `enumerate()`：添加索引

4. **惰性求值**：
   - 适配器不会立即执行
   - 必须调用消费器才会实际执行
   - 好处：性能优化，避免不必要的计算

5. **链式调用**：
   - 多个适配器可以链式组合
   - 最后调用消费器触发执行
   - 例：`vec.iter().map(|x| x * 2).filter(|x| x > 10).collect()`

6. **零成本抽象**：
   - 迭代器编译后和手写循环性能一样
   - 编译器会内联优化
   - Rust 惯用写法：迭代器 > 手写循环

## 💡 学习建议

1. **理解惰性求值**：
   - 适配器只是构建操作链，不会立即执行
   - 调用消费器时才会真正迭代
   - 这是性能优化的关键

2. **迭代器 vs for 循环**：
   - 迭代器更简洁、更表达力强
   - 性能一样（零成本抽象）
   - Rust 社区推荐用迭代器

3. **与闭包配合**：
   - map、filter 等方法接受闭包作为参数
   - 闭包可以捕获环境
   - 这是函数式编程的典型模式

4. **常见模式**：
   - 转换：`map`
   - 过滤：`filter`
   - 聚合：`fold`、`sum`
   - 收集：`collect`
