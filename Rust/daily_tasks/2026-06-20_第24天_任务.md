### 任务2：了解 Actix-web 框架（核心任务）⭐⭐⭐⭐⭐

**预计时长**：1小时

**学习内容**：

#### 2.1 Actix-web 是什么？（10分钟）

**关键问题**：
- Actix-web 是什么类型的框架？
- 为什么选择 Actix-web？
- 它的核心特点是什么？

**了解方向**：
- 基于 Actor 模型
- 高性能（全球最快的 Rust Web 框架之一）
- 异步驱动（基于 tokio）
- 类型安全
- 灵活的路由系统

#### 2.2 基本概念（20分钟）

**核心概念**：
1. **App**：应用程序实例
2. **HttpServer**：HTTP 服务器
3. **Route**：路由定义
4. **Handler**：请求处理函数
5. **Extractor**：请求数据提取
6. **Responder**：响应生成

**示例代码结构**：
```rust
use actix_web::{web, App, HttpServer, Responder};

async fn hello() -> impl Responder {
    "Hello, World!"
}

#[actix_web::main]
async fn main() -> std::io::Result<()> {
    HttpServer::new(|| {
        App::new()
            .route("/", web::get().to(hello))
    })
    .bind("127.0.0.1:8080")?
    .run()
    .await
}
```

### 任务3：规划第一个 Web API 项目（规划任务）⭐⭐⭐⭐

**预计时长**：30分钟

**项目方向选择**：

#### 选项1：Todo List API（推荐）⭐⭐⭐⭐⭐

**功能**：
- GET /todos - 获取所有任务
- GET /todos/:id - 获取单个任务
- POST /todos - 创建任务
- PUT /todos/:id - 更新任务
- DELETE /todos/:id - 删除任务

**优点**：
- 经典入门项目
- 涵盖所有 CRUD 操作
- 容易理解和扩展
- 可以后续添加数据库

**技术栈**：
- Actix-web（Web 框架）
- Serde（JSON 处理）
- 内存存储（先不用数据库）

#### 选项2：简易博客 API

**功能**：
- 文章管理（增删改查）
- 简单分类
- 搜索功能

**优点**：
- 更接近实际应用
- 可以展示更多技术

**难度**：稍高

#### 选项3：用户管理 API

**功能**：
- 用户注册

**优点**：

**我的推荐**：选择 **Todo List API**，原因：
