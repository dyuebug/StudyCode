## 🎯 学习重点

1. **闭包语法**：
   - 基本形式：`|param| expression`
   - 多参数：`|x, y| x + y`
   - 代码块：`|x| { let y = x + 1; y * 2 }`
   - 类型推断：通常可以省略类型标注

2. **环境捕获**：
   - 不可变借用：默认行为（`&T`）
   - 可变借用：闭包内修改环境变量（`&mut T`）
   - 获取所有权：使用 `move` 关键字（`T`）

3. **Fn trait 族**：
   - `Fn`：`&self`，可被多次调用，不可变借用环境
   - `FnMut`：`&mut self`，可被多次调用，可变借用环境
   - `FnOnce`：`self`，只能被调用一次，获取环境所有权
   - 继承关系：`Fn: FnMut: FnOnce`

4. **move 关键字**：
   - 强制闭包获取环境的所有权
   - 使用场景：多线程、生命周期问题
   - 对 Copy 类型：复制值
   - 对非 Copy 类型：移动所有权

5. **闭包作为参数**：
   - 泛型参数：`fn f<F: Fn(i32) -> i32>(closure: F)`
   - impl Trait：`fn f(closure: impl Fn(i32) -> i32)`
   - trait 对象：`fn f(closure: Box<dyn Fn(i32) -> i32>)`

## 💡 学习建议

1. **闭包 vs 函数**：
   - 闭包可以捕获环境，函数不能
   - 闭包有类型推断，函数必须显式标注
   - 每个闭包都有唯一的匿名类型

2. **选择合适的 Fn trait**：
   - 需要多次调用 + 只读环境？→ `Fn`
   - 需要多次调用 + 修改环境？→ `FnMut`
   - 只调用一次 / 消耗环境？→ `FnOnce`

3. **何时用 move**：
   - 闭包在新线程中执行
   - 闭包生命周期超过环境变量
   - 需要明确获取所有权

4. **实际应用**：
   - 迭代器方法：`map`、`filter`、`fold`
   - 回调函数
   - 延迟执行
   - 自定义控制流
