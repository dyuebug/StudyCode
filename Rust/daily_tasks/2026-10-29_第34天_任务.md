## 📝 具体任务

1. [ ] 读 `src/main.rs` 第一部分「核心概念详解」（约 40 分钟）
   - 1.1 四种推送方案对比表——重点看「什么时候别用 WebSocket」
   - 1.2 握手：把请求头和响应头**抄一遍**，手算一次 Accept
   - 1.3 帧结构图：重点看"126/127 是逃逸标记，不是长度值"
   - 1.4 三个对象：`response` / `Session` / `MessageStream` 各自的职责

2. [ ] 读 `src/protocol.rs` 并跑测试（约 50 分钟）
   ```bash
   cd realtime/ws-basics && cargo test
   ```
   - `accept_key()`：对照 RFC 6455 §1.3 的官方向量
     `dGhlIHNhbXBsZSBub25jZQ==` → `s3pPLMBiTxaQ9kYGzzhZRbK+xOo=`
   - `encode_frame()`：三种长度编码的分支各走一遍
   - `decode_frame()`：注意 `Incomplete` 是**正常状态**，不是错误
   - 测试 `oversized_payload_is_rejected_before_allocating`：
     理解"先判大小再等数据"为什么是 DoS 防护的关键
   - **动手**：改 `MAX_PAYLOAD` 为 1 KiB，再跑测试，看哪个用例失败

3. [ ] 跑教学演示（约 15 分钟）
   ```bash
   cargo run -- --demo-only
   ```
   - 2.2 节三种长度编码的帧总长（11 / 308 / 70014 字节）
   - 2.2 节四条错误路径的输出
   - 2.3 节退避表：观察抖动区间落在 `[cap/2, cap)`

4. [ ] 启动服务 + 浏览器验证（约 45 分钟）
   ```bash
   cargo run
   ```
   - 打开 `http://127.0.0.1:8081/`，**开两个标签页**
   - 一个标签发消息，确认两个标签都收到
   - DevTools → Network → WS → 点开 `/ws` → Messages：
     亲眼看到 `↑` 发送帧、`↓` 接收帧、以及每 5 秒一次的 ping/pong
   - 关掉一个标签，观察另一个标签收到"离开了聊天室"
   - **故意拔线**：在 DevTools 里用 Offline 模式，
     观察客户端指数退避重连（状态栏显示第几次、等待多久）
   - 恢复网络，确认自动连回来

5. [ ] 用手写客户端验证协议（约 40 分钟）
   ```bash
   # 终端 1
   cargo run
   # 终端 2（前台）
   cargo run -- --client
   # 终端 3（与终端 2 同时）
   cargo run -- --client
   ```
   - 逐行读 `client_mode()`：它做的事就是浏览器做的事
   - 确认输出里的 `HTTP/1.1 101` 与 `Accept 校验通过`
   - 两个客户端同时在线时，确认彼此能看到对方的加入与消息（`online` 变成 2）
   - 注意客户端为什么要有"12 秒总时限"而不是"8 秒空闲超时"
     （服务端每 5 秒一个 ping，数据永远不会真的断——**空闲 ≠ 没收到数据**）

6. [ ] 读第三部分「深入理解」（约 30 分钟，可跳过）
   - 【1】客户端为什么必须掩码：代理投毒的历史
   - 【2】ring buffer 与 `Lagged`：唯一的诚实反馈
   - 【3】为什么 HTTP/2 流替代不了浏览器里的 WebSocket
   - 【4】横向扩展：本机 broadcast → 消息总线 → 各实例再 broadcast

7. [ ] 读第四部分 8 个常见错误（约 35 分钟）
   - **必做 4.1**：故意在 handler 里 `while let Some(msg) = stream.recv().await`，
     不 spawn，用浏览器连一次，记录控制台报的错
   - **必做 4.4**：删掉 `Close` 分支里的 `break`，观察 `online` 计数怎么跑偏
   - **必做 4.7**：把 `capacity` 改成 2，快速发 10 条，看 `resync` 提示

8. [ ] 完成练习题（约 60 分钟）
   - 必做：练习 1（握手校验）、练习 3（`Lagged` 处理）、练习 4（心跳踢人）
   - 选做：练习 2（echo/广播拆分）、练习 5（分片大消息）
   - 思考题 7：为什么 `close()` 要消费 `self`
