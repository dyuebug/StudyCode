### 2. [ ] 写 `tests/ws.rs`，至少 6 个用例（预计 90 分钟）

1. 握手缺 `Upgrade` 头 → 400
2. 非法房间名（`a.b` / 带中文 / 33 字符）→ 400 `invalid_room`，且不产生房间

7. 只连不读 → 写超时后被踢（`send_timeout` 调成 300ms）

- **要求**：每个用例独立服务器、端口 0；整套 `cargo test` 不超过 60 秒

## 💡 提示

- 先去 `src/chat.rs` 把常量换成配置，再动测试——顺序反了会先卡在"测试跑得太慢"
- 测试里访问 HTTP 用阻塞 `TcpStream` 时，**必须** `spawn_blocking`，
  否则单线程的 actix System 会自己等自己
- 断言 JSON 用 `Value` 比较，不要比原始字符串：`serde_json::json!` 的键是排序的
