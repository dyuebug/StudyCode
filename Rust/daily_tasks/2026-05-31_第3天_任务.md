## 🔥 今日重点概念

### 切片语法

```rust
// 字符串切片
let s = String::from("hello world");
let hello = &s[0..5];   // "hello"
let world = &s[6..11];  // "world"

// 数组切片
let a = [1, 2, 3, 4, 5];
let slice = &a[1..3];   // [2, 3]
```

### 生命周期注解

```rust
// 函数中的生命周期
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() {
        x
    } else {
        y
    }
}

// 'a 表示返回值的生命周期与参数的生命周期相关
```
