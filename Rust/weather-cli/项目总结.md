## 🎓 三库整合应用

### 1. clap - 命令行参数解析

**应用场景**：
```rust
#[derive(Parser)]
#[command(name = "weather")]
struct Cli {
    #[command(subcommand)]
    command: Commands,
}

#[derive(Subcommand)]
enum Commands {
    Get { city: String, verbose: bool },
    History { limit: usize },
    Clear,
}
```

**学到的**：
- 子命令定义（enum）
- 参数注解（short, long, default_value_t）
- 自动帮助生成
- 版本信息

**效果**：
```bash
$ weather-cli --help
Usage: weather-cli <COMMAND>

Commands:
  get      查询城市天气
  history  查看查询历史
  clear    清除历史记录
```

### 2. reqwest - HTTP 客户端

**应用场景**：
```rust
fn fetch_weather(city: &str) -> Result<WeatherResponse> {
    let client = Client::new();
    let url = format!("https://wttr.in/{}?format=j1", city);
    
    let response = client
        .get(&url)
        .header("User-Agent", "weather-cli/1.0")
        .send()?;
    
    let weather: WeatherResponse = response.json()?;
    Ok(weather)
}
```

**学到的**：
- HTTP GET 请求
- 自定义请求头
- 自动 JSON 反序列化
- 错误处理（Result + ?）

**效果**：
```
🔍 正在查询 Beijing 的天气...
📍 位置: Beijing, China
🌡️  温度: 27°C (81°F)
```

### 3. serde - 数据序列化

**应用场景**：
```rust
// API 响应结构
#[derive(Deserialize)]
struct WeatherResponse {
    current_condition: Vec<CurrentCondition>,
    nearest_area: Vec<NearestArea>,
}

// 历史记录结构
#[derive(Serialize, Deserialize)]
struct AppConfig {
    history: Vec<HistoryRecord>,
}
```

**学到的**：
- 复杂结构反序列化
- 嵌套结构处理
- JSON 文件读写
- #[serde(rename)] 字段映射

**效果**：
```json
{
  "history": [
    {
      "city": "Shanghai",
      "temperature": "24°C",
      "description": "Partly cloudy",
      "timestamp": "2026-06-14 20:00:42"
    }
  ]
}
```

## 💡 技术亮点

### 1. 完美的库组合

**数据流**：
```
用户输入 → clap 解析 → reqwest 请求 → serde 反序列化 → 显示结果 → serde 序列化 → 保存历史
```

**每个库的作用**：
- **clap**：用户界面层（CLI）
- **reqwest**：网络通信层（HTTP）
- **serde**：数据转换层（JSON）

### 2. 子命令设计

使用 enum 实现子命令：
```rust
match cli.command {
    Commands::Get { city, verbose } => { /* 查询 */ }
    Commands::History { limit } => { /* 历史 */ }
    Commands::Clear => { /* 清除 */ }
}
```

**优点**：
- 类型安全
- 编译期检查
- 清晰的代码结构

### 3. 错误处理

统一的错误处理：
```rust
fn main() -> Result<(), Box<dyn std::error::Error>> {
    // ...
    Ok(())
}
```

**优点**：
- ? 运算符简化代码
- 统一的错误传播
- 友好的错误提示

### 4. 配置管理

复用 minigrep 的配置模式：
```rust
impl AppConfig {
    fn load(path) -> Result<Self>
    fn save(&self, path) -> Result<()>
    fn add_history(&mut self, record)
}
```

**优点**：
- 代码可复用
- 模式一致
- 易于维护
