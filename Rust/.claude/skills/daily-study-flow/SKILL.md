## 🤖 Claude自动化工作流程规范

> **⚠️ 重要：本节定义Claude的自动化行为，必须严格遵守！**

### 🔄 流程1：每天开始学习

**触发条件**：用户说 "开始学习" 或类似表达（如"今天开始学习"、"准备学习"）

**执行步骤**（按顺序，不可省略）：

1. **读取前一天日志**
   ```
   - 读取 daily_logs/ 中最新的日志文件
   - 提取：遗留问题、未完成任务、明天计划
   ```

2. **读取本周目标**
   ```
   - 读取本周目标清单
   - 计算本周剩余天数
   ```

3. **生成今日任务清单**
   ```
   - 基于：本周目标 + 昨日遗留 + 学习进度
   - 保存到：daily_tasks/YYYY-MM-DD_第X天_任务.md
   - 包含：学习目标、具体任务、预计时长、学习资源
   ```

4. **向用户汇报**
   ```
   - 问候语
   - 今天是第X天
   - 昨日遗留问题提醒
   - 今日学习重点（3-5条）
   - 预计学习时长
   - 鼓励语
   ```

**输出文件**：`daily_tasks/YYYY-MM-DD_第X天_任务.md`

---

### ✅ 流程2：每天结束学习

**触发条件**：用户说 "学习结束" 或 "今天学完了"

**执行步骤**（按顺序，不可省略）：

1. **询问完成情况**
   ```
   - 读取今日任务清单
   - 逐项询问：是否完成、学到什么、遇到问题
   ```

2. **生成学习日志**
   ```
   - 收集：完成情况、学习时长、知识点、问题、心得
   - 保存到：daily_logs/YYYY-MM-DD_第X天_日志.md
   - 格式：统一使用标准模板
   ```

3. **更新CLAUDE.md统计**
   ```
   - 更新：学习天数、总时长、完成项目
   - 更新：本周目标完成度
   - 更新：已掌握技能列表
   ```

4. **规划明天详细任务**
   ```
   - 基于今日完成情况和本周目标
   - 生成明天的详细学习计划，包括：
     * 学习主题
     * 学习目标（具体的知识点）
     * 具体任务清单（文件名、预计时长）
     * 学习重点（核心概念和方法）
     * 预计总时长
     * 需要准备的材料清单
     * 学习建议
     * 成功标准
   - 写入今日日志的"🔜 明天计划（第X天）"部分
   - 确保明天的Claude读取日志后可直接开始工作
   ```

**输出文件**：
- `daily_logs/YYYY-MM-DD_第X天_日志.md`
- 更新 `CLAUDE.md` 统计数据

---

### 📊 流程3：每周生成周报

**触发条件**：
- 用户说 "生成周报"
- 或每周日自动提醒

**执行步骤**：

1. **汇总本周数据**
   ```
   - 读取本周所有日志文件
   - 统计：学习天数、总时长、完成项目、掌握技能
   ```

2. **生成周报**
   ```
   - 保存到：weekly_reports/2026-W01.md
   - 包含：周目标完成度、学习统计、问题总结、下周计划
   ```

3. **更新下周目标**
   ```
   - 在CLAUDE.md中更新"本周学习目标"部分
   - 设置新的一周目标清单
   ```

**输出文件**：`weekly_reports/2026-WXX.md`

---

### 📝 流程4：知识库管理

**触发条件**：用户说 "整理笔记" 或 "更新知识库"

**执行步骤**：

1. **从日志提取知识点**
   ```
   - 扫描所有日志文件的"学到的知识点"部分
   - 按主题分类整理
   ```

2. **生成速查表**
   ```
   - 保存到：knowledge_base/主题_速查表.md
   - 格式：简洁、代码示例、实用
   ```

**输出文件**：`knowledge_base/` 中的各种速查表
