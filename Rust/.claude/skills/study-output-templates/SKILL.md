## 💬 沟通协议规范

### 用户→Claude 标准对话

**开始学习**：
```
用户："开始学习"
Claude：自动执行流程1
```

**遇到问题**：
```
用户："我在学习XXX，遇到问题：[具体描述]"
Claude：
  1. 理解问题
  2. 提供解释和示例
  3. 询问是否理解
  4. 记录到今日问题列表
```

**请求创建材料**：
```
用户："创建XXX学习材料"
Claude：
  1. 创建带详细注释的.rs文件
  2. 解释学习目标和重点
  3. 提供运行方式（cargo run等）
```

**结束学习**：
```
用户："学习结束"
Claude：自动执行流程2
```

**生成周报**：
```
用户："生成周报"
Claude：自动执行流程3
```

**整理笔记**：
```
用户："整理笔记" / "更新知识库"
Claude：自动执行流程4
```

### Claude→用户 输出规范

**每日任务清单格式**：
```markdown
# 📅 第X天学习任务清单
**日期**：YYYY-MM-DD
**本周目标**：XXX
**昨日遗留**：XXX

## 🎯 今日学习目标
- [ ] 目标1
- [ ] 目标2

## 📝 具体任务
1. [ ] 任务1（预计XX分钟）- 文件：XXX.rs
2. [ ] 任务2（预计XX分钟）- 文件：XXX.rs

## 📚 学习资源
- rust_basics/XXX.rs
- 参考文档：The Rust Book相关章节

## ⏰ 时间安排
总预计：X小时
```
