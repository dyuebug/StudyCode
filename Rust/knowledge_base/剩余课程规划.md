## 生成约定

1. 学习材料严格遵循 `rust-material-authoring` 技能的六部分结构：核心概念 → 基础实践 → 深入理解（可选）→ 常见错误（≥5 个，含编译器错误信息）→ 函数/宏卡片 → 练习题（**不给答案**）。
2. 日志中的时长为**规划推定值**，每篇头部必须标注，不得作为实测证据。
3. 未实际运行的代码在文件头标注「未编译验证」，避免与已验证代码混淆。
4. 项目代码必须能 `cargo build` 通过（生成后逐一验证）。
