# 🎯 实战项目：为 minigrep 添加配置文件功能

使用 serde 为 minigrep 添加 JSON 配置文件和搜索历史功能。

---

## 📋 项目目标

为之前的 minigrep 项目添加：
- ✅ JSON 配置文件支持
- ✅ 搜索历史记录
- ✅ 配置持久化
- ✅ 配置查看命令

## 🚀 实现步骤

### 步骤1：添加依赖

在 `Cargo.toml` 中添加：
```toml
[dependencies]
serde = { version = "1.0", features = ["derive"] }
serde_json = "1.0"
```

### 步骤2：创建配置模块

创建 `src/config.rs`：
```rust
use serde::{Deserialize, Serialize};

#[derive(Serialize, Deserialize, Debug)]
pub struct AppConfig {
    pub default_ignore_case: bool,
    pub recent_searches: Vec<String>,
    pub recent_files: Vec<String>,
    pub max_history: usize,
}

impl AppConfig {
    pub fn load<P: AsRef<Path>>(path: P) -> Result<Self, Box<dyn Error>> {
        let contents = fs::read_to_string(path)?;
        let config: AppConfig = serde_json::from_str(&contents)?;
        Ok(config)
    }

    pub fn save<P: AsRef<Path>>(&self, path: P) -> Result<(), Box<dyn Error>> {
        let json = serde_json::to_string_pretty(self)?;
        fs::write(path, json)?;
        Ok(())
    }
}
```

### 步骤3：更新主程序

在 `main.rs` 中：
1. 加载配置文件（如果存在）
2. 执行搜索
3. 更新搜索历史
4. 保存配置

```rust
// 1. 加载配置
let mut app_config = AppConfig::load(CONFIG_FILE).unwrap_or_default();

// 2. 搜索...

// 3. 添加历史
app_config.add_search_history(&config.query, &config.file_path);

// 4. 保存配置
app_config.save(CONFIG_FILE)?;
```

### 步骤4：添加配置查看命令

```rust
if args.len() >= 2 && args[1] == "--config" {
    app_config.display();
    return;
}
```

## 💡 技术亮点

### 1. serde 的实际应用

**自动序列化**：
```rust
#[derive(Serialize, Deserialize)]
struct AppConfig { /* ... */ }
```
- 一行代码实现序列化
- 无需手动解析 JSON

**美化输出**：
```rust
let json = serde_json::to_string_pretty(&config)?;
```
- 自动缩进格式化
- 便于阅读和编辑

### 2. 错误处理

**优雅的降级**：
```rust
let app_config = AppConfig::load(CONFIG_FILE).unwrap_or_default();
```
- 配置文件不存在？使用默认配置
- 不会因为配置问题崩溃

**Result 传播**：
```rust
pub fn load(path: P) -> Result<Self, Box<dyn Error>> {
    let contents = fs::read_to_string(path)?;
    let config: AppConfig = serde_json::from_str(&contents)?;
    Ok(config)
}
```
- `?` 运算符简化错误处理
- 自动类型转换到 `Box<dyn Error>`

### 3. 模块化设计

**职责分离**：
- `config.rs`：配置管理（100行）
- `lib.rs`：搜索逻辑（不变）
- `main.rs`：CLI 接口 + 配置集成（60行）

**可测试性**：
```rust
#[cfg(test)]
mod tests {
    #[test]
    fn test_add_history() { /* ... */ }
}
```
- 配置模块有独立测试
- 保证功能正确性

### 4. 用户体验改进

**自动保存**：
- 搜索历史自动记录
- 无需手动管理

**易于配置**：
- JSON 格式易读易改
- 支持手动编辑

**友好提示**：
- 首次运行提示
- 保存成功提示
- 查看配置提示
