## 🎓 学习重点

### 最重要的三个概念

1. **运算符重载的本质** ⭐⭐⭐⭐⭐
   - 运算符重载本质上是函数
   - `a + b` 等价于 `a.operator+(b)` 或 `operator+(a, b)`
   - 让自定义类型像内置类型一样使用

2. **成员函数 vs 全局函数** ⭐⭐⭐⭐⭐
   - 成员函数：左操作数是当前对象（this）
   - 全局函数：两个操作数都是参数
   - 选择原则：
     - 修改左操作数：成员函数（如 =、+=）
     - 不修改操作数：全局函数（如 +、-）
     - 流操作符：必须全局函数（<<、>>）

3. **运算符重载的规则** ⭐⭐⭐⭐
   - 不能改变运算符的优先级
   - 不能改变运算符的参数个数
   - 不能创建新的运算符
   - 保持运算符的原有语义

## 💡 学习建议

### 学习方法

1. **理解本质**
   - 运算符重载就是函数
   - `a + b` 只是语法糖

2. **对比内置类型**
   ```cpp
   // 内置类型
   int a = 1, b = 2;
   int c = a + b;
   
   // 自定义类型（运算符重载后）
   Complex c1(1, 2), c2(3, 4);
   Complex c3 = c1 + c2;  // 像内置类型一样使用
   ```

3. **遵循最佳实践**
   - 保持运算符的原有语义
   - `+` 应该表示加法，不要滥用
   - 对称性原则：`a + b` 和 `b + a` 应该等价

### 今日注意事项

1. **运算符重载语法**
   ```cpp
   // 成员函数
   Complex operator+(const Complex& other) const;
   
   // 全局函数（需要友元）
   friend Complex operator+(const Complex& a, const Complex& b);
   ```

2. **返回值类型**
   - 算术运算符：返回新对象（值）
   - 赋值运算符：返回引用（*this）
   - 关系运算符：返回 bool

3. **const 正确性**
   - 不修改对象的运算符应该声明为 const
   - 参数不修改应该用 const 引用

4. **前置 vs 后置自增**
   ```cpp
   Counter& operator++();     // 前置：++i
   Counter operator++(int);   // 后置：i++（int 是哑元参数）
   ```
