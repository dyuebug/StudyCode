## 💡 学习建议

### 学习方法

1. **理解特点**
   - set：唯一、有序
   - map：键值对、按键有序

2. **对比记忆**
   ```cpp
   set<int> s;           // 只存值
   map<string, int> m;   // 键值对
   ```

3. **掌握常用操作**
   - 插入：insert、[]
   - 查找：find、count
   - 删除：erase
   - 遍历：迭代器

### 今日注意事项

1. **包含正确的头文件**
   ```cpp
   #include <set>
   #include <map>
   ```

2. **迭代器的使用**
   ```cpp
   // C++11 范围 for（推荐）
   for (const auto& elem : s) {
       cout << elem << endl;
   }
   
   // 传统迭代器
   for (auto it = s.begin(); it != s.end(); ++it) {
       cout << *it << endl;
   }
   ```

3. **map 的遍历**
   ```cpp
   for (const auto& pair : m) {
       cout << pair.first << ": " << pair.second << endl;
   }
   ```

4. **find 返回值判断**
   ```cpp
   auto it = s.find(value);
   if (it != s.end()) {
       // 找到了
   }
   ```
