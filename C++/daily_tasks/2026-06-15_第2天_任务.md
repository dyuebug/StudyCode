## 🎓 学习重点

### 最重要的三个概念

1. **封装（Encapsulation）** ⭐⭐⭐⭐⭐
   - 数据隐藏：private 成员变量
   - 接口暴露：public 成员函数
   - 为什么封装？保护数据、控制访问

2. **构造函数（Constructor）** ⭐⭐⭐⭐⭐
   - 对象创建时自动调用
   - 用于初始化成员变量
   - 可以重载（多个构造函数）

3. **析构函数（Destructor）** ⭐⭐⭐⭐
   - 对象销毁时自动调用
   - 用于清理资源
   - 只能有一个，不能重载

## 💡 学习建议

### 学习方法

1. **先理解概念，再写代码**
   - 类和对象的关系：类是模板，对象是实例
   - 构造函数和析构函数的作用
   - 封装的意义

2. **对比 C 语言的结构体**
   - C 语言结构体：只有数据
   - C++ 类：数据 + 函数
   - 理解"面向对象"的优势

3. **注意观察细节**
   - 构造函数何时被调用？
   - 析构函数何时被调用？
   - 私有成员能否直接访问？

4. **多写多练**
   - 定义不同的类（如：书籍、汽车）
   - 尝试不同的构造函数
   - 测试访问控制

### 今日注意事项

1. **类的定义语法**
   ```cpp
   class ClassName {
   private:
       // 私有成员
   public:
       // 公有成员
   };  // 注意分号！
   ```

2. **构造函数的名字**
   - 构造函数名 = 类名
   - 没有返回类型（连 void 都不要）

3. **析构函数的特点**
   - 析构函数名 = `~类名`
   - 没有参数，不能重载

4. **访问控制的默认值**
   - class：默认 private
   - struct：默认 public
