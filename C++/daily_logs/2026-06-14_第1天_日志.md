### 1. C++ 发展概述

**C++ 三个编程范式**：
- 面向过程（C 语言）：以步骤为中心

- 泛型编程（模板/STL）：通用算法，不损失效率

**C++ 发展三个阶段**：
- 第一阶段（1983-1995）：C with class，工程管理优于 C
- 第二阶段（1995-2000）：STL 出现，泛型编程兴起
- 第三阶段（2000至今）：模板元编程，成为最复杂的主流语言

**C++ 标准演进**：
- C++98：第一个 ISO 标准
- C++11：革命性改进（auto、右值引用、移动语义、多线程）⭐⭐⭐⭐⭐
- C++14/17/20/23：持续演进

**C++ 擅长领域**：

### 2. 命名空间（namespace）

**为什么需要命名空间**：
- 大型项目中避免命名冲突
- 不同模块可以使用相同的名字

**三种使用方式**：

1. **作用域限定符 `::`**（最安全）
   ```cpp
   std::cout << "hello" << std::endl;
   ```
   - 优点：准确，不会冲突
   - 缺点：繁琐

2. **using 编译指令**（谨慎使用）
   ```cpp
   using namespace std;
   cout << "hello" << endl;
   ```
   - 优点：方便
   - 缺点：引入所有实体，可能冲突
   - ⚠️ 建议：写在局部作用域

3. **using 声明机制**（推荐！）⭐⭐⭐⭐⭐
   ```cpp
   using std::cout;
   using std::endl;
   cout << "hello" << endl;
   ```
   - 优点：需要什么声明什么，减少冲突
   - **初学阶段推荐使用**

**关键要点**：
- 命名空间可以嵌套
- 匿名命名空间：不能跨模块调用
- 有名命名空间：可以跨模块调用（需要 extern 声明）

### 3. 引用（reference）⭐⭐⭐⭐⭐（最重点）

**引用的概念**：
- **引用是已定义变量的别名**
- 语法：`类型 & ref = 变量;`

**引用的特点**：
1. `&` 是引用符号，不是取地址符
2. 引用类型必须与绑定变量类型相同
3. **必须在声明时初始化**
4. **引用一经绑定，无法更改**

**引用的本质**：
- 引用是受限制的指针
- 引用占据内存（一个指针的大小）
- 编译器阻止对引用本身的访问
- 对引用取址，得到的是绑定变量的地址

**引用 vs 指针**：

| 特性 | 引用 | 指针 |
|------|------|------|
| 初始化 | 必须初始化 | 可以不初始化 |
| 修改绑定/指向 | 不能修改 | 可以修改 |
| 取地址 | 取到绑定变量的地址 | 取到指针自己的地址 |
| 本质 | 受限的指针 | 地址变量 |
| 使用 | 像普通变量一样 | 需要解引用（*） |

**引用作为函数参数**（重点）：

```cpp
// 值传递（不会交换）
void swap(int x, int y) {
    int temp = x;
    x = y;
    y = temp;
}

// 引用传递（会交换）⭐⭐⭐⭐⭐
void swap(int& x, int& y) {
    int temp = x;
    x = y;
    y = temp;
}
```

**引用传递的优点**：
- 避免复制大对象，提高效率
- 可以修改实参的值
- 语法简洁，不需要解引用

### 4. 函数重载（function overloading）

**什么是函数重载**：
- 同一作用域内，多个函数名称相同，但参数列表不同
- C 语言不支持，C++ 才支持

**函数重载的条件**：
- **参数的数量、类型、顺序任一不同即可构成重载**
- ✅ 参数数量不同
- ✅ 参数类型不同
- ✅ 参数顺序不同
- ❌ **仅返回类型不同，不构成重载**

**函数重载的原理**：
- **名字改编（name mangling）**
- 编译器根据参数类型、顺序、个数改编函数名
- 底层实际是不同名的函数

**示例**：
```cpp
void swap(int& a, int& b);       // 交换 int
void swap(double& a, double& b); // 交换 double

void print(int x);         // 打印 int
void print(double x);      // 打印 double
void print(const char* s); // 打印字符串
```

**函数重载的价值**：
- 减少函数名数量
- 提高代码可读性
- 相同功能用相同名字，更直观

## ❓ 遇到的问题与解决

**问题1**：引用到底占不占内存？

**解决**：
- 教程说明：引用是受限制的指针，占据一个指针的大小
- 虽然逻辑上是"别名"，但底层实现是指针
- 对引用取址，得到的是绑定变量的地址（编译器隐藏了引用本身的地址）

**理解**：引用在使用层面是别名，在实现层面是指针

---

**问题2**：为什么推荐 using 声明机制，而不是 using 编译指令？

**解决**：
- using 编译指令（`using namespace std;`）会引入整个命名空间的所有实体
- 如果命名空间中有与自己定义的名字冲突的实体，会导致错误
- using 声明机制（`using std::cout;`）只引入需要的实体，更安全

**经验**：初学阶段，养成使用 using 声明的习惯

---

**问题3**：函数重载和函数模板有什么区别？

**当前理解**：
- 函数重载：手动为每种类型写一个函数
- 函数模板：编译器自动生成不同类型的函数（还没学到，后续会学习）
