## 📖 学到的知识点

### 1. 流的概念

**什么是流（Stream）**：
- 流是字节序列
- 从设备到内存：输入流（Input Stream）
- 从内存到设备：输出流（Output Stream）

**C++ 流的优势**：
- **类型安全**：编译时检查类型
- **可扩展**：可以自定义类的流操作符
- **统一接口**：标准I/O、文件I/O、字符串I/O统一使用流

**对比 C 语言**：
```c
// C 语言
printf("Hello %s, age: %d\n", name, age);
scanf("%d", &num);

// C++
cout << "Hello " << name << ", age: " << age << endl;
cin >> num;
```

**核心理解**：流提供了统一的 I/O 接口，屏蔽了底层设备的差异。

---

### 2. 常用流类型

**流类层次结构**：

| 类名 | 作用 | 头文件 |
|------|------|--------|
| **istream** | 通用输入流 | iostream |
| **ostream** | 通用输出流 | iostream |
| iostream | 通用输入输出流 | iostream |
| **ifstream** | 文件输入流 | fstream |
| **ofstream** | 文件输出流 | fstream |
| fstream | 文件输入输出流 | fstream |
| **istringstream** | 字符串输入流 | sstream |
| **ostringstream** | 字符串输出流 | sstream |
| stringstream | 字符串输入输出流 | sstream |

**预定义的全局对象**：
- `cin`：标准输入（键盘）
- `cout`：标准输出（屏幕）
- `cerr`：标准错误（屏幕，不带缓冲）
- `clog`：标准日志（屏幕，带缓冲）

---

### 3. 流的四种状态 ⭐⭐⭐⭐⭐（重点）

**四种状态**：

| 状态 | 含义 | 说明 |
|------|------|------|
| **goodbit** | 有效状态 | 流可以正常使用 |
| **badbit** | 系统级错误 | 不可恢复，流无法使用 |
| **failbit** | 可恢复错误 | 如类型不匹配，可以恢复 |
| **eofbit** | 到达文件末尾 | 正常结束 |

**状态检查函数**：
```cpp
cin.good()  // 是否处于 goodbit 状态
cin.bad()   // 是否处于 badbit 状态
cin.fail()  // 是否处于 failbit 状态
cin.eof()   // 是否到达文件末尾
```

**恢复流状态**：
```cpp
if (!cin.good()) {
    cin.clear();  // 清除错误标志
    cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');  // 清空缓冲区
}
```

**关键理解**：
- 输入失败（如类型不匹配）会导致流进入 failbit 状态
- failbit 状态下流无法正常工作，需要恢复
- 恢复流状态需要两步：clear() + ignore()

---

### 4. 标准输入输出流

**cin（标准输入）**：
```cpp
int num;
string name;
cin >> num >> name;  // 链式调用，提取操作符 >>
```

**cout（标准输出）**：
```cpp
cout << "Hello" << endl;  // 链式调用，插入操作符 <<
```

**流操作符的返回值**：
- `cin >> num` 返回 `cin` 的引用
- `cout << "hello"` 返回 `cout` 的引用
- 因此可以链式调用

**关键理解**：
- `>>` 跳过空格、tab、换行符
- `<<` 不自动换行（需要手动 `endl` 或 `\n`）
- 链式调用利用了引用的返回值（回顾第1天的引用知识）

### 5. 缓冲机制 ⭐⭐⭐⭐

**为什么需要缓冲区**：
- 减少实际 I/O 操作次数（I/O 操作很慢）
- 协调高速 CPU 和低速设备
- 提高程序运行效率

**三种缓冲类型**：

1. **全缓冲**：缓冲区满才刷新
   - 典型代表：文件 I/O
   - 缓冲区通常是 1024 字节

2. **行缓冲**：遇到换行符才刷新
   - 典型代表：cin
   - 回车后数据才进入缓冲区

3. **不带缓冲**：立即刷新
   - 典型代表：cerr
   - 错误信息需要立即显示

**输出缓冲区刷新时机**：
1. 程序正常结束
2. 缓冲区满（通常 1024 字节）
3. 使用 `endl`（换行 + 刷新缓冲区）
4. 使用 `flush`（仅刷新缓冲区，不换行）

**关键理解**：
- `endl` = `\n` + 刷新缓冲区
- `\n` 仅换行，不刷新缓冲区
- 需要立即输出时使用 `endl` 或 `flush`

### 6. 格式化输出 ⭐⭐⭐⭐⭐（重点）

**常用格式化方法**（需要 `#include <iomanip>`）：

| 操作符 | 作用 | 示例 |
|--------|------|------|
| **setw(n)** | 设置字段宽度 | `setw(10)` |
| **setfill(c)** | 设置填充字符 | `setfill('*')` |
| **left** | 左对齐 | `left` |
| **right** | 右对齐 | `right` |
| **setprecision(n)** | 设置精度 | `setprecision(2)` |
| **fixed** | 固定小数点 | `fixed` |
| **scientific** | 科学计数法 | `scientific` |
| **hex** | 十六进制 | `hex` |
| **oct** | 八进制 | `oct` |
| **dec** | 十进制 | `dec` |
| **boolalpha** | 布尔值文本 | `boolalpha` |

**实践验证**：

1. **制作对齐的表格**：
```cpp
cout << setw(10) << "Name" << setw(10) << "Age" << endl;
cout << setw(10) << "Alice" << setw(10) << 20 << endl;
```
输出：
```
      Name       Age
     Alice        20
```

2. **控制浮点数精度**：
```cpp
double pi = 3.14159265;
cout << fixed << setprecision(2) << pi << endl;  // 3.14
```

3. **进制转换**：
```cpp
int num = 255;
cout << hex << num << endl;  // ff
cout << oct << num << endl;  // 377
```

**关键理解**：
- setw() 只影响下一个输出项
- setprecision() 和 fixed 组合使用
- 进制转换后记得恢复为 dec

### 7. 文件流 ⭐⭐⭐⭐⭐（重点）

**文件输入流（ifstream）**：

**创建方式**：
```cpp
// 方式1：构造时打开
ifstream ifs("test.txt");

// 方式2：先创建，再打开
ifstream ifs;
ifs.open("test.txt");
```

**检查是否成功打开**：
```cpp
if (!ifs.is_open()) {
    cout << "文件打开失败！" << endl;
    return;
}
```

**按行读取（推荐）**：
```cpp
string line;
while (getline(ifs, line)) {
    cout << line << endl;
}
```

**文件输出流（ofstream）**：

**写入文件**：
```cpp
ofstream ofs("output.txt");
ofs << "Hello File" << endl;
ofs.close();
```

**文件打开模式**：

| 模式 | 说明 |
|------|------|
| **ios::in** | 读模式（文件不存在则失败） |
| **ios::out** | 写模式（文件不存在则创建） |
| **ios::app** | 追加模式（写入从文件末尾开始） |
| **ios::ate** | 打开后定位到文件末尾 |
| ios::trunc | 截断模式（清空文件内容） |
| ios::binary | 二进制模式 |

**追加模式**：
```cpp
ofstream ofs("data.txt", ios::app);
ofs << "追加的内容" << endl;
```

**实践验证**：
- ✅ 创建了 `students.txt` 文件
- ✅ 读取了文件内容
- ✅ 追加了数据到文件
- ✅ 综合应用：学生成绩管理系统

**文件操作流程**：
```
打开文件 → 检查是否成功 → 读写操作 → 关闭文件
```

**关键理解**：
- 文件不存在时：
  - ifstream 打开失败（进入 failbit 状态）
  - ofstream 自动创建文件
- 追加模式（ios::app）不会覆盖原有内容
- 使用完毕后关闭文件（RAII 会自动关闭）

## ❓ 遇到的问题与解决

**问题1**：endl 和 \n 有什么区别？

**解决**：
- `endl`：换行 + 刷新缓冲区
- `\n`：仅换行，不刷新缓冲区

**示例**：
```cpp
// 使用 endl，立即输出
for (int i = 0; i < 5; i++) {
    cout << "a" << endl;
}

// 使用 \n，可能延迟输出
for (int i = 0; i < 5; i++) {
    cout << "a\n";
}
sleep(2);  // 等待2秒才输出
```

**结论**：需要立即看到输出时使用 endl

---

**问题2**：为什么 setw() 只影响下一个输出项？

**解决**：
setw() 是临时生效的，输出一个项后就失效。

**示例**：
```cpp
cout << setw(10) << "a" << "b" << endl;
// 输出：         ab
// "a" 占10个字符，"b" 不受影响
```

**结论**：如果需要每列都对齐，每列都要设置 setw()

---

**问题3**：文件不存在时，ifstream 和 ofstream 行为有什么不同？

**解决**：
- **ifstream**：文件不存在，打开失败（进入 failbit 状态）
- **ofstream**：文件不存在，自动创建文件

**验证**：
```cpp
// 读取不存在的文件
ifstream ifs("not_exist.txt");
if (!ifs.is_open()) {
    cout << "文件不存在，打开失败" << endl;
}

// 写入不存在的文件
ofstream ofs("new_file.txt");
// 自动创建 new_file.txt
```

**结论**：打开文件后一定要检查 is_open()
