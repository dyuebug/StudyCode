## 📖 学到的知识点

### 1. STL 容器概述

**什么是 STL**：
- STL = Standard Template Library（标准模板库）
- 组成：容器（Containers）、算法（Algorithms）、迭代器（Iterators）

**关联式容器的特点**：
- 元素自动排序
- 查找效率高：O(log n)
- 底层实现：红黑树（自平衡二叉搜索树）

**为什么叫"关联式"**：
- 元素通过键（key）关联
- 不是通过位置（下标）访问

---

### 2. set 容器 ⭐⭐⭐⭐⭐

**set 的两大特征**：
1. **元素唯一**：不能重复
2. **自动排序**：默认升序

**构造方式**（4种）：
```cpp
set<int> s1;                      // 1. 无参构造
set<int> s2 = {3, 1, 4, 1, 5};   // 2. 初始化列表
set<int> s3(s2);                  // 3. 拷贝构造
set<int> s4(arr, arr + 5);        // 4. 迭代器构造
```

**实践验证**：
```
输入：{3, 1, 4, 1, 5, 9}
实际存储：1 3 4 5 9
```
- ✅ 自动去重（两个1只保留一个）
- ✅ 自动排序（升序）

---

**常用操作**：

| 操作 | 函数 | 说明 | 时间复杂度 |
|------|------|------|-----------|
| 插入 | `insert(value)` | 返回 pair<iterator, bool> | O(log n) |
| 查找 | `find(value)` | 找到返回迭代器，否则返回 end() | O(log n) |
| 计数 | `count(value)` | 返回 1（找到）或 0（未找到）| O(log n) |
| 删除 | `erase(value)` | 删除元素 | O(log n) |
| 大小 | `size()` | 返回元素个数 | O(1) |
| 清空 | `clear()` | 清空所有元素 | O(n) |

**insert 的返回值** ⭐⭐⭐⭐：
```cpp
pair<set<int>::iterator, bool> ret = s.insert(5);
if (ret.second) {  // 插入成功
    cout << "插入成功，值为：" << *(ret.first) << endl;
} else {           // 插入失败（元素已存在）
    cout << "元素已存在" << endl;
}
```

**注意事项**：
- ❌ set 不支持下标访问（没有 [] 运算符）
- ❌ 不能通过迭代器修改元素（底层是红黑树，修改会破坏结构）

**适用场景**：
- 需要去重的场景
- 需要有序集合的场景
- 判断元素是否存在

---

### 3. pair 类型

**pair 的概念**：
- 存储两个不同类型的变量
- 定义在 `<utility>` 头文件中
- 类似于结构体

**访问成员**：
```cpp
pair<int, string> p = {1, "hello"};
cout << p.first;   // 访问第一个成员（key）
cout << p.second;  // 访问第二个成员（value）
```

**创建 pair 的三种方式**：
```cpp
pair<int, string>(1, "hello");      // 方式1：直接构造
{1, "hello"};                        // 方式2：初始化列表
make_pair(1, "hello");               // 方式3：make_pair 函数（推荐）
```

**实践验证**：
```
p1: 1 -> hello
p2: 2 -> world
p3: 3 -> c++
```

**为什么需要 pair**：
- map 的元素类型是 pair
- 函数需要返回两个值时使用

---

### 4. map 容器 ⭐⭐⭐⭐⭐

**map 的三大特征**：
1. **键值对存储**：pair<key, value>
2. **键唯一**：key 不能重复
3. **按键排序**：默认按 key 升序

**构造方式**：
```cpp
map<int, string> m = {
    {1, "hello"},
    {2, "world"},
    pair<int, string>(3, "c++"),
    make_pair(4, "stl")
};
```

**实践验证**：
```
输入包含重复的 key=3
map 内容：
1 -> apple
2 -> banana
3 -> cherry  （重复的被忽略）
4 -> date
5 -> elderberry
```
- ✅ key 唯一（重复的被忽略）
- ✅ 按 key 排序

---

**常用操作**：

| 操作 | 函数 | 说明 | 时间复杂度 |
|------|------|------|-----------|
| 插入 | `insert(pair)` | 返回 pair<iterator, bool> | O(log n) |
| 查找 | `find(key)` | 找到返回迭代器，否则返回 end() | O(log n) |
| 计数 | `count(key)` | 返回 1 或 0 | O(log n) |
| 删除 | `erase(key)` | 删除键值对 | O(log n) |
| 访问 | `m[key]` | 返回 value 的引用 | O(log n) |

---

**下标操作 [] 的特点** ⭐⭐⭐⭐⭐（重点）：

这是 map 最特殊的地方！

1. **返回 value 的引用**
2. **下标是 key，不是传统意义的索引**
3. **如果 key 不存在，会自动插入**（value 为默认值）
4. **可以进行写操作**

**实践验证**：
```cpp
map<int, string> m;

m[1] = "hello";         // key=1 不存在，插入 {1, "hello"}
m[1] = "world";         // key=1 存在，修改 value 为 "world"
cout << m[2];           // key=2 不存在，插入 {2, ""}，返回空字符串
```

**运行结果**：
```
m[1] = apple                    （访问存在的 key）
修改后 m[2] = BANANA            （修改存在的 key）
访问不存在的 key：m[10] = ""   （自动插入 {10, ""}）
现在 m.size() = 7               （size 增加了！）
```

**重要警告** ⚠️：
- 使用 `m[key]` 访问不存在的 key 会自动插入
- 如果只是想查找，应该用 `find()`，避免意外插入

**对比**：
```cpp
// 方式1：使用 [] （会自动插入）
if (m[key] != "") {  // ❌ 如果 key 不存在，会插入 {key, ""}
    // ...
}

// 方式2：使用 find（不会插入）
if (m.find(key) != m.end()) {  // ✅ 安全，不会插入
    // ...
}
```

---

**适用场景**：
- 字典（单词 -> 翻译）
- 配置表（键 -> 值）
- 统计计数（单词 -> 出现次数）
- 映射关系（学号 -> 成绩）

### 5. 迭代器（Iterator）⭐⭐⭐⭐⭐

**迭代器的概念**：
- 类似指针，用于遍历容器
- 提供统一的访问接口
- 是容器和算法之间的桥梁

**基本用法**：
```cpp
// 方式1：传统迭代器
for (auto it = s.begin(); it != s.end(); ++it) {
    cout << *it << endl;  // 解引用访问元素
}

// 方式2：C++11 范围 for（推荐）
for (const auto& elem : s) {
    cout << elem << endl;
}
```

**重要函数**：
- `begin()`：返回指向第一个元素的迭代器
- `end()`：返回指向最后一个元素之后的迭代器（尾后迭代器）
- `*it`：解引用，访问迭代器指向的元素
- `++it`：移动到下一个元素

---

**map 的遍历** ⭐⭐⭐⭐：

map 的元素是 pair，遍历时要注意：

```cpp
// 方式1：传统迭代器
for (auto it = m.begin(); it != m.end(); ++it) {
    cout << it->first << ": " << it->second << endl;
    // it 是指向 pair 的迭代器
    // it->first 访问 key
    // it->second 访问 value
}

// 方式2：范围 for（推荐）
for (const auto& pair : m) {
    cout << pair.first << ": " << pair.second << endl;
}

// 方式3：C++17 结构化绑定（最推荐）
for (const auto& [key, value] : m) {
    cout << key << ": " << value << endl;
}
```

**实践验证**：
```
方式1：传统迭代器遍历 set：1 3 5 7 9
方式2：范围 for 遍历 set：1 3 5 7 9

遍历 map：
1 -> one
2 -> two
3 -> three
```

## ❓ 遇到的问题与解决

**问题1**：map 的 [] 操作符为什么访问不存在的 key 会自动插入？

**解决**：
这是 map 的 [] 操作符的设计特性。

**原理**：
```cpp
// map 的 [] 操作符实现原理（简化版）
T& operator[](const Key& key) {
    auto it = find(key);
    if (it == end()) {
        // key 不存在，插入 {key, T()}
        it = insert({key, T()}).first;
    }
    return it->second;  // 返回 value 的引用
}
```

**实践验证**：
```
访问不存在的 key：m[10] = ""
注意：m[10] 不存在，会自动插入 {10, ""}（默认值）
现在 m.size() = 7  （size 增加了）
```

**结论**：
- 如果只是查找，使用 `find()`，避免意外插入
- 如果是统计计数，利用这个特性：`m[word]++`

---

**问题2**：为什么 set 不能通过迭代器修改元素？

**解决**：
set 的底层是红黑树，元素的位置由其值决定。

**原理**：
- 如果允许修改元素，可能破坏红黑树的有序性
- 例如：元素5在中间，修改为10后应该在末尾，但位置没变

**验证**：
```cpp
set<int> s = {1, 3, 5};
auto it = s.begin();
*it = 10;  // ❌ 编译错误：assignment of read-only location
```

**结论**：
- set 的迭代器是 const_iterator
- 如果需要修改，先删除旧元素，再插入新元素

---

**问题3**：set 和 map 的查找为什么是 O(log n)？

**解决**：
底层是红黑树（自平衡二叉搜索树）。

**原理**：
- 二叉搜索树的查找：每次比较可以排除一半元素
- 红黑树保证平衡：树高度 O(log n)
- 查找从根到叶：最多 O(log n) 次比较

**对比**：
- vector 的查找：O(n)（遍历）
- set/map 的查找：O(log n)（二叉搜索）
- unordered_set/unordered_map 的查找：O(1)（哈希表）

**结论**：
- set/map：有序 + O(log n) 查找
- unordered_set/unordered_map：无序 + O(1) 查找

- 简洁：`m[key] = value`

- 访问不存在的 key 会自动插入
- 可能导致意外的元素增加

**最佳实践**：
- 查找：使用 `find()`
- 插入/修改：使用 `[]`

- 不同容器，统一的遍历方式

**推荐**：优先使用范围 for，代码更简洁。

### 5. 底层是红黑树

理解了为什么 set/map 有这些特性：
- 唯一：二叉搜索树的性质
