   ├─ EPOLLONESHOT
   │  ├─ 问题：竞态条件
   │  ├─ 解决：触发后自动移除
   │  └─ 重新注册：EPOLL_CTL_MOD

#### 1.2 核心概念对比表

| 维度 | select | epoll LT | epoll ET |
|------|--------|----------|----------|
| **性能** | O(n) 轮询 | O(1) 事件通知 | O(1) + 减少通知 |
| **并发能力** | 1024 限制 | 无限制 | 无限制 |
| **触发方式** | 轮询 | 持续通知 | 通知一次 |
| **编程难度** | 简单 | 简单 | 复杂 |
| **非阻塞要求** | 可选 | 可选 | 必须 |
| **循环读取** | 可选 | 可选 | 必须 |
| **适用场景** | 跨平台、<100连接 | 开发阶段 | 高并发、生产环境 |
