### 任务1：协程核心概念（预计60分钟）

#### 1.1 协程是什么？

**定义**：
- 协程（Coroutine）= 可以暂停和恢复的函数
- 协作式多任务（Cooperative Multitasking）
- 用户态轻量级"线程"

**与普通函数的区别**：
```
普通函数：
  - 调用 → 执行 → 返回（一次性）
  - 无法暂停
  - 无法恢复

协程：
  - 调用 → 执行 → 暂停（yield）
  - 恢复（resume）→ 继续执行 → 暂停
  - ...
  - 恢复 → 返回
```

---

#### 1.2 协程 vs 线程

**线程（Thread）**：
- 抢占式多任务（Preemptive）
- 内核态调度
- 创建开销大（~1MB 栈空间）
- 上下文切换慢（~1-10 微秒）
- 需要锁同步

**协程（Coroutine）**：
- 协作式多任务（Cooperative）
- 用户态调度
- 创建开销小（几百字节）
- 上下文切换快（~10-100 纳秒）
- 无需锁（单线程内执行）

**对比表**：

| 维度 | 线程 | 协程 |
|------|------|------|
| 调度方式 | 抢占式（内核） | 协作式（用户） |
| 创建开销 | 大（~1MB） | 小（几百字节） |
| 切换开销 | 慢（~1-10μs） | 快（~10-100ns） |
| 并发数量 | 受限（~1000） | 大（~100万） |
| 同步机制 | 锁（复杂） | 无需（简单） |
| 适用场景 | CPU 密集 | I/O 密集 |

---

#### 1.3 协程 vs 回调

**回调（Callback）方式**：
```cpp
// 回调地狱
asyncRead(fd, [](data1) {
    asyncProcess(data1, [](data2) {
        asyncWrite(fd, data2, [](result) {
            // 嵌套3层
        });
    });
});
```

**问题**：
- 嵌套深（回调地狱）
- 逻辑分散
- 错误处理困难

**协程方式**：
```cpp
// 同步写法，异步执行
data1 = co_await asyncRead(fd);
data2 = co_await asyncProcess(data1);
result = co_await asyncWrite(fd, data2);
```

**好处**：
- 代码线性（易读）
- 逻辑集中
- 错误处理简单（try-catch）

---

#### 1.4 协程的优势

**1. 高并发**：
- 创建 100 万个协程
- 内存占用 ~100MB
- 线程需要 ~1TB

**2. 低延迟**：
- 协程切换 ~10-100ns
- 线程切换 ~1-10μs
- 快 100 倍

**3. 简化异步编程**：
- 同步写法，异步执行
- 避免回调地狱
- 代码易读易维护

**4. 无锁编程**：
- 协程在单线程内执行
- 协作式调度，无竞态
- 简化并发逻辑

### 任务2：C++20 Coroutines 基础（预计60分钟）

#### 2.1 三个关键字

**co_await**：
- 暂停协程，等待异步操作完成
- 类似 await（JavaScript）

**co_yield**：
- 暂停协程，返回一个值
- 用于生成器（Generator）

**co_return**：
- 协程返回
- 类似 return

---

#### 2.2 协程的生命周期

```
创建：调用协程函数
  ↓
执行：开始执行
  ↓
暂停：遇到 co_await 或 co_yield
  ↓
恢复：resume() 恢复执行
  ↓
（可能多次暂停和恢复）
  ↓
完成：co_return 或执行到末尾
  ↓
销毁：协程对象销毁
```

---

#### 2.3 简单协程示例

**生成器（Generator）**：
```cpp
Generator<int> fibonacci() {
    int a = 0, b = 1;
    while (true) {
        co_yield a;  // 暂停并返回 a
        int next = a + b;
        a = b;
        b = next;
    }
}

// 使用
auto gen = fibonacci();
cout << gen.next();  // 0
cout << gen.next();  // 1
cout << gen.next();  // 1
cout << gen.next();  // 2
```

**异步任务（Async Task）**：
```cpp
Task<string> fetchUrl(string url) {
    auto data = co_await httpGet(url);  // 暂停，等待 HTTP 请求
    co_return data;
}

// 使用
auto task = fetchUrl("http://example.com");
string data = co_await task;  // 等待任务完成
```

### 任务3：协程应用场景（预计30分钟）

#### 3.1 异步 I/O

**问题**：
- I/O 操作慢（等待时间长）
- 阻塞会降低性能

**协程解决方案**：
```cpp
Task<void> handleClient(int fd) {
    while (true) {
        auto data = co_await asyncRead(fd);  // 暂停，不阻塞
        auto result = process(data);
        co_await asyncWrite(fd, result);     // 暂停，不阻塞
    }
}
```

**好处**：
- 等待 I/O 时暂停，让出 CPU
- 其他协程继续执行
- 充分利用 CPU

---

#### 3.2 生成器（Generator）

**问题**：
- 生成大量数据占用内存
- 需要惰性求值（Lazy Evaluation）

**协程解决方案**：
```cpp
Generator<int> range(int start, int end) {
    for (int i = start; i < end; i++) {
        co_yield i;  // 按需生成
    }
}

// 使用
for (int i : range(0, 1000000)) {
    cout << i << endl;
    if (i > 10) break;  // 只生成了 11 个数，不是 100 万
}
```

---

#### 3.3 协程 + Reactor

**传统 Reactor**：
```cpp
class ReadHandler {
    void handleEvent() {
        recv(fd, buf, ...);
        pool->enqueue([buf, fd]() {
            process(buf);
            send(fd, result, ...);
        });
    }
};
```

**协程 + Reactor**：
```cpp
Task<void> handleClient(int fd, Reactor* reactor) {
    while (true) {
        auto data = co_await reactor->asyncRead(fd);  // 协程化
        auto result = process(data);
        co_await reactor->asyncWrite(fd, result);
    }
}
```

**好处**：
- 代码更清晰（同步写法）
- 逻辑更集中
- 易于理解和维护
