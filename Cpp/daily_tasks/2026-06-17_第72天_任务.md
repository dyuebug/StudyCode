### 任务1：epoll + 线程池架构（预计60分钟）

#### 1.1 为什么需要线程池？

**问题场景**：单线程 epoll 的瓶颈

```
epoll 事件循环（单线程）：
  epoll_wait() → 返回就绪的 fd
  ↓
  处理 fd（recv + 业务逻辑 + send）← 如果业务逻辑很慢怎么办？
  ↓
  继续 epoll_wait()
```

**瓶颈**：
- epoll 负责 I/O 事件监听（快）
- 业务逻辑处理可能很慢（数据库查询、文件操作、计算）
- 如果业务逻辑在主线程处理，会阻塞 epoll_wait
- → 其他就绪的 fd 无法及时处理

**解决方案**：epoll + 线程池

```
主线程（epoll 事件循环）：
  epoll_wait() → 返回就绪的 fd
  ↓
  将 fd 的处理任务放入任务队列
  ↓
  立即继续 epoll_wait()（不阻塞）

工作线程池：
  从任务队列取出任务
  ↓
  处理业务逻辑（可以慢）
  ↓
  完成后通知主线程
```

---

#### 1.2 架构设计

**职责划分**：

| 角色 | 职责 | 特点 |
|------|------|------|
| **主线程** | epoll_wait 监听事件 | 轻量、快速 |
| **工作线程** | 处理业务逻辑 | 可以慢、可以阻塞 |
| **任务队列** | 连接主线程和工作线程 | 线程安全 |

**数据流**：
```
客户端数据到达
  ↓
主线程：epoll_wait 返回
  ↓
主线程：recv 接收数据
  ↓
主线程：创建任务，放入队列
  ↓
工作线程：从队列取任务
  ↓
工作线程：处理业务逻辑
  ↓
工作线程：send 发送结果
```

---

#### 1.3 竞态问题

**问题**：同一个 fd 可能被多个线程同时处理

**场景**：
```
时刻1：主线程 epoll_wait 返回 fd=5（有数据）
时刻2：主线程将 fd=5 的任务放入队列
时刻3：工作线程 A 从队列取出 fd=5 的任务，开始处理
时刻4：主线程再次 epoll_wait 返回 fd=5（又有数据）← 问题！
时刻5：主线程又将 fd=5 的任务放入队列
时刻6：工作线程 B 从队列取出 fd=5 的任务，开始处理

结果：工作线程 A 和 B 同时处理 fd=5
  → 数据乱序
  → 竞态条件
  → 程序崩溃
```

**解决方案**：EPOLLONESHOT

### 任务2：EPOLLONESHOT 详解（预计30分钟）

#### 2.1 EPOLLONESHOT 的作用

**含义**：One Shot = 一次性触发

**行为**：
- fd 就绪后，epoll_wait 返回一次
- 之后 epoll 自动将该 fd 从监听列表移除
- 直到你用 EPOLL_CTL_MOD 重新注册

**目的**：确保同一个 fd 同时只被一个线程处理

---

#### 2.2 工作流程

**不使用 EPOLLONESHOT（有竞态）**：
```
epoll_wait 返回 fd=5
  ↓
主线程：将 fd=5 任务放入队列
  ↓
主线程：继续 epoll_wait
  ↓
epoll_wait 又返回 fd=5（新数据到达）← 问题
  ↓
主线程：又将 fd=5 任务放入队列
  ↓
两个工作线程同时处理 fd=5 ← 竞态
```

**使用 EPOLLONESHOT（无竞态）**：
```
epoll_wait 返回 fd=5
  ↓
epoll 自动移除 fd=5（不再监听）
  ↓
主线程：将 fd=5 任务放入队列
  ↓
主线程：继续 epoll_wait
  ↓
epoll_wait 不会返回 fd=5（已移除）
  ↓
工作线程：处理 fd=5
  ↓
工作线程：处理完成后，用 EPOLL_CTL_MOD 重新注册 fd=5
  ↓
epoll 重新监听 fd=5
```

---

#### 2.3 EPOLLONESHOT 代码

**注册时设置 EPOLLONESHOT**：
```cpp
struct epoll_event ev;
ev.events = EPOLLIN | EPOLLET | EPOLLONESHOT;  // 一次性触发
ev.data.fd = client_fd;
epoll_ctl(epfd, EPOLL_CTL_ADD, client_fd, &ev);
```

**处理完成后重新注册**：
```cpp
// 工作线程处理完 fd 后
ev.events = EPOLLIN | EPOLLET | EPOLLONESHOT;
ev.data.fd = fd;
epoll_ctl(epfd, EPOLL_CTL_MOD, fd, &ev);  // 重新注册
```

### 任务3：epoll + 线程池服务器实战（预计60分钟）

**项目目标**：实现 epoll ET + 线程池 + EPOLLONESHOT

**文件**：`high_performance/03_epoll_threadpool.cpp`

**实现步骤**：

#### Step 1：准备线程池

```cpp
class ThreadPool {

```

#### Step 2：主线程 epoll 循环

```cpp
while (true) {
    int n = epoll_wait(epfd, events, MAX_EVENTS, -1);
    
    for (int i = 0; i < n; i++) {
        int fd = events[i].data.fd;
        
        if (fd == listen_fd) {
            // 新连接：主线程处理（快）
            // accept + setNonBlocking + epoll_ctl ADD
        } else {
            // 数据到达：交给线程池处理
            pool.enqueue([fd, epfd]() {
                handleClient(fd, epfd);
            });
        }
    }
}
```

#### Step 3：工作线程处理函数

```cpp
void handleClient(int fd, int epfd) {
    // 循环读取数据（ET 模式）
    while (true) {
        char buf[1024];
        int n = recv(fd, buf, sizeof(buf), 0);
        
        if (n > 0) {
            // 处理业务逻辑（可以很慢）
            process_business_logic(buf, n);
            
            // 回显数据
            send(fd, buf, n, 0);
        } else if (n == 0) {
            // 连接关闭
            epoll_ctl(epfd, EPOLL_CTL_DEL, fd, NULL);
            close(fd);
            return;
        } else {
            if (errno == EAGAIN) {
                break;  // 数据读完
            } else {
                // 错误
                epoll_ctl(epfd, EPOLL_CTL_DEL, fd, NULL);
                close(fd);
                return;
            }
        }
    }
    
    // ⭐ 重新注册 fd（EPOLLONESHOT）
    struct epoll_event ev;
    ev.events = EPOLLIN | EPOLLET | EPOLLONESHOT;
    ev.data.fd = fd;
    epoll_ctl(epfd, EPOLL_CTL_MOD, fd, &ev);
}
```
