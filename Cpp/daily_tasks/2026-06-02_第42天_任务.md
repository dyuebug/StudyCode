### 2. 计算器核心逻辑

```cpp
double m_firstNum = 0;
QString m_operator = "";
bool m_waitingForSecond = false;

void onNumberClicked(const QString &num) {
    if (m_waitingForSecond) {
        m_display->setText(num);
        m_waitingForSecond = false;
    } else {
        if (m_display->text() == "0")
            m_display->setText(num);
        else
            m_display->setText(m_display->text() + num);
    }
}

void onOperatorClicked(const QString &op) {
    m_firstNum = m_display->text().toDouble();
    m_operator = op;
    m_waitingForSecond = true;
}

void onEquals() {
    double second = m_display->text().toDouble();
    double result = 0;
    if (m_operator == "+") result = m_firstNum + second;
    else if (m_operator == "-") result = m_firstNum - second;
    else if (m_operator == "×") result = m_firstNum * second;
    else if (m_operator == "÷") {
        if (second == 0) { /* 除零保护 */ return; }
        result = m_firstNum / second;
    }
    m_display->setText(QString::number(result));
    m_waitingForSecond = true;  // 支持连续运算
}
```

## 💭 学习建议

1. **先搭界面，再写逻辑**：界面和逻辑分开，更容易调试
2. **用成员变量保存状态**：`m_firstNum`、`m_operator`、`m_waitingForSecond`
3. **Lambda 连接按钮**：用 Lambda 捕获按钮文字，避免写大量槽函数
4. **测试边界情况**：除零、连续运算、小数点重复输入
