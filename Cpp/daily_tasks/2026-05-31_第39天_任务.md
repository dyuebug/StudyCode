## 📚 学习重点

### 1. 更多控件的使用

**QComboBox（下拉框）**：
```cpp
QComboBox *combo = new QComboBox();
combo->addItem("选项1");
combo->addItems({"选项2", "选项3", "选项4"});
QString current = combo->currentText();
```

**QCheckBox（复选框）**：
```cpp
QCheckBox *check = new QCheckBox("同意条款");
check->setChecked(true);
bool isChecked = check->isChecked();
```

**QRadioButton（单选按钮）**：
```cpp
QRadioButton *radio1 = new QRadioButton("男");
QRadioButton *radio2 = new QRadioButton("女");
radio1->setChecked(true);
```

**QSpinBox（数字输入框）**：
```cpp
QSpinBox *spin = new QSpinBox();
spin->setRange(18, 100);
spin->setValue(25);
int value = spin->value();
```

### 2. 高级布局管理

**QGridLayout（网格布局）**：
```cpp
QGridLayout *grid = new QGridLayout();
grid->addWidget(label1, 0, 0);  // 第0行第0列
grid->addWidget(edit1, 0, 1);   // 第0行第1列
grid->addWidget(label2, 1, 0);  // 第1行第0列
grid->addWidget(edit2, 1, 1);   // 第1行第1列
```

**QFormLayout（表单布局）**：
```cpp
QFormLayout *form = new QFormLayout();
form->addRow("姓名：", nameEdit);
form->addRow("年龄：", ageSpinBox);
form->addRow("城市：", cityCombo);
```

### 3. 表单验证

```cpp
void onSubmitClicked()
{
    // 验证姓名
    QString name = nameEdit->text().trimmed();
    if (name.isEmpty()) {
        QMessageBox::warning(this, "错误", "请输入姓名！");
        return;
    }
    
    // 验证年龄
    int age = ageSpinBox->value();
    if (age < 18 || age > 100) {
        QMessageBox::warning(this, "错误", "年龄必须在18-100之间！");
        return;
    }
    
    // 验证爱好
    if (!hobby1->isChecked() && !hobby2->isChecked() && !hobby3->isChecked()) {
        QMessageBox::warning(this, "错误", "请至少选择一个爱好！");
        return;
    }
    
    // 提交成功
    QMessageBox::information(this, "成功", "注册成功！");
}
```
