### 任务1：学习概念（Concepts）基础（预计50分钟）

**什么是概念（Concepts）？**

概念（Concepts）是 C++20 引入的重要特性：
- 为模板参数提供命名的约束
- 比 SFINAE 更清晰、更易读
- 编译错误信息更友好
- 是现代 C++ 模板编程的最佳实践

**为什么需要概念？**

**SFINAE 的问题**：
```cpp
// SFINAE 方式：难以理解
template<typename T>
enable_if_t<is_integral<T>::value>
func(T value) {
    cout << value << endl;
}

// 编译错误信息：
// error: no matching function for call to 'func(double)'
// note: candidate template ignored: requirement 'is_integral<double>::value' was not satisfied
```

**概念的优势**：
```cpp
// 概念方式：清晰易读
template<typename T>
requires std::integral<T>
void func(T value) {
    cout << value << endl;
}

// 或者更简洁：
template<std::integral T>
void func(T value) {
    cout << value << endl;
}

// 编译错误信息：
// error: no matching function for call to 'func(double)'
// note: constraints not satisfied
// note: the expression 'std::integral<double>' evaluated to false
```

**概念的定义语法**：

```cpp
// 基本语法
template<typename T>
concept 概念名 = 约束表达式;

// 示例1：整数概念
template<typename T>
concept Integral = std::is_integral_v<T>;

// 示例2：可加概念
template<typename T>
concept Addable = requires(T a, T b) {
    { a + b } -> std::same_as<T>;
};

// 示例3：有 size() 方法的概念
template<typename T>
concept HasSize = requires(T t) {
    { t.size() } -> std::convertible_to<std::size_t>;
};
```

**概念的使用方式**：

**方式1：requires 子句**
```cpp
template<typename T>
requires Integral<T>
void func(T value) {
    cout << value << endl;
}
```

**方式2：简写形式（推荐）**
```cpp
template<Integral T>
void func(T value) {
    cout << value << endl;
}
```

**方式3：尾置 requires**
```cpp
template<typename T>
void func(T value) requires Integral<T> {
    cout << value << endl;
}
```

**方式4：auto 参数（C++20）**
```cpp
void func(Integral auto value) {
    cout << value << endl;
}
```

**requires 表达式**：

```cpp
// 简单要求：表达式必须有效
template<typename T>
concept HasPlusOperator = requires(T a, T b) {
    a + b;  // 必须支持 + 运算符
};

// 类型要求：表达式必须返回特定类型
template<typename T>
concept ReturnsInt = requires(T t) {
    { t.getValue() } -> std::same_as<int>;
};

// 复合要求：多个要求
template<typename T>
concept Container = requires(T t) {
    typename T::value_type;  // 必须有 value_type 类型
    { t.size() } -> std::convertible_to<std::size_t>;  // 必须有 size() 方法
    { t.begin() } -> std::same_as<typename T::iterator>;  // 必须有 begin() 方法
    { t.end() } -> std::same_as<typename T::iterator>;  // 必须有 end() 方法
};

// 嵌套要求
template<typename T>
concept Sortable = requires(T t) {
    requires std::random_access_iterator<typename T::iterator>;
    requires std::totally_ordered<typename T::value_type>;
};
```

**标准库提供的概念**：

```cpp
// 核心语言概念（<concepts>）
std::same_as<T, U>           // T 和 U 是相同类型
std::derived_from<T, U>      // T 派生自 U
std::convertible_to<T, U>    // T 可以转换为 U
std::integral<T>             // T 是整数类型
std::floating_point<T>       // T 是浮点类型
std::signed_integral<T>      // T 是有符号整数
std::unsigned_integral<T>    // T 是无符号整数

// 比较概念
std::equality_comparable<T>  // T 支持 == 和 !=
std::totally_ordered<T>      // T 支持 <, >, <=, >=

// 对象概念
std::movable<T>              // T 可以移动
std::copyable<T>             // T 可以拷贝
std::semiregular<T>          // T 可以默认构造和拷贝
std::regular<T>              // T 是规则类型（semiregular + equality_comparable）

// 可调用概念
std::invocable<F, Args...>   // F 可以用 Args... 调用
std::predicate<F, Args...>   // F 是谓词（返回 bool）

// 迭代器概念（<iterator>）
std::input_iterator<T>       // T 是输入迭代器
std::output_iterator<T, V>   // T 是输出迭代器
std::forward_iterator<T>     // T 是前向迭代器
std::bidirectional_iterator<T>  // T 是双向迭代器
std::random_access_iterator<T>  // T 是随机访问迭代器

// 范围概念（<ranges>）
std::ranges::range<T>        // T 是范围（有 begin/end）
std::ranges::sized_range<T>  // T 是有大小的范围
std::ranges::view<T>         // T 是视图
```

```cpp
void print(const T& value) {
    cout << value << endl;

// 示例4：容器概念
template<typename T>
concept Container = requires(T t) {
    typename T::value_type;

    { t.end() };

template<Container C>

        cout << item;
        first = false;

    cout << "]" << endl;

template<typename T>
concept Addable = requires(T a, T b) {

concept Comparable = std::totally_ordered<T>;

template<typename T>
requires Addable<T> && Comparable<T>

    T sum1 = a + b;
    T sum2 = b + c;
    return sum1 > sum2 ? sum1 : sum2;
}

    // 示例2：Printable 概念

        print_container(vec);

    // 示例4：多个概念组合
```

### 任务2：学习 requires 表达式和约束（预计50分钟）

**requires 表达式的四种形式**：

**1. 简单要求（Simple Requirements）**
```cpp
template<typename T>
concept HasPlusOperator = requires(T a, T b) {
    a + b;  // 表达式必须有效
};
```

**2. 类型要求（Type Requirements）**
```cpp
template<typename T>
concept HasValueType = requires {
    typename T::value_type;  // 必须有 value_type 类型
    typename T::iterator;    // 必须有 iterator 类型
};
```

**3. 复合要求（Compound Requirements）**
```cpp
template<typename T>
concept HasSize = requires(T t) {
    { t.size() } -> std::convertible_to<size_t>;  // 返回类型约束
    { t.empty() } noexcept -> std::same_as<bool>;  // noexcept 约束
};
```

**4. 嵌套要求（Nested Requirements）**
```cpp
template<typename T>
concept Sortable = requires(T t) {
    requires std::random_access_iterator<typename T::iterator>;
    requires std::totally_ordered<typename T::value_type>;
};
```

**约束的组合**：

```cpp
// 逻辑与（&&）
template<typename T>
concept SignedIntegral = std::integral<T> && std::signed_integral<T>;

// 逻辑或（||）
template<typename T>
concept Numeric = std::integral<T> || std::floating_point<T>;

// 逻辑非（!）
template<typename T>
concept NotPointer = !std::is_pointer_v<T>;

// 复杂组合
template<typename T>
concept StringLike = 
    std::convertible_to<T, std::string> ||
    std::same_as<T, const char*> ||
    std::same_as<T, char*>;
```

**概念的特化**：

```cpp
// 基础概念
template<typename T>
concept Arithmetic = std::integral<T> || std::floating_point<T>;

// 特化概念
template<Arithmetic T>
T multiply(T a, T b) {
    return a * b;
}

// 更特化的版本（整数优化）
template<std::integral T>
T multiply(T a, T b) {
    cout << "整数乘法优化" << endl;
    return a * b;
}

// 调用
multiply(10, 20);      // 调用整数版本
multiply(3.14, 2.0);   // 调用通用版本
```

```cpp
#include <iostream>
#include <concepts>
#include <vector>
#include <string>
using namespace std;

// 示例1：简单要求
template<typename T>
concept Addable = requires(T a, T b) {
    a + b;
};

// 示例2：类型要求
template<typename T>
concept HasIterator = requires {
    typename T::iterator;
    typename T::value_type;
};

// 示例3：复合要求
template<typename T>
concept Container = requires(T t) {
    { t.size() } -> std::convertible_to<size_t>;
    { t.begin() } -> std::same_as<typename T::iterator>;
    { t.end() } -> std::same_as<typename T::iterator>;
};

// 示例4：嵌套要求
template<typename T>
concept SortableContainer = requires(T t) {
    requires Container<T>;
    requires std::totally_ordered<typename T::value_type>;
};

// 示例5：约束组合
template<typename T>
concept NumericOrString = 
    std::integral<T> || 
    std::floating_point<T> || 
    std::same_as<T, string>;

template<NumericOrString T>
void process(const T& value) {
    if constexpr (std::integral<T>) {
        cout << "处理整数：" << value << endl;
    } else if constexpr (std::floating_point<T>) {
        cout << "处理浮点数：" << value << endl;
    } else {
        cout << "处理字符串：" << value << endl;
    }
}

// 示例6：概念特化
template<typename T>
concept Arithmetic = std::integral<T> || std::floating_point<T>;

template<Arithmetic T>
T square(T value) {
    return value * value;
}

template<std::integral T>
T square(T value) {
    cout << "整数平方优化" << endl;
    return value * value;
}

int main() {
    cout << "=== requires 表达式示例 ===" << endl;
    
    // 示例1：Addable 概念
    {
        cout << "\n【示例1】Addable 概念" << endl;
        cout << string(60, '-') << endl;
        
        auto add = []<Addable T>(T a, T b) {
            return a + b;
        };
        
        cout << "add(10, 20) = " << add(10, 20) << endl;
        cout << "add(3.14, 2.86) = " << add(3.14, 2.86) << endl;
        cout << "add(\"hello\", \"world\") = " << add(string("hello"), string("world")) << endl;
    }
    
    // 示例2：Container 概念
    {
        cout << "\n【示例2】Container 概念" << endl;
        cout << string(60, '-') << endl;
        
        auto print_size = []<Container C>(const C& c) {
            cout << "容器大小：" << c.size() << endl;
        };
        
        vector<int> vec = {1, 2, 3, 4, 5};
        print_size(vec);
        
        string str = "hello";
        print_size(str);
    }
    
    // 示例3：NumericOrString 概念
    {
        cout << "\n【示例3】NumericOrString 概念" << endl;
        cout << string(60, '-') << endl;
        
        process(42);
        process(3.14);
        process(string("Hello"));
    }
    
    // 示例4：概念特化
    {
        cout << "\n【示例4】概念特化" << endl;
        cout << string(60, '-') << endl;
        
        cout << "square(10) = " << square(10) << endl;
        cout << "square(3.14) = " << square(3.14) << endl;
    }
    
    return 0;
}
```

### 任务3：综合实践 - 使用概念重写通用打印函数（预计20分钟）

**目标**：使用 C++20 概念重写昨天的通用打印函数，使代码更清晰易读

创建文件 `cpp_basics/87_concepts_print.cpp`：
```cpp
#include <iostream>
#include <concepts>
#include <vector>
#include <map>
#include <set>
#include <string>
using namespace std;

// ============================================
// 概念定义
// ============================================

// 算术类型概念
template<typename T>
concept Arithmetic = std::integral<T> || std::floating_point<T>;

// 字符串类型概念
template<typename T>
concept StringLike = 
    std::same_as<T, string> || 
    std::same_as<T, const char*>;

// 容器概念
template<typename T>
concept Container = requires(T t) {
    typename T::value_type;
    { t.begin() };
    { t.end() };
} && !std::same_as<T, string>;

// ============================================
// 打印函数（使用概念）
// ============================================

// 1. 打印算术类型
template<Arithmetic T>
void print(const T& value) {
    cout << value;
}

// 2. 打印布尔值
void print(bool value) {
    cout << (value ? "true" : "false");
}

// 3. 打印字符串
template<StringLike T>
void print(const T& value) {
    cout << "\"" << value << "\"";
}

// 4. 打印字符
void print(char value) {
    cout << "'" << value << "'";
}

// 5. 打印指针
template<typename T>
requires std::is_pointer_v<T> && !std::same_as<T, const char*>
void print(const T& value) {
    if (value == nullptr) {
        cout << "nullptr";
    } else {
        cout << "ptr(" << value << ")";
    }
}

// 6. 打印 pair
template<typename T1, typename T2>
void print(const pair<T1, T2>& p) {
    cout << "(";
    print(p.first);
    cout << ", ";
    print(p.second);
    cout << ")";
}

// 7. 打印容器
template<Container C>
void print(const C& container) {
    cout << "[";
    bool first = true;
    for (const auto& item : container) {
        if (!first) cout << ", ";
        print(item);
        first = false;
    }
    cout << "]";
}

// 8. 可变参数打印
template<typename... Args>
void println(Args&&... args) {
    (print(args), ...);
    cout << endl;
}

int main() {
    cout << "=== 使用概念的通用打印函数 ===" << endl;
    
    // 示例1：基本类型
    {
        cout << "\n【示例1】基本类型" << endl;
        cout << string(60, '-') << endl;
        
        println(42, ", ", 3.14, ", ", true, ", ", 'A');
    }
    
    // 示例2：字符串
    {
        cout << "\n【示例2】字符串" << endl;
        cout << string(60, '-') << endl;
        
        println(string("Hello"), ", ", "World");
    }
    
    // 示例3：容器
    {
        cout << "\n【示例3】容器" << endl;
        cout << string(60, '-') << endl;
        
        vector<int> vec = {1, 2, 3, 4, 5};
        println(vec);
        
        set<int> s = {5, 3, 1, 4, 2};
        println(s);
    }
    
    // 示例4：嵌套容器
    {
        cout << "\n【示例4】嵌套容器" << endl;
        cout << string(60, '-') << endl;
        
        vector<vector<int>> nested = {{1, 2}, {3, 4}, {5, 6}};
        println(nested);
        
        vector<pair<int, string>> pairs = {
            {1, "one"},
            {2, "two"},
            {3, "three"}
        };
        println(pairs);
    }
    
    return 0;
}
```
