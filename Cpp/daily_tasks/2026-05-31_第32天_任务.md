### 任务1：学习可变参数模板（预计50分钟）

**什么是可变参数模板？**

可变参数模板（Variadic Templates）是 C++11 引入的特性：
- 允许模板接受任意数量的参数
- 参数类型可以不同
- 是实现泛型库的关键技术

**基本语法**：

```cpp
// 可变参数函数模板
template<typename... Args>
void func(Args... args) {
    // Args 是模板参数包
    // args 是函数参数包
}

// 调用
func(1, 2.5, "hello", 'c');  // 4个不同类型的参数
```

**参数包的大小**：

```cpp
template<typename... Args>
void func(Args... args) {
    cout << "参数个数：" << sizeof...(Args) << endl;
    cout << "参数个数：" << sizeof...(args) << endl;
}

func(1, 2, 3);  // 输出：参数个数：3
```

**递归展开参数包**：

```cpp
// 递归终止条件
void print() {
    cout << endl;
}

// 递归展开
template<typename T, typename... Args>
void print(T first, Args... rest) {
    cout << first << " ";
    print(rest...);  // 递归调用
}

// 使用
print(1, 2.5, "hello", 'c');
// 输出：1 2.5 hello c
```

**折叠表达式（C++17）**：

```cpp
// 左折叠：(... op pack)
template<typename... Args>
auto sum(Args... args) {
    return (... + args);  // ((arg1 + arg2) + arg3) + ...
}

// 右折叠：(pack op ...)
template<typename... Args>
auto sum_right(Args... args) {
    return (args + ...);  // arg1 + (arg2 + (arg3 + ...))
}

// 使用
cout << sum(1, 2, 3, 4, 5) << endl;  // 输出：15
```

**常见的折叠表达式**：

```cpp
// 逻辑与
template<typename... Args>
bool all(Args... args) {
    return (... && args);  // arg1 && arg2 && arg3 && ...
}

// 逻辑或
template<typename... Args>
bool any(Args... args) {
    return (... || args);  // arg1 || arg2 || arg3 || ...
}

// 逗号运算符（执行所有表达式）
template<typename... Args>
void call_all(Args... args) {
    (args(), ...);  // arg1(), arg2(), arg3(), ...
}
```

**参数包展开的方式**：

```cpp
// 1. 函数调用
template<typename... Args>
void wrapper(Args... args) {
    func(args...);  // 展开为 func(arg1, arg2, arg3, ...)
}

// 2. 初始化列表
template<typename... Args>
void init(Args... args) {
    int arr[] = {args...};  // 展开为 {arg1, arg2, arg3, ...}
}

// 3. 模板参数
template<typename... Args>
void create(Args... args) {
    tuple<Args...> t(args...);  // 展开为 tuple<T1, T2, T3>
}

// 4. 表达式
template<typename... Args>
void process(Args... args) {
    int arr[] = {(cout << args << " ", 0)...};
    // 展开为：{(cout << arg1 << " ", 0), (cout << arg2 << " ", 0), ...}
}
```

### 任务2：学习 SFINAE（预计50分钟）

**什么是 SFINAE？**

SFINAE（Substitution Failure Is Not An Error）：
- 替换失败不是错误
- 模板参数替换失败时，编译器不报错，而是尝试其他重载
- 用于在编译期进行类型检查和条件编译

**基本概念**：

```cpp
// 示例：只接受整数类型
template<typename T>
typename enable_if<is_integral<T>::value, T>::type
func(T value) {
    return value * 2;
}

// 调用
func(10);      // OK：int 是整数类型
func(3.14);    // 错误：double 不是整数类型
```

**enable_if 的使用**：

```cpp
// enable_if 的定义（简化版）
template<bool B, typename T = void>
struct enable_if {};

template<typename T>
struct enable_if<true, T> {
    using type = T;
};

// 使用方式1：返回类型
template<typename T>
typename enable_if<is_integral<T>::value, T>::type
func1(T value) { return value; }

// 使用方式2：模板参数
template<typename T, typename = enable_if_t<is_integral<T>::value>>
void func2(T value) { cout << value << endl; }

// 使用方式3：函数参数
template<typename T>
void func3(T value, enable_if_t<is_integral<T>::value>* = nullptr) {
    cout << value << endl;
}
```

**类型萃取（Type Traits）**：

```cpp
// 常用的类型萃取
is_integral<T>::value        // 是否是整数类型
is_floating_point<T>::value  // 是否是浮点类型
is_pointer<T>::value         // 是否是指针类型
is_array<T>::value           // 是否是数组类型
is_class<T>::value           // 是否是类类型
is_same<T, U>::value         // 两个类型是否相同

// C++17 简化版本
is_integral_v<T>             // 等价于 is_integral<T>::value
```

**SFINAE 的应用场景**：

```cpp
// 1. 函数重载选择
template<typename T>
enable_if_t<is_integral<T>::value>
print(T value) {
    cout << "整数：" << value << endl;
}

template<typename T>
enable_if_t<is_floating_point<T>::value>
print(T value) {
    cout << "浮点数：" << value << endl;
}

// 2. 检测成员函数是否存在
template<typename T>
class has_size {
    template<typename U>
    static auto test(int) -> decltype(declval<U>().size(), true_type{});
    
    template<typename>
    static false_type test(...);
    
public:
    static constexpr bool value = decltype(test<T>(0))::value;
};

// 3. 条件编译
template<typename T>
void process(T& container) {
    if constexpr (has_size<T>::value) {
        cout << "容器大小：" << container.size() << endl;
    } else {
        cout << "不支持 size()" << endl;
    }
}
```

### 任务3：综合实践（预计20分钟）

**目标**：实现一个通用的打印函数，支持各种类型

创建文件 `cpp_basics/84_advanced_print.cpp`：
```cpp
#include <iostream>
#include <vector>
#include <map>
#include <type_traits>
using namespace std;

// 前向声明
template<typename T>
void print(const T& value);

// 1. 打印基本类型
template<typename T>
enable_if_t<is_arithmetic<T>::value>
print(const T& value) {
    cout << value;
}

// 2. 打印字符串
void print(const string& value) {
    cout << "\"" << value << "\"";
}

// 3. 打印指针
template<typename T>
enable_if_t<is_pointer<T>::value>
print(const T& value) {
    cout << "ptr(" << value << ")";
}

// 4. 打印容器（有 begin/end 的类型）
template<typename T>
auto print_container(const T& container) 
    -> decltype(container.begin(), container.end(), void()) {
    cout << "[";
    bool first = true;
    for (const auto& item : container) {
        if (!first) cout << ", ";
        print(item);
        first = false;
    }
    cout << "]";
}

// 5. 打印 pair
template<typename T1, typename T2>
void print(const pair<T1, T2>& p) {
    cout << "(";
    print(p.first);
    cout << ", ";
    print(p.second);
    cout << ")";
}

// 6. 可变参数打印
template<typename... Args>
void println(Args... args) {
    (print(args), ...);
    cout << endl;
}

int main() {
    cout << "=== 通用打印函数示例 ===" << endl;
    
    // 基本类型
    cout << "\n基本类型：";
    println(42, ", ", 3.14, ", ", true);
    
    // 字符串
    cout << "字符串：";
    println(string("Hello"), ", ", string("World"));
    
    // 容器
    cout << "vector：";
    vector<int> vec = {1, 2, 3, 4, 5};
    print_container(vec);
    cout << endl;
    
    // pair
    cout << "pair：";
    println(make_pair(1, string("one")));
    
    // 嵌套容器
    cout << "嵌套 vector：";
    vector<vector<int>> nested = {{1, 2}, {3, 4}, {5, 6}};
    print_container(nested);
    cout << endl;
    
    return 0;
}
```
