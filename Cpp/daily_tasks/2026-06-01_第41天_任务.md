## 📚 学习重点

### 1. QMessageBox 四种类型对比

| 类型 | 方法 | 图标 | 用途 |
|------|------|------|------|
| 信息 | `information()` | ℹ️ | 普通提示 |
| 警告 | `warning()` | ⚠️ | 警告用户 |
| 错误 | `critical()` | ❌ | 严重错误 |
| 询问 | `question()` | ❓ | 确认操作 |

### 2. QMessageBox::question 返回值处理

```cpp
auto reply = QMessageBox::question(this, "确认", "确定要删除吗？",
    QMessageBox::Yes | QMessageBox::No);
if (reply == QMessageBox::Yes) {
    // 执行删除
}
```

### 3. QFileDialog 文件过滤器

```cpp
QString file = QFileDialog::getOpenFileName(
    this,
    "选择图片",           // 标题
    QDir::homePath(),    // 默认目录
    "图片文件 (*.png *.jpg *.bmp);;所有文件 (*.*)"  // 过滤器
);
if (!file.isEmpty()) {
    // 使用文件路径
}
```

### 4. 模态 vs 非模态

```cpp
// 模态：阻塞父窗口，等待用户关闭
dialog.exec();   // 返回 Accepted 或 Rejected

// 非模态：不阻塞，父窗口可继续操作
dialog.show();   // 立即返回
```

## 💭 学习建议

1. **标准对话框优先**：QMessageBox、QFileDialog 是最常用的，先熟练掌握
2. **注意返回值**：`exec()` 返回 `QDialog::Accepted`（1）或 `QDialog::Rejected`（0）
3. **文件路径处理**：Qt 统一使用正斜杠 `/`，跨平台兼容
4. **自定义对话框**：实际项目中最常用，要掌握标准继承写法
5. **空路径检查**：用户取消文件对话框时返回空字符串，要检查 `!file.isEmpty()`
