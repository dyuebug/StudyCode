## 🎓 学习重点

### 核心概念

**调度策略的三个维度**：
```
1. 效率：吞吐量、延迟
2. 公平性：防止饥饿
3. 灵活性：支持优先级
```

**调度策略的选择**：
```
FIFO     → 简单场景，任务平等
优先级   → 重要性有差异
公平调度 → 防止饥饿
负载均衡 → 多线程调度
```

### 关键技术

**优先级调度**：
- std::priority_queue<handle, vector<handle>, Comparator>
- 自定义比较器
- 优先级反转处理

**公平调度**：
- 轮询算法：每个协程轮流执行
- 时间片：每个协程执行固定次数
- 统计执行次数

**负载均衡**：
- 工作窃取：空闲线程从忙碌线程偷任务
- 多队列：每个线程一个队列
- 亲和性：协程绑定到特定线程

## 💡 学习提示

### 昨日回顾

**调度器的作用**：
1. 协程生命周期管理
2. 任务调度
3. 状态追踪

**简单调度器**：
```cpp
void run() {
    while (!queue.empty()) {
        auto h = queue.front(); queue.pop();
        h.resume();
        if (!h.done()) queue.push(h);
        else h.destroy();
    }
}
```

### 今日重点

**优先级调度器**：
```cpp
// 核心：使用 priority_queue
std::priority_queue<
    std::coroutine_handle<>,
    std::vector<std::coroutine_handle<>>,
    TaskComparator
> task_queue;
```

**公平调度器**：
```cpp
// 核心：轮询 + 执行次数限制
for (int i = 0; i < time_slice; ++i) {
    handle.resume();
}
```

### 常见问题预防

**问题1**：优先级反转
- 高优先级协程被低优先级协程阻塞
- 解决：优先级继承

**问题2**：饥饿问题
- 低优先级协程永远得不到执行
- 解决：老化机制、公平调度

**问题3**：时间片设置
- 太小：切换开销大
- 太大：响应慢
- 建议：根据任务类型调整
