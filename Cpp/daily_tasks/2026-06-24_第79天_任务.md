### 任务1：实现 Generator（预计60分钟）

#### 1.1 Generator 的作用

**用途**：
- 惰性生成序列
- 节省内存
- 无限序列

**示例**：
```cpp
Generator<int> fibonacci() {
    int a = 0, b = 1;
    while (true) {
        co_yield a;
        int next = a + b;
        a = b;
        b = next;
    }
}

// 使用
auto gen = fibonacci();
cout << gen.next();  // 0
cout << gen.next();  // 1
cout << gen.next();  // 1
cout << gen.next();  // 2
```

---

#### 1.2 Generator 的实现要点

**需要实现的组件**：

**1. Promise 类型**：
```cpp
struct promise_type {
    // 当前生成的值
    int current_value;
    
    // 协程创建时调用
    Generator get_return_object();
    
    // 协程开始时调用
    suspend_never initial_suspend();
    
    // 协程结束时调用
    suspend_always final_suspend() noexcept;
    
    // co_yield 调用时
    suspend_always yield_value(int value);
    
    // 异常处理
    void unhandled_exception();
};
```

**2. Generator 类**：
```cpp
class Generator {
private:
    std::coroutine_handle<promise_type> handle;
    
public:
    Generator(std::coroutine_handle<promise_type> h);
    ~Generator();
    
    // 获取下一个值
    int next();
    
    // 是否完成
    bool done();
};
```

### 任务2：实现 Task（预计60分钟）

#### 2.1 Task 的作用

**用途**：
- 异步任务
- 可以等待（co_await）
- 返回结果

**示例**：
```cpp
Task<int> calculate() {
    int sum = 0;
    for (int i = 0; i < 10; i++) {
        sum += i;
        co_await suspend_always{};  // 让出 CPU
    }
    co_return sum;
}

// 使用
auto task = calculate();
while (!task.done()) {
    task.resume();  // 手动恢复
}
int result = task.result();  // 45
```

---

#### 2.2 Task 的实现要点

**需要实现的组件**：

**1. Promise 类型**：
```cpp
template<typename T>
struct promise_type {
    T result_value;
    
    Task<T> get_return_object();
    suspend_never initial_suspend();
    suspend_always final_suspend() noexcept;
    
    // co_return 调用时
    void return_value(T value);
    
    void unhandled_exception();
};
```

**2. Task 类**：
```cpp
template<typename T>
class Task {
private:
    std::coroutine_handle<promise_type> handle;
    
public:
    Task(std::coroutine_handle<promise_type> h);
    ~Task();
    
    // 恢复协程
    void resume();
    
    // 是否完成
    bool done();
    
    // 获取结果
    T result();
};
```

### 任务3：理解 Awaitable（预计30分钟）

#### 3.1 Awaitable 的作用

**作用**：
- 定义如何暂停和恢复协程
- co_await 的操作对象

**接口**：
```cpp
struct Awaitable {
    // 是否需要暂停
    bool await_ready();
    
    // 暂停时调用
    void await_suspend(std::coroutine_handle<> handle);
    
    // 恢复时调用，返回 co_await 的结果
    auto await_resume();
};
```

---

#### 3.2 内置的 Awaitable

**suspend_never**：
- 永不暂停
- await_ready() 返回 true

**suspend_always**：
- 总是暂停
- await_ready() 返回 false

---

#### 3.3 自定义 Awaitable

**示例**：延迟执行
```cpp
struct DelayAwaitable {
    int ms;
    
    bool await_ready() { return false; }
    
    void await_suspend(std::coroutine_handle<> h) {
        // 注册定时器，ms 后恢复 h
        scheduler.addTimer(ms, [h]() {
            h.resume();
        });
    }
    
    void await_resume() {}
};

// 使用
Task<void> delayed() {
    co_await DelayAwaitable{1000};  // 延迟 1 秒
    cout << "1 秒后执行" << endl;
}
```

### 任务4：简单协程调度器（可选）

#### 4.1 调度器的作用

**作用**：
- 管理多个协程
- 协程切换
- 协程队列

**示例**：
```cpp
class Scheduler {
private:
    queue<coroutine_handle<>> ready_queue;
    
public:
    void addCoroutine(coroutine_handle<> h) {
        ready_queue.push(h);
    }
    
    void run() {
        while (!ready_queue.empty()) {
            auto h = ready_queue.front();
            ready_queue.pop();
            
            h.resume();  // 恢复协程
            
            if (!h.done()) {
                ready_queue.push(h);  // 未完成，重新入队
            }
        }
    }
};
```
