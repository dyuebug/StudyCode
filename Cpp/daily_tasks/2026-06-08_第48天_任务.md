### 任务1：文件下载器（预计40分钟）
**文件**：`qt_basics/29_file_downloader.cpp`

**学习内容**：
- [ ] downloadProgress 信号（已下载字节数 / 总字节数）
- [ ] QProgressBar 显示下载进度
- [ ] QFile 保存下载内容到本地
- [ ] 取消下载（reply->abort()）
- [ ] 下载速度计算

**核心代码预览**：
```cpp
QNetworkReply *reply = manager->get(request);

// 进度信号
connect(reply, &QNetworkReply::downloadProgress,
        this, [this](qint64 received, qint64 total) {
    if (total > 0) {
        m_progress->setValue(received * 100 / total);
        m_sizeLabel->setText(
            QString("%1 / %2 KB")
                .arg(received/1024).arg(total/1024));
    }
});

// 完成后保存文件
connect(reply, &QNetworkReply::finished, this, [this, reply]() {
    QFile file("download.zip");
    file.open(QIODevice::WriteOnly);
    file.write(reply->readAll());
    file.close();
    reply->deleteLater();
});
```
