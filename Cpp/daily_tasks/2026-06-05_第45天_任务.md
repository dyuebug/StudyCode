### 任务1：Qt SQL 基础（预计40分钟）
**文件**：`qt_basics/20_sql_basics.cpp`

**学习内容**：
- [ ] 连接 SQLite 数据库（QSqlDatabase::addDatabase("QSQLITE")）
- [ ] 创建表（CREATE TABLE IF NOT EXISTS）
- [ ] 插入数据（INSERT INTO）
- [ ] 查询数据（SELECT，遍历 QSqlQuery）
- [ ] 更新数据（UPDATE）
- [ ] 删除数据（DELETE）
- [ ] 错误处理（query.lastError()）

**核心代码预览**：
```cpp
// 连接数据库
QSqlDatabase db = QSqlDatabase::addDatabase("QSQLITE");
db.setDatabaseName("myapp.db");
db.open();

// 执行 SQL
QSqlQuery query;
query.exec("CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY, name TEXT, age INTEGER)");
query.exec("INSERT INTO users (name, age) VALUES ('张三', 25)");

// 查询
query.exec("SELECT * FROM users");
while (query.next()) {
    int id     = query.value(0).toInt();
    QString name = query.value(1).toString();
    int age    = query.value(2).toInt();
}

// 参数化查询（防止 SQL 注入）
query.prepare("INSERT INTO users (name, age) VALUES (:name, :age)");
query.bindValue(":name", "李四");
query.bindValue(":age", 30);
query.exec();
```

### 任务2：QSqlTableModel + QTableView（预计40分钟）
**文件**：`qt_basics/21_sql_tableview.cpp`

**学习内容**：
- [ ] QSqlTableModel：将数据库表绑定为数据模型
- [ ] QTableView：将模型显示为表格
- [ ] 增删改查（通过模型操作，自动同步到数据库）
- [ ] 排序和过滤（setSort、setFilter）

**核心代码预览**：
```cpp
QSqlTableModel *model = new QSqlTableModel(this, db);
model->setTable("users");
model->setEditStrategy(QSqlTableModel::OnManualSubmit);
model->select();  // 加载数据

QTableView *view = new QTableView();
view->setModel(model);

// 插入新行
model->insertRow(model->rowCount());
// 提交更改到数据库
model->submitAll();
// 撤销未提交的更改
model->revertAll();
```

## 📚 重要提示

**必须在 .pro 文件中添加**：
```
QT += sql
```
否则编译时找不到 QSqlDatabase 等类。

**SQLite 特点**：
- 无需安装服务器，数据库就是一个 .db 文件
- 适合桌面应用的本地数据存储
- Qt 内置支持，无需额外安装驱动
