## 📚 学习重点

### 1. Qt Style Sheets 基本语法

**选择器**：
```css
/* 类型选择器 */
QPushButton { background-color: blue; }

/* 类选择器 */
.QPushButton { background-color: blue; }

/* ID选择器 */
#submitButton { background-color: green; }

/* 子控件选择器 */
QComboBox::drop-down { border: none; }
```

**伪状态**：
```css
/* 悬停状态 */
QPushButton:hover { background-color: lightblue; }

/* 按下状态 */
QPushButton:pressed { background-color: darkblue; }

/* 选中状态 */
QCheckBox:checked { color: green; }

/* 禁用状态 */
QPushButton:disabled { color: gray; }
```

**常用属性**：
```css
QPushButton {
    color: white;                    /* 文字颜色 */
    background-color: #3498db;       /* 背景颜色 */
    border: 2px solid #2980b9;       /* 边框 */
    border-radius: 5px;              /* 圆角 */
    padding: 10px 20px;              /* 内边距 */
    font-size: 14px;                 /* 字体大小 */
    font-weight: bold;               /* 字体粗细 */
}
```

### 2. 按钮样式示例

```cpp
QPushButton *btn = new QPushButton("提交");
btn->setStyleSheet(R"(
    QPushButton {
        background-color: #3498db;
        color: white;
        border: none;
        border-radius: 5px;
        padding: 10px 30px;
        font-size: 14px;
    }
    QPushButton:hover {
        background-color: #2980b9;
    }
    QPushButton:pressed {
        background-color: #21618c;
    }
)");
```

### 3. 输入框样式示例

## 💭 学习建议

1. **类比 CSS**：如果有 CSS 基础，学习会更容易
2. **多尝试**：尝试不同的样式组合，看看效果
3. **参考示例**：Qt 官方提供了很多样式表示例
4. **注意兼容性**：不同平台可能有细微差异
5. **保持一致**：统一的样式风格更专业

**重要提示**：
- Qt Style Sheets 语法类似 CSS，但不完全相同
- 使用 R"(...)" 原始字符串字面量避免转义
- 样式可以继承，子控件会继承父控件样式
- 伪状态用冒号（:），子控件用双冒号（::）
- 可以使用十六进制颜色（#RRGGBB）或颜色名称
- 注意性能：复杂的样式可能影响性能
