### 任务1：epoll 理论学习（预计60分钟）

**学习内容**：

#### 1.1 select 的缺陷（为什么需要 epoll）

**select 的三大问题**：
1. **性能问题**：O(n) 轮询所有 fd，效率低
2. **数量限制**：默认最多监听 1024 个 fd（FD_SETSIZE）
3. **重复设置**：每次调用都要重新设置 fd_set

**实际影响**：
- 1000 个连接，只有 10 个活跃，也要轮询 1000 次
- 大量 CPU 时间浪费在无效检查上
- 无法支持高并发场景（如 C10K 问题）

---

#### 1.2 epoll 的优势

**epoll 的三大改进**：
1. **事件通知**：O(1) 获取就绪 fd，不需要轮询
2. **无数量限制**：受限于系统资源，不是硬编码
3. **状态维护**：内核维护 fd 状态，不需要每次重设

**性能对比**：
- select：连接数 ↑，性能 ↓（线性下降）
- epoll：连接数 ↑，性能稳定（活跃连接决定）

---

#### 1.3 epoll 内部原理

**核心数据结构**：

1. **红黑树（RB-Tree）**
   - 存储所有被监听的 fd
   - 插入/删除/查找都是 O(log n)
   - fd 作为 key，event 作为 value

2. **就绪列表（Ready List）**
   - 双向链表，存储已就绪的 fd
   - epoll_wait 直接返回这个列表
   - 无需遍历所有 fd

**工作流程**：
```
1. epoll_create：创建 epoll 实例（红黑树 + 就绪列表）
2. epoll_ctl ADD：fd 加入红黑树，注册回调函数
3. fd 就绪：内核调用回调函数，将 fd 加入就绪列表
4. epoll_wait：返回就绪列表中的 fd
```

**为什么快**：
- select：每次遍历所有 fd（O(n)）
- epoll：直接返回就绪 fd（O(1)）

---

#### 1.4 epoll 三大 API

**API 1：epoll_create1()**
```cpp
int epfd = epoll_create1(0);
// 参数：0 或 EPOLL_CLOEXEC
// 返回：epoll 文件描述符
```

**API 2：epoll_ctl()**
```cpp
int epoll_ctl(int epfd, int op, int fd, struct epoll_event *event);
// epfd：epoll 实例
// op：操作类型（EPOLL_CTL_ADD/MOD/DEL）
// fd：要监听的文件描述符
// event：事件类型（EPOLLIN/EPOLLOUT/EPOLLERR等）
```

**API 3：epoll_wait()**
```cpp
int n = epoll_wait(int epfd, struct epoll_event *events, 
                   int maxevents, int timeout);
// epfd：epoll 实例
// events：输出参数，返回就绪的事件数组
// maxevents：events 数组大小
// timeout：超时时间（毫秒，-1表示阻塞）
// 返回：就绪的 fd 数量
```

### 任务2：epoll 回显服务器实战（预计60分钟）

**项目目标**：用 epoll 改写阶段12的 TCP 回显服务器

**文件**：`high_performance/01_epoll_basics.cpp`

**实现步骤**：

1. **创建 epoll 实例**
   ```cpp
   int epfd = epoll_create1(0);
   ```

2. **创建监听 socket 并加入 epoll**
   ```cpp
   int listen_fd = socket(...);
   bind(...);
   listen(...);
   
   struct epoll_event ev;
   ev.events = EPOLLIN;  // 监听可读事件
   ev.data.fd = listen_fd;
   epoll_ctl(epfd, EPOLL_CTL_ADD, listen_fd, &ev);
   ```

3. **事件循环**
   ```cpp
   while (true) {
       int n = epoll_wait(epfd, events, MAX_EVENTS, -1);
       
       for (int i = 0; i < n; i++) {
           if (events[i].data.fd == listen_fd) {
               // 新连接
               int client_fd = accept(listen_fd, ...);
               epoll_ctl(epfd, EPOLL_CTL_ADD, client_fd, &ev);
           } else {
               // 已连接的客户端有数据
               int fd = events[i].data.fd;
               char buf[1024];
               int len = recv(fd, buf, sizeof(buf), 0);
               if (len > 0) {
                   send(fd, buf, len, 0);  // 回显
               } else {
                   // 关闭连接
                   epoll_ctl(epfd, EPOLL_CTL_DEL, fd, NULL);
                   close(fd);
               }
           }
       }
   }
   ```

**关键点**：
- listen_fd 和 client_fd 都要加入 epoll
- 区分"新连接"和"数据到达"两种事件
- 连接关闭时记得从 epoll 删除
