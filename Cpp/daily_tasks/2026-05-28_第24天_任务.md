## 📝 具体任务

### 任务1：阶段4知识点总结（预计30分钟）
**文件**：`cpp_basics/75_stage4_review.cpp`

**复习内容**：
1. **STL 容器**
   - 容器分类：序列容器（vector/list）、关联容器（map/set）
   - 容器选型决策树
   - 常用操作：增删查改、遍历

2. **迭代器与算法**
   - 迭代器类型：begin/end、const迭代器、反向迭代器
   - 常用算法：sort、find、find_if、count、reverse、for_each、transform
   - 容器+算法组合模式

3. **Lambda 表达式与函数对象**
   - Lambda 语法：`[捕获列表](参数) { 函数体 }`
   - 捕获方式：值捕获、引用捕获、隐式捕获
   - 函数对象（仿函数）
   - STL 适配器（bind）

4. **模板编程**
   - 函数模板：`template<typename T>`
   - 类模板：通用容器、通用算法
   - 模板参数推导
   - 模板实例化机制

5. **智能指针与 RAII**
   - unique_ptr：独占所有权
   - shared_ptr：共享所有权、引用计数
   - weak_ptr：打破循环引用
   - RAII 原则：资源获取即初始化

6. **移动语义与现代 C++**
   - 左值与右值
   - 右值引用（&&）
   - 移动构造函数、移动赋值运算符
   - std::move
   - 五法则（Rule of Five）
   - auto、范围for、nullptr、constexpr

**重点**：
- 理解各个知识点之间的联系
- 掌握现代 C++ 的编程思维
- 知道何时使用哪种技术

### 任务2：阶段4综合项目练习（预计40分钟）
**文件**：`cpp_basics/76_stage4_project.cpp`

**项目主题**：实现一个通用的资源管理器（ResourceManager）

**功能需求**：
1. **资源注册**：支持任意类型的资源（使用模板）
2. **资源查询**：根据ID查找资源
3. **自动释放**：使用智能指针自动管理内存
4. **统计信息**：资源数量、类型统计
5. **性能优化**：使用移动语义避免拷贝

**技术要点**：
- 使用类模板实现通用资源管理
- 使用 shared_ptr 管理资源生命周期
- 使用 map 存储资源（ID → 资源指针）
- 使用 Lambda 表达式实现资源过滤
- 使用移动语义优化性能
- 使用 auto 和范围for简化代码

**示例场景**：
- 游戏资源管理（纹理、音频、模型）
- 数据库连接池
- 文件句柄管理
