### 任务3：实现自动备份功能（预计30分钟）

**文件**：`student_management/StudentManager.h` 和 `StudentManager.cpp`

**任务内容**：
1. 在 `StudentManager.h` 中添加方法声明：
   ```cpp
   bool autoBackup();
   ```

2. 在 `StudentManager.cpp` 中实现 `autoBackup()` 方法：
   - 生成带时间戳的备份文件名
   - 调用 `saveToFile()` 保存数据
   - 可选：限制备份文件数量（保留最近5个）
   - 返回 true 表示成功，false 表示失败

**生成时间戳文件名示例**：
```cpp
#include <ctime>
#include <iomanip>
#include <sstream>

string generateBackupFilename() {
    time_t now = time(nullptr);
    tm* ltm = localtime(&now);
    
    stringstream ss;
    ss << "backup_"
       << (1900 + ltm->tm_year)
       << setfill('0') << setw(2) << (1 + ltm->tm_mon)
       << setfill('0') << setw(2) << ltm->tm_mday
       << "_"
       << setfill('0') << setw(2) << ltm->tm_hour
       << setfill('0') << setw(2) << ltm->tm_min
       << setfill('0') << setw(2) << ltm->tm_sec
       << ".txt";
    
    return ss.str();
}
```

**关键知识点**：
- 获取当前时间：`time()` 和 `localtime()`
- 格式化时间字符串
- 文件名生成

### 文件流操作参考

**写文件**：
```cpp
#include <fstream>
using namespace std;

ofstream file("data.txt");
if (!file.is_open()) {
    cout << "文件打开失败！" << endl;
    return false;
}

file << "数据1" << endl;
file << "数据2" << endl;

file.close();
```

**读文件**：
```cpp
#include <fstream>
using namespace std;

ifstream file("data.txt");
if (!file.is_open()) {
    cout << "文件打开失败！" << endl;
    return false;
}

string line;
while (getline(file, line)) {
    cout << line << endl;
}

file.close();
```
