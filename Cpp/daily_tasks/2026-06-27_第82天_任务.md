### 任务1：协程调度器概念（预计60分钟）

**目标**：理解为什么需要调度器，调度器的核心作用

**内容**：

**1. 为什么需要调度器？**

**问题场景**：
```cpp
// 没有调度器：手动管理协程
Task<void> task1 = asyncRead1();
Task<void> task2 = asyncRead2();
Task<void> task3 = asyncRead3();

// 需要手动调度
while (!task1.done() || !task2.done() || !task3.done()) {
    if (!task1.done()) task1.resume();
    if (!task2.done()) task2.resume();
    if (!task3.done()) task3.resume();
}
// 问题：复杂、容易出错、不灵活
```

**调度器解决**：
```cpp
// 有调度器：自动管理
Scheduler scheduler;
scheduler.schedule(asyncRead1());
scheduler.schedule(asyncRead2());
scheduler.schedule(asyncRead3());
scheduler.run();  // 自动调度所有协程
```

**调度器的价值**：
- ✅ 自动管理协程生命周期
- ✅ 统一调度策略
- ✅ 简化协程使用
- ✅ 提高代码可维护性

**4. 调度器与协程的交互**

```
用户代码
  ↓ scheduler.schedule(coro)
Scheduler（添加到任务队列）
  ↓ scheduler.run()
Event Loop（事件循环开始）
  ↓ 从队列取出协程
Coroutine（开始执行）
  ↓ co_await（暂停）
Scheduler（协程暂停，切换到下一个）
  ↓ 事件就绪
Scheduler（恢复协程）
  ↓ handle.resume()
Coroutine（继续执行）
  ↓ co_return（完成）
Scheduler（从运行集合移除）
```

```cpp
};
```

---

**2. FIFO队列实现（最简单）**

```cpp
#include <queue>
#include <coroutine>

class FIFOQueue {
private:
    std::queue<std::coroutine_handle<>> tasks;
    
public:
    // 入队
    void enqueue(std::coroutine_handle<> handle) {
        tasks.push(handle);
    }
    
    // 出队
    std::coroutine_handle<> dequeue() {
        if (tasks.empty()) {
            return nullptr;
        }
        auto handle = tasks.front();
        tasks.pop();
        return handle;
    }
    
    // 是否为空
    bool empty() const {
        return tasks.empty();
    }
    
    // 队列大小
    size_t size() const {
        return tasks.size();
    }
};
```

**特点**：
- ✅ 简单
- ✅ 公平（先进先出）
- ❌ 没有优先级

---

**3. 线程安全的队列**

```cpp
#include <queue>
#include <mutex>
#include <coroutine>

class ThreadSafeQueue {
private:
    std::queue<std::coroutine_handle<>> tasks;
    mutable std::mutex mtx;
    
public:
    // 入队（线程安全）
    void enqueue(std::coroutine_handle<> handle) {
        std::lock_guard<std::mutex> lock(mtx);
        tasks.push(handle);
    }
    
    // 出队（线程安全）
    std::coroutine_handle<> dequeue() {
        std::lock_guard<std::mutex> lock(mtx);
        if (tasks.empty()) {
            return nullptr;
        }
        auto handle = tasks.front();
        tasks.pop();
        return handle;
    }
    
    // 是否为空（线程安全）
    bool empty() const {
        std::lock_guard<std::mutex> lock(mtx);
        return tasks.empty();
    }
};
```

**特点**：
- ✅ 线程安全
- ✅ 支持多线程调度
- ❌ 有锁开销

---

**4. 队列选择指南**

| 场景 | 推荐队列 | 理由 |
|------|---------|------|
| 单线程调度 | FIFO队列 | 简单高效 |
| 多线程调度 | 线程安全队列 | 避免竞态 |
| 需要优先级 | 优先级队列 | 支持调度策略 |
| 高性能要求 | 无锁队列 | 减少锁开销 |

### 任务3：简单调度器实现（预计30分钟）

**目标**：实现一个最简单的协程调度器

**内容**：

**1. Scheduler类设计**

```cpp
class Scheduler {
private:
    FIFOQueue task_queue;  // 任务队列
    bool running;          // 是否运行中
    
public:
    // 调度协程
    void schedule(std::coroutine_handle<> handle);
    
    // 运行调度器
    void run();
    
    // 停止调度器
    void stop();
};
```

---

**2. 完整实现**

```cpp
#include <queue>
#include <coroutine>
#include <iostream>

class Scheduler {
private:
    std::queue<std::coroutine_handle<>> task_queue;
    bool running = false;
    
public:
    // 调度协程（添加到队列）
    void schedule(std::coroutine_handle<> handle) {
        if (handle) {
            task_queue.push(handle);
        }
    }
    
    // 运行调度器（事件循环）
    void run() {
        running = true;
        
        while (running && !task_queue.empty()) {
            // 从队列取出协程
            auto handle = task_queue.front();
            task_queue.pop();
            
            // 检查协程是否完成
            if (handle.done()) {
                handle.destroy();  // 销毁已完成的协程
                continue;
            }
            
            // 恢复协程
            handle.resume();
            
            // 如果协程未完成，重新加入队列
            if (!handle.done()) {
                task_queue.push(handle);
            } else {
                handle.destroy();  // 销毁已完成的协程
            }
        }
        
        running = false;
    }
    
    // 停止调度器
    void stop() {
        running = false;
    }
    
    // 获取队列大小
    size_t size() const {
        return task_queue.size();
    }
};
```

**3. 使用示例**

```cpp
// 简单的Task类型
template<typename T>
struct Task {
    struct promise_type {
        T value;
        
        Task get_return_object() {
            return Task{std::coroutine_handle<promise_type>::from_promise(*this)};
        }
        
        std::suspend_always initial_suspend() { return {}; }
        std::suspend_always final_suspend() noexcept { return {}; }
        
        void return_value(T v) { value = v; }
        void unhandled_exception() {}
    };
    
    std::coroutine_handle<promise_type> handle;
    
    Task(std::coroutine_handle<promise_type> h) : handle(h) {}
    ~Task() { if (handle) handle.destroy(); }
    
    operator std::coroutine_handle<>() const { return handle; }
};

// 协程函数
Task<int> calculate(int n) {
    std::cout << "Calculate " << n << std::endl;
    co_await std::suspend_always{};
    std::cout << "Result: " << n * 2 << std::endl;
    co_return n * 2;
}

// 使用调度器
int main() {
    Scheduler scheduler;
    
    // 调度多个协程
    scheduler.schedule(calculate(1));
    scheduler.schedule(calculate(2));
    scheduler.schedule(calculate(3));
    
    // 运行调度器
    scheduler.run();
    
    return 0;
}
```

**输出**：
```
Calculate 1
Calculate 2
Calculate 3
Result: 2
Result: 4
Result: 6
```
