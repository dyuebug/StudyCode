## 🔗 技术要点

### 使用 STL 算法查找学生

```cpp
// 使用 find_if + Lambda 查找学生
auto it = find_if(students.begin(), students.end(),
    [&id](const Student& s) {
        return s.getId() == id;
    });

if (it != students.end()) {
    // 找到了
} else {
    // 没找到
}
```

### 使用范围 for 遍历学生

```cpp
// 遍历所有学生
for (const auto& student : students) {
    student.display();
}
```

### 使用 vector 的 erase 删除学生

```cpp
// 删除学生
students.erase(it);  // it 是迭代器
```
