# cpp_basics 设计说明

## 设计目标

以循序渐进的单文件材料帮助学习者理解 C++ 语法、对象模型、资源管理和现代语言特性。

## 组织决策

- 保留历史编号，避免破坏 daily_tasks 和 daily_logs 中的路径引用。
- 以文件头标注语言标准和平台，不把整个目录强制绑定到同一个标准。
- 学习示例与工程项目分离；需要多文件、测试或外部依赖的内容应迁移到独立项目目录。

## 已知限制

- CMake 当前只覆盖代表性示例，且 MSVC Debug 已完成构建验证。
- 目录级自动化测试仍未建立。
- `.bak` 文件已隔离到归档目录，正式扫描不应包含归档内容。
- C++20 Modules 示例需要专用模块工程和编译器版本验证。
- 个别早期示例存在教学式重复代码，不应直接作为生产代码模板。

## 验证计划

1. 建立按 C++ 标准分组的构建目标。
2. 清理或归档备份文件。
3. 为资源管理、文件解析和现代 C++ 示例增加最小测试。
4. 在 README 中维护可构建文件清单。
