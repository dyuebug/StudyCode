# cpp_basics

## 定位

C++ 基础、面向对象、STL 和现代 C++ 学习示例集合。这里的文件以单文件教学示例为主，不代表所有文件都已通过统一构建或工程级测试。

## 内容范围

- `01`-`35`：语法、控制结构、函数、数组、字符串和文件基础
- `36`-`56`：类、构造/析构、拷贝控制、继承、多态、运算符重载和友元
- `57`-`68`：STL 容器、迭代器、算法、Lambda 和模板
- `69`-`84`：智能指针、RAII、移动语义、完美转发、可变参数模板和 SFINAE
- `85`-`99`：Concepts、Ranges、Coroutines、Modules 等 C++20 主题
- `100`：跨主题示例，需单独确认平台和构建要求

编号是历史学习顺序，不等同于目录依赖关系。`archive/` 中的 `.bak` 文件仅用于历史参考，不属于正式示例。

## 状态与限制

| 项目 | 内容 |
|---|---|
| 状态 | 学习完成，工程化中 |
| 平台 | Windows 可运行基础示例；个别主题依赖 Linux 或 C++20 工具链 |
| 标准 | C++11、C++17、C++20，按文件头说明为准 |
| 构建 | 提供 CMake 示例分组；其余文件仍可单文件编译 |
| 测试 | 暂无目录级自动化测试；按文件单独验证 |
| 限制 | Modules、协程和系统主题文件可能是概念演示或伪代码，不能默认视为可编译工程 |

## 使用建议

1. 先按编号阅读，再查看文件头的语言标准和平台说明。
2. 编译时启用警告，例如 `g++ -std=c++17 -Wall -Wextra file.cpp -o app`。
3. 运行会生成数据文件的示例时，使用独立临时目录，避免污染源码目录。
4. 需要 C++20 Modules、Linux API 或嵌入式 API 的文件，先阅读对应的限制说明。
