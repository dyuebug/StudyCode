# knowledge_base 设计说明

## 设计目标

建立可追溯的 C++ 学习知识索引，减少日志、阶段总结、README 和源码之间的信息漂移。

## 组织决策

- 速查表服务于快速复习，项目 README 服务于工程事实，二者不互相替代。
- 历史总结保留原始内容，但必须通过文件名或标题标明截止日期。
- 总索引负责指向来源模块，不复制大量实现细节。

## 已知限制

- 当前没有自动检查来源文件是否存在。
- 性能数字和项目统计可能来自历史文档，需逐步重新核验。
- 中文和英文文件名并存，暂时保留以避免历史引用断裂。

## 验证计划

1. 建立总索引和来源映射。
2. 为每份速查表增加更新时间和验证状态。
3. 定期根据模块 README 和测试结果更新知识库。

## 变更历史

### 2026-09-19 - 建立知识库治理说明

- 变更内容：新增知识库 README、设计说明和总索引规划。
- 变更理由：区分历史总结、速查表和实际工程事实。
- 影响范围：知识库目录和后续资料整理流程。
- 验证方式：人工盘点现有知识文档。
- 未解决问题：尚未建立自动同步检查。
