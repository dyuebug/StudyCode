# knowledge_base

## 定位

集中保存 C++ 学习过程中的速查表、阶段总结、技能清单和架构笔记。该目录是知识索引，不是代码实现的唯一事实来源。

## 维护规则

- 每份知识文档注明来源文件、适用平台和更新时间。
- 理论性能数字必须标记假设或实测状态。
- 历史总结必须标明截止日期，不能覆盖当前阶段状态。
- 与源码不一致时，以实际代码、测试结果和最新项目 README 为准。
