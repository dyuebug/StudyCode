# qt_basics 设计说明

## 设计目标

通过小型可运行示例逐步学习 Qt Widgets、SQL、网络和线程模型，并把知识迁移到综合桌面项目。

## 组织决策

- 按学习主题和阶段编号组织文件，保留历史路径引用。
- 将 Qt 示例材料与 `TaskManager` 工程分开，避免教学示例和产品代码混合。
- 每个示例应声明 Qt 模块、C++ 标准、构建方式和运行限制。

## 已知限制

- 缺少统一 Qt 版本、编译器和构建系统矩阵。
- 示例没有目录级测试目标，SQL 和网络示例缺少自动化验证。
- 网络示例依赖外部 API，测试需要替身服务或固定响应。
- `qt_capstone_project_plan.md` 已替代原编号式名称，历史任务和日志引用已同步。

## 验证计划

1. 补充 Qt 版本和模块矩阵。
2. 为核心示例建立最小 qmake/CMake 构建入口。
3. 为 SQL 数据访问增加临时数据库测试。
4. 为网络示例增加离线 JSON 解析测试。
