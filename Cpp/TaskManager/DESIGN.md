# TaskManager 设计说明

## 设计目标

使用 Qt Widgets 和 SQLite 实现个人任务管理器，综合练习 UI、数据库、筛选、样式和对象生命周期。

## 架构

- UI：`MainWindow`、`TaskDialog`
- 数据模型：`Task`、`Category`
- 数据访问：`DatabaseManager`
- 样式和资源：`styles.qss`、`resources.qrc`
- 构建：当前使用 qmake 的 `TaskManager.pro`

## 关键决策

- 使用 SQLite 保存任务和分类。
- 使用参数化查询降低 SQL 注入风险。
- 使用 Qt 对象树和信号槽组织窗口及对话框生命周期。
- 当前保留单例数据库管理器，后续可根据测试隔离需求重新评估。

## 已知限制

- 当前 qmake 工程声明 C++11，Qt 主版本和编译器版本尚未形成验证矩阵。
- 缺少单元测试和数据库临时路径隔离。
- `tasks.db` 的运行路径、迁移策略和 `.gitignore` 策略需要明确。
- 搜索、导入导出、提醒和分类管理仍未完成。

## 验证计划

1. 补充 Qt 版本、编译器和平台记录。
2. 为数据库操作增加测试目标。
3. 将测试数据库放入临时目录，并避免污染源码目录。
4. 再实现搜索、导入导出和提醒功能。
