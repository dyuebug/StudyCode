## 🗄️ 数据库设计

### categories 表（分类表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键，自增 |
| name | TEXT | 分类名称（唯一） |
| color | TEXT | 分类颜色（十六进制） |

**预设分类**：
- 工作（红色 #e74c3c）
- 学习（蓝色 #3498db）
- 生活（绿色 #2ecc71）
- 其他（灰色 #95a5a6）

### tasks 表（任务表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键，自增 |
| title | TEXT | 任务标题 |
| description | TEXT | 任务描述 |
| category_id | INTEGER | 分类ID（外键） |
| priority | INTEGER | 优先级（1-高，2-中，3-低） |
| due_date | TEXT | 截止日期（YYYY-MM-DD） |
| completed | INTEGER | 是否完成（0-未完成，1-已完成） |
| created_at | TEXT | 创建时间 |
| updated_at | TEXT | 更新时间 |

## 🛠️ 编译和运行

### 环境要求
- Qt 5.12 或更高版本
- C++11 或更高版本
- SQLite（Qt 自带）

### 编译步骤

**方式1：使用 Qt Creator**
1. 打开 Qt Creator
2. 打开项目文件 `TaskManager.pro`
3. 点击"构建"按钮
4. 点击"运行"按钮

**方式2：使用命令行**
```bash
# 生成 Makefile
qmake TaskManager.pro

# 编译
make

# 运行（Windows）
TaskManager.exe

# 运行（Linux/macOS）
./TaskManager
```

## 📝 使用说明

### 添加任务
1. 点击"添加任务"按钮或使用菜单"任务 → 添加任务"
2. 填写任务信息：
   - 标题（必填）
   - 描述（可选）
   - 分类（从下拉框选择）
   - 优先级（高/中/低）
   - 截止日期（可选，可以清除）
3. 点击"确定"保存任务

### 编辑任务
1. 在任务列表中选择一个任务
2. 点击"编辑任务"按钮或使用菜单"任务 → 编辑任务"
3. 修改任务信息
4. 点击"确定"保存修改

### 查看任务列表
- 启动程序后，自动显示所有任务
- 使用筛选条件可以按分类、优先级、状态筛选
- 点击表头可以排序

### 删除任务
1. 在任务列表中选择一个任务
2. 点击"删除任务"按钮
3. 确认删除

### 标记任务完成/未完成
1. 在任务列表中选择一个任务
2. 点击"标记完成"或"标记未完成"按钮

### 刷新任务列表
- 点击"刷新"按钮

### 查看统计信息
- 状态栏显示任务统计信息
