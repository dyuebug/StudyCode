# 学生管理系统 - 编译和运行指南

## 📁 项目结构

```
student_management/
├── Student.h              # 学生类头文件
├── Student.cpp            # 学生类实现
├── StudentManager.h       # 管理器类头文件
├── StudentManager.cpp     # 管理器类实现
├── Course.h               # 课程类头文件（新增）
├── Course.cpp             # 课程类实现（新增）

└── README.md              # 本文件
```

## 🔨 编译方法

### Windows (MinGW)

```bash
cd student_management
g++ -std=c++17 -o student_system Student.cpp StudentManager.cpp Course.cpp main.cpp
student_system.exe
```

### Linux / macOS

```bash
cd student_management
g++ -std=c++17 -o student_system Student.cpp StudentManager.cpp Course.cpp main.cpp
./student_system
```

## 🎯 功能说明

### 1. 添加学生
- 输入学号、姓名、年龄、专业
- 自动检查学号是否重复
- 添加成功后显示提示信息

### 2. 删除学生
- 输入学号
- 删除指定学生
- 显示删除结果

### 3. 修改学生信息
- 输入学号查找学生
- 选择要修改的属性（姓名/年龄/专业）
- 输入新值完成修改

### 4. 查询学生
- 按学号查询：精确查找
- 按姓名查询：可能返回多个结果

### 5. 显示所有学生
- 以表格形式显示所有学生信息
- 显示学生总数

### 6. 添加成绩（新增）
- 输入学号查找学生
- 输入课程代码、课程名称、学分、成绩
- 自动检查课程代码是否重复
- 添加成功后显示提示信息

### 7. 查询成绩（新增）
- 输入学号查找学生
- 显示学生的所有课程和成绩
- 显示平均分、总学分

### 8. 统计信息（新增）
- 班级平均分：计算所有学生的平均分
- 成绩排名：显示前10名学生
- 优秀学生：显示平均分>=90的学生

### 9. 高级查询（新增）
- 按年龄范围查询
- 按专业查询
- 按平均分范围查询
- 使用 Lambda 表达式实现灵活过滤

### 10. 保存数据（新增）
- 手动保存所有学生数据到文件
- 文件名：students.txt
- 包含学生基本信息和课程成绩

### 11. 加载数据（新增）
- 从文件加载学生数据
- 覆盖当前数据（有确认提示）
- 自动验证数据完整性

### 12. 批量导入（CSV）（新增）
- 从CSV文件批量导入学生
- CSV格式：学号,姓名,年龄,专业
- 自动验证数据
- 统计导入结果（成功/失败）

### 13. 帮助（新增）
- 显示完整的使用帮助
- 基本操作说明
- 成绩管理说明
- 数据管理说明
- 常见问题解答

### 程序启动自动加载
- 程序启动时自动从 students.txt 加载数据
- 如果文件不存在，从空白开始

### 退出时保存提示
- 退出程序前提示是否保存数据
- 避免数据丢失

## 🔧 技术特点

### 使用的 C++ 特性

1. **面向对象编程**
   - 类的封装：Student、StudentManager、Course
   - 访问控制：private/public
   - 构造函数、成员函数

2. **STL 容器**
   - `vector<Student>`：存储学生列表
   - `vector<Course>`：存储课程列表（嵌套使用）
   - `pair<string, double>`：存储排名信息
   - 动态数组，自动管理内存

3. **STL 算法**
   - `find_if`：查找学生和课程
   - `sort`：成绩排序
   - 配合 Lambda 表达式使用

4. **Lambda 表达式**
   ```cpp
   // 查找学生
   [&id](const Student& s) {
       return s.getId() == id;
   }
   
   // 过滤学生
   [minAge, maxAge](const Student& s) {
       return s.getAge() >= minAge && s.getAge() <= maxAge;
   }
   ```

5. **function 对象**
   ```cpp
   function<bool(const Student&)> predicate
   ```
   - 作为参数传递
   - 实现灵活的过滤功能

6. **文件流操作（新增）**
   - `ofstream`：写文件
   - `ifstream`：读文件
   - `getline()`：读取一行
   - 文件打开检查：`is_open()`

7. **字符串处理（新增）**
   - `stringstream`：字符串流
   - `getline(ss, str, '|')`：按分隔符分割
   - `stoi()`：字符串转整数
   - `stod()`：字符串转浮点数

8. **时间处理（新增）**
   - `time()`：获取当前时间
   - `localtime()`：转换为本地时间
   - `setfill()`、`setw()`：格式化时间字符串

9. **现代 C++ 语法**
   - `auto`：自动类型推导
   - 范围 for：`for (const auto& student : students)`
   - 成员初始化列表
   - `pair` 容器

10. **输入输出**
    - `cin`/`cout`：标准输入输出
    - `setw`：格式化输出
    - `getline`：读取包含空格的字符串
    - `fixed`/`setprecision`：控制浮点数精度

## 📝 代码设计原则

### 1. 单一职责原则
- Student 类：只负责学生信息和课程的存储和访问
- Course 类：只负责课程信息的存储和访问
- StudentManager 类：只负责学生的管理和统计
- main.cpp：只负责用户交互

### 2. 封装原则
- 成员变量私有化
- 通过公有方法访问
- 隐藏实现细节

### 3. 错误处理
- 学号重复检查
- 课程代码重复检查
- 学生不存在检查
- 输入错误处理
- 文件操作错误处理（新增）
- 数据格式验证（新增）
- 友好的错误提示

### 4. 代码复用
- 私有辅助方法 `findById`
- 避免重复代码
- Lambda 表达式简化逻辑

### 5. 数据持久化设计（新增）
- 自定义文件格式（易读、易解析）
- 使用分隔符（`|`）避免冲突
- 分段标记（`[STUDENT]`、`[COURSES]`、`[END]`）
- 数据完整性验证
- 异常处理和错误恢复
