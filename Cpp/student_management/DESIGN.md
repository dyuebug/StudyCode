# student_management 设计说明

## 设计目标

用一个多文件控制台项目综合练习面向对象、STL、文件持久化、数据校验、CSV 导入和单元测试。

## 组织决策

- `Student` 和 `Course` 负责数据模型。
- `StudentManager` 负责增删改查、统计、持久化和导入。
- `main.cpp` 负责交互，不承载核心业务规则。
- 保留当前自定义文本格式，便于学习文件解析；后续可再评估 JSON/SQLite。

## 已知限制

- 当前缺少统一 CMake/CTest 构建。
- 测试使用相对路径，工作目录不同可能产生文件位置差异。
- 自动备份、启动加载和退出保存等流程需要补充行为测试。
- 头文件仍有全局 `using namespace std`，后续应改为显式命名空间。

## 验证计划

1. 增加 CMake 和 CTest。
2. 使用临时测试目录隔离保存/加载文件。
3. 补充 CSV 异常输入、备份和边界数据测试。
4. 统一 README 的文件和行数统计口径。
