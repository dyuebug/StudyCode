## 📖 学到的知识点

1. **QSqlDatabase::addDatabase("QSQLITE")**：添加 SQLite 数据库驱动
2. **setDatabaseName()**：设置数据库文件路径（":memory:" 为内存库）
3. **db.open()**：打开数据库连接，失败时检查 lastError()
4. **QSqlQuery::exec()**：执行 SQL 语句，返回 bool
5. **CREATE TABLE IF NOT EXISTS**：表不存在时创建，已存在则跳过
6. **参数化查询**：prepare() + bindValue() 防止 SQL 注入，必须使用
7. **query.next()**：移动到结果集下一行，返回 false 表示结束
8. **query.value(列名/索引)**：获取当前行指定列的值（返回 QVariant）
9. **query.lastInsertId()**：获取刚插入行的自增 ID
10. **query.numRowsAffected()**：获取 UPDATE/DELETE 影响的行数
11. **QSqlTableModel**：将数据库表绑定为数据模型，与 QTableView 配合
12. **setEditStrategy(OnManualSubmit)**：手动提交策略，支持撤销
13. **submitAll() / revertAll()**：提交/撤销所有未保存更改
14. **QSortFilterProxyModel**：包装模型，提供搜索过滤功能
15. **setFilterKeyColumn(-1)**：搜索所有列（-1 表示全列）
16. **mapToSource()**：代理模型索引映射回源模型索引（删除/编辑时必须）
17. **setColumnHidden()**：隐藏指定列（如隐藏 ID 列）
18. **数据持久化**：SQLite 文件在程序重启后数据仍然保留
