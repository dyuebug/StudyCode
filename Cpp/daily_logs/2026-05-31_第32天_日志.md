## 💡 今日学习要点

### 1. 可变参数模板的核心概念

**参数包的定义**：
```cpp
// 模板参数包
template<typename... Args>

// 函数参数包
void func(Args... args)

// 参数包大小
sizeof...(Args)  // 或 sizeof...(args)
```

**参数包展开的四种方式**：

**方式1：递归展开**
```cpp
// 递归终止条件
void print() {
    cout << endl;
}

// 递归展开
template<typename T, typename... Args>
void print(T first, Args... rest) {
    cout << first << " ";
    print(rest...);  // 递归调用
}
```

**方式2：折叠表达式（C++17）**
```cpp
// 左折叠：(... op pack)
template<typename... Args>
auto sum(Args... args) {
    return (... + args);  // ((arg1 + arg2) + arg3) + ...
}

// 右折叠：(pack op ...)
template<typename... Args>
auto sum_right(Args... args) {
    return (args + ...);  // arg1 + (arg2 + (arg3 + ...))
}
```

**方式3：初始化列表展开**
```cpp
template<typename... Args>
void print(Args... args) {
    int dummy[] = {(cout << args << " ", 0)...};
    (void)dummy;  // 避免未使用警告
}
```

**方式4：逗号运算符展开**
```cpp
template<typename... Args>
void print(Args... args) {
    ((cout << args << " "), ...);
}
```

### 2. SFINAE 的工作原理

**核心思想**：
- 模板参数替换失败时，编译器不报错
- 而是从候选函数集中移除该重载
- 继续尝试其他重载

**enable_if 的实现原理**：
```cpp
// enable_if 的定义（简化版）
template<bool B, typename T = void>
struct enable_if {};

template<typename T>
struct enable_if<true, T> {
    using type = T;
};

// 当 B = true 时，enable_if<true, T>::type 存在
// 当 B = false 时，enable_if<false, T>::type 不存在（SFINAE）
```

**三种使用方式**：

**方式1：返回类型**
```cpp
template<typename T>
typename enable_if<is_integral<T>::value, T>::type
func(T value) {
    return value * 2;
}
```

**方式2：模板参数**
```cpp
template<typename T, typename = enable_if_t<is_integral<T>::value>>
void func(T value) {
    cout << value << endl;
}
```

**方式3：函数参数**
```cpp
template<typename T>
void func(T value, enable_if_t<is_integral<T>::value>* = nullptr) {
    cout << value << endl;
}
```

### 3. 自定义类型萃取

**检测成员函数是否存在**：
```cpp
template<typename T>
class has_size {
    // 如果 T 有 size() 方法，这个重载会被选中
    template<typename U>
    static auto test(int) -> decltype(declval<U>().size(), true_type{});
    
    // 否则，这个重载会被选中（...匹配任何参数）
    template<typename>
    static false_type test(...);
    
public:
    // 根据 test<T>(0) 的返回类型判断
    static constexpr bool value = decltype(test<T>(0))::value;
};
```

**工作原理**：
1. `test<T>(0)` 优先匹配 `test(int)` 重载
2. 如果 `declval<U>().size()` 有效，返回 `true_type`
3. 如果替换失败（SFINAE），选择 `test(...)` 重载，返回 `false_type`
4. `decltype(test<T>(0))::value` 提取结果

### 4. 解决模板函数循环依赖

**问题场景**：
```cpp
// print(pair) 需要调用 print(container)
template<typename T1, typename T2>
void print(const pair<T1, T2>& p) {
    print(p.first);
    print(p.second);  // 如果 T2 是容器，需要 print(container)
}

// print(container) 需要调用 print(pair)
template<typename T>
void print(const T& container) {
    for (const auto& item : container) {
        print(item);  // 如果 item 是 pair，需要 print(pair)
    }
}
```

**解决方案：前向声明 + SFINAE**
```cpp
// 1. 前向声明容器打印函数
template<typename T>
enable_if_t<has_iterator<T>::value && !is_same<T, string>::value>
print(const T& container);

// 2. 定义 pair 打印函数（可以调用前向声明的函数）
template<typename T1, typename T2>
void print(const pair<T1, T2>& p) {
    print(p.first);
    print(p.second);  // OK：已有前向声明
}

// 3. 定义容器打印函数（实现前向声明）
template<typename T>
enable_if_t<has_iterator<T>::value && !is_same<T, string>::value>
print(const T& container) {
    for (const auto& item : container) {
        print(item);  // OK：pair 打印函数已定义
    }
}
```

### 6. 完美转发 + 可变参数模板

**工厂函数模式**：
```cpp
template<typename T, typename... Args>
unique_ptr<T> make_unique_custom(Args&&... args) {
    return unique_ptr<T>(new T(std::forward<Args>(args)...));
}

// 使用
auto ptr = make_unique_custom<string>("Hello", 5, 'x');
// 等价于：new string("Hello", 5, 'x')
```

**包装器函数模式**：
```cpp
template<typename Func, typename... Args>
auto wrapper(Func&& func, Args&&... args) {
    return std::forward<Func>(func)(std::forward<Args>(args)...);
}
```

### 7. 可变参数模板类

**递归定义模式**：
```cpp
// 空 tuple（递归终止）
template<>
class SimpleTuple<> {
public:
    SimpleTuple() {}
};

// 递归定义
template<typename Head, typename... Tail>
class SimpleTuple<Head, Tail...> : private SimpleTuple<Tail...> {
private:
    Head head;
public:
    SimpleTuple(Head h, Tail... t) 
        : SimpleTuple<Tail...>(t...), head(h) {}
    
    Head getHead() const { return head; }
};
```

**使用示例**：
```cpp
SimpleTuple<int, double, string> t(42, 3.14, "hello");
// 继承链：SimpleTuple<int, double, string>
//        -> SimpleTuple<double, string>
//        -> SimpleTuple<string>
//        -> SimpleTuple<>
```

## 🎯 重要知识点

### 1. 可变参数模板最佳实践

**推荐做法**：
```cpp
// ✅ 使用折叠表达式（C++17）
template<typename... Args>
auto sum(Args... args) {
    return (... + args);
}

// ✅ 使用完美转发
template<typename... Args>
void wrapper(Args&&... args) {
    target(std::forward<Args>(args)...);
}

// ✅ 递归终止条件清晰
void print() { cout << endl; }  // 终止条件

template<typename T, typename... Args>
void print(T first, Args... rest) {
    cout << first << " ";
    print(rest...);
}
```

**避免做法**：
```cpp
// ❌ 没有递归终止条件
template<typename T, typename... Args>
void print(T first, Args... rest) {
    cout << first << " ";
    print(rest...);  // 编译错误：无限递归
}

// ❌ 不使用完美转发
template<typename... Args>
void wrapper(Args... args) {  // 拷贝参数
    target(args...);
}
```

### 2. SFINAE 最佳实践

**推荐做法**：
```cpp
// ✅ 使用 enable_if_t（C++14）
template<typename T>
enable_if_t<is_integral<T>::value>
func(T value) { ... }

// ✅ 使用 if constexpr（C++17）
template<typename T>
void func(T value) {
    if constexpr (is_integral<T>::value) {
        // 整数处理
    } else {
        // 其他类型处理
    }
}

// ✅ 自定义类型萃取
template<typename T>
class has_method {
    template<typename U>
    static auto test(int) -> decltype(declval<U>().method(), true_type{});
    
    template<typename>
    static false_type test(...);
    
public:
    static constexpr bool value = decltype(test<T>(0))::value;
};
```

**注意事项**：
```cpp
// ⚠️ enable_if 只在模板参数推导时有效
template<typename T>
enable_if_t<is_integral<T>::value>
func(T value);  // OK：模板参数推导

void func(enable_if_t<is_integral<int>::value>);  // 错误：不是模板
```

### 3. 何时使用可变参数模板

**适合使用的场景**：
- 工厂函数（make_unique、make_shared）
- 包装器函数（转发参数）
- 容器的 emplace 方法
- 日志系统（可变参数日志）
- 元组（tuple）实现

**不适合使用的场景**：
- 参数类型固定且数量少（直接重载更清晰）
- 需要运行时动态参数数量（使用容器）
- 参数需要修改（可变参数难以修改）

## ❓ 遇到的问题与解决

**问题1**：模板函数循环依赖导致编译错误

**现象**：
```cpp
// print(pair) 调用 print(vector)
template<typename T1, typename T2>
void print(const pair<T1, T2>& p) {
    print(p.second);  // 错误：找不到 print(vector)
}

// print(vector) 定义在后面
template<typename T>
void print(const T& container) { ... }
```

**错误信息**：
```
error: no matching function for call to 'print(const std::vector<int>&)'
```

**原因分析**：
- 模板函数在实例化时需要看到完整定义
- `print(pair<int, vector<int>>)` 实例化时，需要 `print(vector<int>)`
- 但 `print(vector)` 定义在后面，编译器看不到

**解决方案**：
```cpp
// 1. 前向声明容器打印函数
template<typename T>
enable_if_t<has_iterator<T>::value && !is_same<T, string>::value>
print(const T& container);

// 2. 定义 pair 打印函数
template<typename T1, typename T2>
void print(const pair<T1, T2>& p) {
    print(p.first);
    print(p.second);  // OK：有前向声明
}

// 3. 实现容器打印函数
template<typename T>
enable_if_t<has_iterator<T>::value && !is_same<T, string>::value>
print(const T& container) {
    for (const auto& item : container) {
        print(item);  // OK：pair 打印函数已定义
    }
}
```

**关键点**：
- 前向声明必须包含 SFINAE 约束
- 函数定义顺序：前向声明 → pair → 容器
- 这样两个函数都能看到对方

**问题2**：为什么折叠表达式比递归展开更好？

**解答**：

**递归展开的缺点**：
```cpp
// 需要递归终止条件
void print() { cout << endl; }

// 需要递归调用
template<typename T, typename... Args>
void print(T first, Args... rest) {
    cout << first << " ";
    print(rest...);  // 递归
}

// 编译器生成多个函数实例
// print(1, 2, 3) 生成：
// - print(int, int, int)
// - print(int, int)
// - print(int)
// - print()
```

**折叠表达式的优点**：
```cpp
// 只需一个函数
template<typename... Args>
void print(Args... args) {
    ((cout << args << " "), ...);
}

// 编译器直接展开为：
// cout << arg1 << " ", cout << arg2 << " ", cout << arg3 << " "

// 优点：
// 1. 代码更简洁
// 2. 编译更快（只生成一个函数实例）
// 3. 不需要递归终止条件
```

**性能对比**：
- 递归展开：编译时间长，生成多个函数实例
- 折叠表达式：编译时间短，只生成一个函数实例
- 运行时性能：两者相同（都是编译期展开）

**问题3**：什么时候使用 `if constexpr`，什么时候使用 `enable_if`？

**解答**：

**使用 `if constexpr`（C++17）**：
```cpp
// 场景：同一个函数内部的条件分支
template<typename T>
void func(T value) {
    if constexpr (is_integral<T>::value) {
        // 整数处理
        cout << "整数：" << value << endl;
    } else if constexpr (is_floating_point<T>::value) {
        // 浮点数处理
        cout << "浮点数：" << value << endl;
    } else {
        // 其他类型处理
        cout << "其他类型" << endl;
    }
}

// 优点：
// - 代码集中在一个函数内
// - 逻辑清晰
// - 不需要的分支不会编译
```

**使用 `enable_if`**：
```cpp
// 场景：需要不同的函数签名或返回类型
template<typename T>
enable_if_t<is_integral<T>::value, T>
func(T value) {
    return value * 2;  // 返回 T
}

template<typename T>
enable_if_t<is_floating_point<T>::value, int>
func(T value) {
    return static_cast<int>(value);  // 返回 int
}

// 优点：
// - 可以有不同的返回类型
// - 可以有不同的参数列表
// - 更灵活
```

**选择建议**：
- 同一函数内的条件分支 → `if constexpr`
- 需要不同函数签名 → `enable_if`
- C++17 及以上 → 优先 `if constexpr`
- C++14 及以下 → 只能用 `enable_if`
