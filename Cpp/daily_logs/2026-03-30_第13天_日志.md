## 📚 知识点总结

### 1. 拷贝构造函数（42_copy_constructor.cpp）

**语法**：
```cpp
ClassName(const ClassName& other);
```

**三种调用时机**：
1. 用已有对象初始化新对象：`MyString s2 = s1;`
2. 函数参数按值传递：`void foo(MyString s)`
3. 函数返回值（部分情况）

**关键规则**：
- 参数必须是引用，否则无限递归
- 含裸指针成员时必须自定义（深拷贝）
- 编译器默认生成浅拷贝（逐成员复制）

---

### 2. 深拷贝与浅拷贝（43_deep_shallow_copy.cpp）

| 对比项 | 浅拷贝 | 深拷贝 |
|--------|--------|--------|
| 指针处理 | 复制地址 | 分配新内存+复制内容 |
| 内存独立 | 否（共享） | 是 |
| 风险 | double free 崩溃 | 无 |
| 适用场景 | 值类型成员 | 含裸指针成员 |

**需要深拷贝的情况**：类中含有裸指针（指向堆内存）

**不需要深拷贝的情况**：只有值类型、`std::string`、`vector` 等（已内置深拷贝）

---

### 3. 赋值运算符重载（44_assignment_operator.cpp）

**语法**：
```cpp
MyString& operator=(const MyString& other) {
    if (this == &other) return *this;  // 步骤1：自赋值检查
    delete[] data;                      // 步骤2：释放旧资源
    length = other.length;              // 步骤3：深拷贝
    data = new char[length + 1];
    strcpy(data, other.data);
    return *this;                       // 步骤4：返回 *this
}
```

**四个关键步骤**：自赋值检查 → 释放旧资源 → 深拷贝 → `return *this`

**三法则（Rule of Three）**：
> 如果类需要自定义以下任意一个，通常三个都需要：
> 1. 析构函数
> 2. 拷贝构造函数
> 3. 赋值运算符
