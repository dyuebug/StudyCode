## 📖 学到的知识点

### 1. 多文件项目组织 ⭐⭐⭐⭐⭐

**核心概念**：
- 头文件（.h）：类的声明、接口定义
- 实现文件（.cpp）：类的具体实现
- 主程序（main.cpp）：程序入口和用户交互

**项目结构**：
```
student_management/
├── Student.h              # 学生类头文件
├── Student.cpp            # 学生类实现
├── StudentManager.h       # 管理器类头文件
├── StudentManager.cpp     # 管理器类实现
├── main.cpp               # 主程序
└── README.md              # 项目文档
```

**编译命令**：
```bash
g++ -std=c++17 -o student_system Student.cpp StudentManager.cpp main.cpp
```

**关键要点**：
- 头文件保护：`#ifndef STUDENT_H` / `#define STUDENT_H` / `#endif`
- 分离声明与实现：提高代码可维护性
- 模块化设计：每个类负责单一职责

### 3. STL 容器的实际应用 ⭐⭐⭐⭐⭐

**使用 vector 存储学生列表**：
```cpp
class StudentManager {
private:
    vector<Student> students;  // 动态数组，自动管理内存
};
```

**优势**：
- 动态大小：自动扩容，无需手动管理内存
- 随机访问：通过下标快速访问
- STL 算法支持：可以使用 find_if、sort 等算法

**关键操作**：
- `students.push_back(student)`：添加学生
- `students.erase(it)`：删除学生（it 是迭代器）
- `students.size()`：获取学生数量
- `students.empty()`：检查是否为空

---

### 4. STL 算法 + Lambda 表达式 ⭐⭐⭐⭐⭐

**使用 find_if 查找学生**：
```cpp
auto it = find_if(students.begin(), students.end(),
    [&id](const Student& s) {
        return s.getId() == id;
    });

if (it != students.end()) {
    // 找到了
    return &(*it);
} else {
    // 没找到
    return nullptr;
}
```

**Lambda 表达式详解**：
- `[&id]`：捕获外部变量 id（引用捕获）
- `(const Student& s)`：参数列表
- `{ return s.getId() == id; }`：函数体，返回 bool

**优势**：
- 代码简洁：不需要单独定义函数或函数对象
- 灵活：可以捕获外部变量
- 高效：编译器可以内联优化

---

### 5. 迭代器的使用 ⭐⭐⭐⭐

**迭代器类型**：
```cpp
vector<Student>::iterator it;              // 可修改的迭代器
vector<Student>::const_iterator it;        // 只读迭代器
```

**迭代器操作**：
- `students.begin()`：指向第一个元素
- `students.end()`：指向最后一个元素的下一个位置
- `*it`：解引用，获取元素
- `it->method()`：通过迭代器调用成员函数

**重载两个版本的 findById**：
```cpp
// 非 const 版本：返回可修改的迭代器
vector<Student>::iterator findById(const string& id);

// const 版本：返回只读迭代器
vector<Student>::const_iterator findById(const string& id) const;
```

### 8. 成员初始化列表 ⭐⭐⭐⭐

**构造函数使用初始化列表**：
```cpp
Student::Student(const string& id, const string& name, int age, const string& major)
    : id(id), name(name), age(age), major(major) {
    // 构造函数体（可以为空）
}
```

**优势**：
- 效率更高：直接初始化，避免先默认构造再赋值
- 必须使用：const 成员、引用成员、没有默认构造函数的成员
- 初始化顺序：按成员变量声明顺序，不是初始化列表顺序

---

### 9. const 成员函数 ⭐⭐⭐⭐

**const 成员函数**：
```cpp
string getId() const { return id; }
void display() const { /* ... */ }
```

**作用**：
- 承诺不修改对象的成员变量
- const 对象只能调用 const 成员函数
- 提高代码安全性和可读性

**const 正确性**：
```cpp
const Student* findStudentById(const string& id) const;
// 第一个 const：返回的指针指向 const 对象
// 第二个 const：该成员函数不修改对象
```

---

### 10. 私有辅助方法 ⭐⭐⭐

**设计模式**：
```cpp
class StudentManager {
private:
    // 私有辅助方法：只在类内部使用
    vector<Student>::iterator findById(const string& id);
    
public:
    // 公有接口：供外部调用
    Student* findStudentById(const string& id);
    bool removeStudent(const string& id);
};
```

**优势**：
- 避免代码重复：多个公有方法可以复用私有方法
- 隐藏实现细节：外部不需要知道如何查找
- 易于修改：修改查找逻辑只需改一处
