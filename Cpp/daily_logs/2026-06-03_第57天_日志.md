## 📖 学到的知识点

### 中断处理
1. **ISR 黄金法则**：只设标志位 + 读硬件寄存器，执行时间 < 1μs
2. **volatile**：禁止编译器优化，强制每次从内存读写；不保证原子性
3. **环形缓冲区**：解决 ISR 和主循环速度不匹配；tail 由 ISR 写，head 由主循环写
4. **atomic**：保证原子性 + 内存屏障；`fetch_add(1, memory_order_relaxed)` 用于计数器
5. **临界区保护**：关中断（DISABLE_IRQ）保护多字节变量的读写

### 硬件抽象层（HAL）
6. **三层结构**：应用层 → HAL 接口（纯虚基类）→ BSP 驱动实现
7. **IGpio 接口**：setDir / write / read / toggle 四个纯虚函数
8. **依赖注入**：构造函数传入 IGpio& 引用，测试时用 MockGpio，生产时换真实实现
9. **LedDriver**：只依赖 IGpio 抽象，与具体硬件解耦
10. **ButtonDriver**：软件防抖（debounce），时间源通过参数传入（可测试性）

### RTOS 基础
11. **裸机 vs RTOS**：裸机轮询简单但耦合；RTOS 多任务解耦但有额外开销
12. **Mutex + lock_guard**：RAII 自动解锁，保护共享资源
13. **二值信号量**：ISR `release()` 通知任务，任务 `acquire()` 阻塞等待（不占 CPU）
14. **消息队列（SafeQueue）**：生产者-消费者模式，线程安全 FIFO
15. **FreeRTOS API 对照**：`xSemaphoreGiveFromISR`、`xQueueSendFromISR`（ISR 专用）

### 状态机设计
16. **enum class 状态/事件**：有作用域，防命名冲突
17. **switch-case 状态机**：当前状态 + 事件 → 下一状态 + 动作
18. **onEnter / onExit**：进入/退出状态时的初始化和清理
19. **边沿动作**：同状态内的事件（SampleDone）只执行动作不转换状态

### 完整系统集成
20. **三任务流水线**：ADC ISR → 环形缓冲区 → 采样任务 → 消息队列 → 显示任务
21. **thread + ref()**：线程传引用参数必须用 `std::ref()`
