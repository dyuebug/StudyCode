## 📖 学到的知识点
1. **左值与右值**：左值有名字可取地址，右值是临时对象或字面量，理解这个区别是掌握移动语义的基础。
2. **右值引用（&&）**：绑定到右值的引用类型，延长临时对象生命周期，是实现移动语义的核心机制。
3. **移动语义**：转移资源所有权而不是拷贝资源，避免深拷贝的开销，大幅提升性能。
4. **移动构造函数**：接受右值引用参数，偷走源对象的资源指针，将源对象置为安全状态（nullptr），必须标记 noexcept。
5. **移动赋值运算符**：检查自赋值、释放旧资源、偷走源对象资源、置空源对象，必须标记 noexcept。
6. **std::move**：将左值转换为右值引用的类型转换函数，本身不移动任何东西，真正的移动发生在移动构造/赋值中。
7. **五法则（Rule of Five）**：管理资源的类需要定义析构函数、拷贝构造、拷贝赋值、移动构造、移动赋值。
8. **auto 关键字**：自动类型推导，简化代码，但会忽略顶层 const 和引用，需要时显式写 const auto 或 auto&。
9. **decltype 关键字**：推导表达式类型但不求值，保留 const 和引用，用于需要精确类型信息的场景。
10. **范围 for 循环**：简化容器遍历，推荐使用 const auto& 避免拷贝，不要在循环中修改正在遍历的容器。
11. **统一初始化列表**：使用 {} 统一所有类型的初始化语法，防止窄化转换，但优先匹配 initializer_list 构造函数。
12. **nullptr**：类型安全的空指针常量，替代 NULL 和 0，避免重载歧义。
13. **性能优化**：移动比拷贝快100倍以上，返回大对象时编译器自动使用移动语义或 RVO。
14. **noexcept 的重要性**：STL 容器扩容时，只有 noexcept 的移动构造才会被使用，否则使用拷贝保证异常安全。

## 💭 今日心得
今天学习了现代 C++ 的核心特性——移动语义和语法糖，这些是 C++11 引入的革命性改进。

移动语义彻底改变了 C++ 的性能优化方式。以前只能通过拷贝传递对象，大对象的拷贝开销巨大。现在有了移动语义，可以转移资源所有权，只需要复制指针，性能提升100倍以上。理解左值和右值的区别是关键——左值有名字可取地址，右值是临时对象。右值引用（&&）绑定到右值，实现移动语义。std::move 只是类型转换，真正的移动发生在移动构造和移动赋值中。

移动构造和移动赋值的实现要点：偷走源对象的资源指针，将源对象置为安全状态（nullptr），必须标记 noexcept。noexcept 非常重要，STL 容器扩容时只有 noexcept 的移动构造才会被使用，否则为了异常安全会使用拷贝，性能损失巨大。移动后的对象处于"有效但未定义"状态，可以安全析构，但不应再使用其值。

现代 C++ 语法糖让代码更简洁、更安全。auto 自动类型推导，避免冗长的类型名，特别适合迭代器和复杂模板类型。但要注意 auto 会忽略顶层 const 和引用，需要时显式写 const auto 或 auto&。范围 for 循环简化容器遍历，推荐使用 const auto& 避免拷贝，只有基本类型才用 auto。统一初始化列表（{}）防止窄化转换，但要注意优先匹配 initializer_list 构造函数。nullptr 替代 NULL，类型安全，避免重载歧义。

通过综合练习，实现了支持移动语义的字符串类，对比了拷贝和移动的性能差异，结合智能指针和 Lambda 表达式完成了学生管理系统。这些特性组合使用，可以写出高效、简洁、安全的现代 C++ 代码。

从今天开始，应该全面使用这些现代特性：返回大对象时利用移动语义，遍历容器时使用 const auto&，创建智能指针时使用 make_unique/make_shared，使用 Lambda 简化算法调用。这些是现代 C++ 的标配，掌握它们是成为优秀 C++ 程序员的必经之路。
