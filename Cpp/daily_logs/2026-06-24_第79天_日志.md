## 📖 学到的知识点

### 1. 三大核心组件

**组件关系**：
```
Promise：配置协程行为（配置文件）
coroutine_handle：操作协程（遥控器）
Awaitable：定义暂停和恢复（控制器）
```

#### 1.1 Promise 类型

**作用**：配置协程行为

**必需方法**：
```cpp
struct promise_type {
    // 1. 返回协程对象
    Generator get_return_object();
    
    // 2. 协程开始时的行为
    suspend_never/suspend_always initial_suspend();
    
    // 3. 协程结束时的行为
    suspend_always final_suspend() noexcept;
    
    // 4. 异常处理
    void unhandled_exception();
    
    // 5. co_yield 或 co_return
    suspend_always yield_value(T value);  // co_yield
    void return_value(T value);           // co_return
};
```

**关键理解**：
- Promise 是协程的"配置文件"
- 编译器根据 Promise 生成协程代码
- 不同的 Promise → 不同的协程行为

---

#### 1.2 coroutine_handle

**作用**：操作协程

**常用方法**：
```cpp
std::coroutine_handle<promise_type> handle;

// 恢复协程
handle.resume();

// 销毁协程
handle.destroy();

// 检查是否完成
bool done = handle.done();

// 访问 Promise
promise_type& p = handle.promise();
```

**关键理解**：
- handle 是协程的"遥控器"
- 通过 handle 控制协程的暂停和恢复
- 协程对象通常持有 handle

#### 1.3 Awaitable 对象

**作用**：定义 co_await 的行为

**接口**：
```cpp
struct Awaitable {
    // 是否需要暂停？
    bool await_ready();
    
    // 暂停时调用
    void await_suspend(std::coroutine_handle<>);
    
    // 恢复时调用，返回 co_await 的结果
    auto await_resume();
};
```

**内置类型**：
```cpp
// 永不暂停
std::suspend_never

// 总是暂停
std::suspend_always
```

### 2. Generator 实现

**完整实现**：
```cpp
template<typename T>
class Generator {
public:
    struct promise_type {
        T current_value;  // 当前值
        
        // 返回 Generator 对象
        Generator get_return_object() {
            return Generator{
                std::coroutine_handle<promise_type>::from_promise(*this)
            };
        }
        
        // 延迟执行（需要手动 resume）
        std::suspend_always initial_suspend() { 
            return {}; 
        }
        
        // 保持状态（不自动销毁）
        std::suspend_always final_suspend() noexcept { 
            return {}; 
        }
        
        // co_yield value 调用时
        std::suspend_always yield_value(T value) {
            current_value = value;  // 保存值
            return {};              // 暂停
        }
        
        void return_void() {}
        void unhandled_exception() {}
    };
    
private:
    std::coroutine_handle<promise_type> handle;
    
public:
    // 构造、析构、移动...
    
    // 获取下一个值
    T next() {
        handle.resume();  // 恢复协程
        return handle.promise().current_value;
    }
    
    // 是否完成
    bool done() const {
        return handle.done();
    }
};
```

**使用示例**：
```cpp
Generator<int> fibonacci() {
    int a = 0, b = 1;
    while (true) {
        co_yield a;  // 暂停并返回 a
        int next = a + b;
        a = b;
        b = next;
    }
}

// 使用
auto gen = fibonacci();
cout << gen.next();  // 0
cout << gen.next();  // 1
cout << gen.next();  // 1
cout << gen.next();  // 2
```

**关键点**：

**1. co_yield 的工作原理**：
```
co_yield value
  ↓
编译器调用 promise.yield_value(value)
  ↓
保存 value 到 current_value
  ↓
返回 suspend_always，暂停协程
  ↓
next() 调用 resume()，从暂停处恢复
  ↓
返回 current_value
```

**2. initial_suspend 返回 suspend_always**：
```cpp
// 延迟执行
std::suspend_always initial_suspend() { return {}; }

auto gen = fibonacci();  // 创建，但未执行
gen.next();              // 第1次 resume，开始执行
```

**3. 惰性求值**：
```cpp
Generator<int> range(int n) {
    for (int i = 0; i < n; i++) {
        co_yield i;  // 按需生成
    }
}

// 只生成需要的值
for (int i = 0; i < 10; i++) {
    cout << gen.next();  // 只生成了 10 个
}
```

### 3. Task 实现

**完整实现**：
```cpp
template<typename T>
class Task {
public:
    struct promise_type {
        std::optional<T> result_value;  // 结果值
        
        // 返回 Task 对象
        Task get_return_object() {
            return Task{
                std::coroutine_handle<promise_type>::from_promise(*this)
            };
        }
        
        // 立即开始执行
        std::suspend_never initial_suspend() { 
            return {}; 
        }
        
        // 保持状态
        std::suspend_always final_suspend() noexcept { 
            return {}; 
        }
        
        // co_return value 调用时
        void return_value(T value) {
            result_value = value;  // 保存结果
        }
        
        void unhandled_exception() {}
    };
    
private:
    std::coroutine_handle<promise_type> handle;
    
public:
    // 恢复协程
    void resume() {
        if (handle && !handle.done()) {
            handle.resume();
        }
    }
    
    // 是否完成
    bool done() const {
        return handle.done();
    }
    
    // 获取结果
    T result() {
        return handle.promise().result_value.value();
    }
};
```

**使用示例**：
```cpp
Task<int> calculate() {
    int sum = 0;
    for (int i = 0; i < 10; i++) {
        sum += i;
        co_await std::suspend_always{};  // 让出 CPU
    }
    co_return sum;  // 返回结果
}

// 使用
auto task = calculate();
while (!task.done()) {
    task.resume();  // 手动驱动
}
int result = task.result();  // 45
```

**关键点**：

**1. co_return 的工作原理**：
```
co_return value
  ↓
编译器调用 promise.return_value(value)
  ↓
保存 value 到 result_value
  ↓
协程结束
  ↓
result() 获取 result_value
```

**2. initial_suspend 返回 suspend_never**：
```cpp
// 立即执行
std::suspend_never initial_suspend() { return {}; }

auto task = calculate();  // 创建并开始执行
task.resume();            // 从第1个暂停处恢复
```

**3. 与 Generator 的对比**：

| 维度 | Generator | Task |
|------|-----------|------|
| 关键字 | co_yield | co_return |
| 返回值 | 多次 | 一次 |
| Promise 方法 | yield_value() | return_value() |
| initial_suspend | suspend_always（延迟） | suspend_never（立即） |
| 使用场景 | 生成序列 | 异步任务 |

### 4. Awaitable 接口

**接口定义**：
```cpp
struct Awaitable {
    // 1. 是否需要暂停？
    bool await_ready();
    
    // 2. 暂停时调用
    void await_suspend(std::coroutine_handle<>);
    
    // 3. 恢复时调用
    auto await_resume();
};
```

**内置类型**：

**suspend_never**：
```cpp
struct suspend_never {
    bool await_ready() const noexcept { 
        return true;  // 不需要暂停
    }
    void await_suspend(std::coroutine_handle<>) const noexcept {}
    void await_resume() const noexcept {}
};

// 使用
co_await std::suspend_never{};  // 不暂停，立即继续
```

**suspend_always**：
```cpp
struct suspend_always {
    bool await_ready() const noexcept { 
        return false;  // 需要暂停
    }
    void await_suspend(std::coroutine_handle<>) const noexcept {}
    void await_resume() const noexcept {}
};

// 使用
co_await std::suspend_always{};  // 暂停，等待 resume
```

**自定义 Awaitable**：
```cpp
struct IntAwaitable {
    int value;
    
    bool await_ready() { return false; }
    void await_suspend(std::coroutine_handle<>) {}
    int await_resume() { return value; }  // 返回值
};

// 使用
Task<void> test() {
    int x = co_await IntAwaitable{42};
    cout << x << endl;  // 42
}
```

### 5. 协程执行流程

**完整流程**（10个步骤）：
```
1. 调用协程函数
   ↓
2. 编译器创建协程帧
   - 分配内存
   - 创建 Promise 对象
   ↓
3. promise.get_return_object()
   - 返回协程对象
   ↓
4. promise.initial_suspend()
   - suspend_never → 立即开始
   - suspend_always → 延迟执行
   ↓
5. 执行协程体
   ↓
6. 遇到 co_yield / co_await
   - 保存状态，暂停
   ↓
7. 外部调用 handle.resume()
   - 从暂停处恢复
   ↓
8. co_return value
   - promise.return_value(value)
   ↓
9. promise.final_suspend()
   - 返回 suspend_always
   ↓
10. 外部调用 handle.destroy()
    - 销毁协程帧
```

**Generator 流程**：
```
auto gen = fibonacci();  // 步骤 1-4（创建，未执行）
int val1 = gen.next();   // 步骤 5-6（执行到第1个 co_yield，暂停）
int val2 = gen.next();   // 步骤 7-6（恢复，执行到第2个 co_yield）
// ~Generator()          // 步骤 10（销毁）
```

**Task 流程**：
```
auto task = calculate();  // 步骤 1-5（创建并立即执行到第1个暂停）
task.resume();            // 步骤 7（恢复）
int result = task.result();  // 获取结果
```

## ❓ 遇到的问题与解决

**问题1**：Promise 类型为什么这么复杂？

**解决**：
- Promise 是协程的"配置文件"
- 需要定义协程的各种行为
- 编译器根据 Promise 生成代码
- 复杂但灵活，可以定制任何行为

**问题2**：initial_suspend 应该返回什么？

**解决**：
- Generator：返回 suspend_always（延迟执行）
  - 原因：需要 next() 驱动
- Task：返回 suspend_never（立即执行）
  - 原因：创建即开始

**问题3**：final_suspend 为什么返回 suspend_always？

**解决**：
- 保持协程状态，不立即销毁
- 可以获取结果（result_value）
- 避免悬垂指针
- 手动调用 destroy() 销毁

### 3. 协程的"状态机"本质

**协程看起来像魔法**：
```cpp
co_await asyncOp();  // 看起来是同步的
```

**实际上是状态机**：
```cpp
// 协程代码
Task<void> func() {
    auto data1 = co_await op1();  // 状态1
    auto data2 = co_await op2();  // 状态2
}

// 等价状态机
class FuncStateMachine {
    int state = 0;
    Data data1, data2;
    
    void resume() {
        switch (state) {
            case 0:
                op1(); state = 1; return;
            case 1:
                data1 = get_op1_result();
                op2(); state = 2; return;
            case 2:
                data2 = get_op2_result();
                state = 3; return;
        }
    }
};
```

**协程 = 状态机的语法糖**：
- 编译器自动生成状态机
- 程序员写同步代码
- 运行时执行异步逻辑

**这种理解很重要**：
- 协程不是魔法
- 是编译器的技巧
- 理解本质才能用好

### 4. Generator vs Task 的设计哲学

**Generator**：
- 惰性求值（按需生成）
- 多次返回（co_yield）
- 延迟执行（suspend_always）

**Task**：
- 异步任务（返回结果）
- 一次返回（co_return）
- 立即执行（suspend_never）

**设计哲学不同**：
- Generator：像迭代器（pull 模式）
- Task：像 Future（push 模式）

**没有对错，只有适合**：
- 生成序列 → Generator
- 异步任务 → Task

**这就是"没有银弹"**：
- 不同场景，不同方案
- 理解场景，选择工具
