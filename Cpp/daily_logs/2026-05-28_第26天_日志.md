## 📖 学到的知识点

### 核心知识点

1. **嵌套容器的使用**
   - `vector<Course>` 嵌套在 Student 类中
   - 管理一对多关系（一个学生有多门课程）

2. **Lambda 表达式的实际应用**
   - 在 `find_if` 中使用 Lambda 查找课程
   - 在 `sort` 中使用 Lambda 自定义排序规则
   - 值捕获 vs 引用捕获的选择

3. **function 对象作为参数**
   - `function<bool(const Student&)>` 作为函数参数
   - 实现灵活的过滤接口
   - 调用者可以传入任意 Lambda 表达式

4. **STL 算法的组合使用**
   - `find_if` + Lambda：查找符合条件的元素
   - `sort` + Lambda：自定义排序规则
   - 容器 + 算法 + Lambda 的完整工作流

5. **pair 容器的使用**
   - `pair<string, double>` 存储学号和平均分
   - `vector<pair<string, double>>` 存储排名列表
   - 在 Lambda 中访问 pair 的 first 和 second

6. **const 正确性**
   - const 成员函数（不修改对象状态）
   - const 迭代器（只读访问）
   - 双版本方法（const 和 non-const）

7. **错误处理和边界情况**
   - 检查课程代码是否重复
   - 处理空课程列表（返回0.0）
   - 只统计有成绩的学生

8. **格式化输出**
   - 使用 `setw` 对齐列
   - 使用 `fixed` 和 `setprecision` 控制小数位数
   - 使用 `left` 左对齐

9. **多文件项目组织**
   - 头文件声明接口
   - 实现文件定义方法
   - 主程序协调各个模块

10. **面向对象设计原则**
    - 单一职责：Course 只管课程，Student 只管学生信息
    - 封装：私有成员变量，公有访问方法
    - 复用：通用的 filterStudents 方法
