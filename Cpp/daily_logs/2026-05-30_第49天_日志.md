## 📖 学到的知识点

### 阶段9总结（Qt 网络编程）
1. **QNetworkAccessManager 核心 API**：get()、post()、put()、deleteResource()
2. **HTTP GET 请求模板**：创建管理器 → 创建请求 → 发送请求 → 处理响应
3. **HTTP POST 请求模板**：构造 JSON/表单数据 → 设置 Content-Type → 发送请求
4. **JSON 解析速查**：QJsonDocument::fromJson() → object()/array() → 访问字段
5. **文件下载模板**：基础下载（readAll）vs 流式下载（readyRead）
6. **常见公开 API**：IP查询、UUID生成、汇率查询、天气查询等
7. **错误处理**：检查 reply->error()、处理超时、释放 reply
8. **最佳实践**：管理器复用、Lambda 简化、检查 JSON 有效性、大文件流式下载

### 阶段10开始（Qt 多线程编程）
9. **多线程的必要性**：避免 UI 卡顿，耗时任务在后台执行
10. **Qt 线程模型**：主线程（UI）+ 工作线程（计算/I/O）+ 信号槽通信
11. **QThread 基础概念**：start()、quit()、wait()、isRunning()
12. **moveToThread 模式（推荐）**：创建工作对象 → 创建线程 → moveToThread → 连接信号槽 → start()
13. **线程间信号槽通信**：Qt 自动使用队列连接（QueuedConnection），线程安全
14. **黄金规则**：永远不要在工作线程中直接操作 UI，通过信号通知主线程
15. **取消机制**：使用布尔标志（shouldStop），工作线程定期检查
16. **常见错误**：
    - 在工作线程中操作 UI → 崩溃
    - moveToThread 时设置了父对象 → 失败
    - 忘记启动线程 → 任务不执行
    - 忘记清理线程 → 内存泄漏
    - 在工作线程中使用 QTimer → 不工作
17. **实战项目**：斐波那契计算器（后台计算、进度更新、取消功能、UI 保持响应）
