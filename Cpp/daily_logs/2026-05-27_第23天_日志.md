## 📖 学到的知识点

### 核心知识点

1. **移动语义与右值引用**
   - 左值（lvalue）：有名字、可取地址的对象
   - 右值（rvalue）：临时对象、字面量、即将销毁的对象
   - 右值引用（&&）：绑定到右值的引用类型
   - 移动构造函数：转移资源所有权，避免深拷贝
   - 移动赋值运算符：转移资源并释放原有资源
   - std::move：将左值转换为右值引用（类型转换工具）

2. **五法则（Rule of Five）**
   - 析构函数
   - 拷贝构造函数
   - 拷贝赋值运算符
   - 移动构造函数
   - 移动赋值运算符

3. **现代 C++ 语法糖**
   - `auto` 关键字：自动类型推导
   - `decltype`：获取表达式的类型
   - 范围 for 循环：`for (auto& item : container)`
   - 统一初始化列表：`vector<int> v{1, 2, 3}`
   - `nullptr`：替代 NULL 的空指针字面量
   - `constexpr`：编译期常量表达式

4. **性能优化**
   - 移动语义避免不必要的深拷贝
   - 返回值优化（RVO）
   - `noexcept` 标记移动操作不抛异常

5. **最佳实践**
   - 移动后的对象处于"有效但未指定"状态
   - 使用 `const auto&` 遍历容器避免拷贝
   - 优先使用范围 for 循环
   - 使用 `nullptr` 而不是 `NULL` 或 `0`
