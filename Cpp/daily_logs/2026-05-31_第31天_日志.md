## 💡 今日学习要点

### 1. 移动语义的本质

**核心概念**：
- 移动语义是转移资源所有权，而非复制资源
- 避免不必要的深拷贝，提高性能

**std::move 的真相**：
```cpp
// std::move 只是类型转换
string s1 = "hello";
string s2 = std::move(s1);  // move 将 s1 转换为右值引用

// 等价于：
string s2 = static_cast<string&&>(s1);

// 真正的移动发生在移动构造函数中
```

**移动构造函数的实现**：
```cpp
Buffer(Buffer&& other) noexcept 
    : data(other.data), size(other.size) {
    // 转移所有权
    other.data = nullptr;
    other.size = 0;
    // 必须清空源对象的资源指针
}
```

**关键要点**：
- 移动操作必须标记为 `noexcept`
- 移动后的对象必须处于有效但未指定的状态
- 必须清空源对象的资源指针（避免 double free）

### 2. 五法则（Rule of Five）

**完整的五法则**：
```cpp
class MyClass {
public:
    // 1. 析构函数
    ~MyClass();
    
    // 2. 拷贝构造函数
    MyClass(const MyClass& other);
    
    // 3. 拷贝赋值运算符
    MyClass& operator=(const MyClass& other);
    
    // 4. 移动构造函数
    MyClass(MyClass&& other) noexcept;
    
    // 5. 移动赋值运算符
    MyClass& operator=(MyClass&& other) noexcept;
};
```

**原则**：
- 如果需要自定义其中任何一个，通常需要自定义全部五个
- 管理资源的类必须实现五法则
- 移动操作必须标记为 noexcept

### 3. noexcept 的重要性

**为什么重要**：
```cpp
// STL 容器的行为
vector<MyClass> vec;
vec.push_back(obj);  // 可能触发扩容

// 如果移动构造是 noexcept：
// - 扩容时使用移动（高效）

// 如果移动构造不是 noexcept：
// - 扩容时使用拷贝（低效，但异常安全）
```

**检查方法**：
```cpp
// 使用 noexcept 运算符
cout << noexcept(MyClass(declval<MyClass&&>())) << endl;
// 输出 1（true）表示是 noexcept
```

### 4. 完美转发的原理

**问题场景**：
```cpp
template<typename T>
void wrapper(T arg) {
    target(arg);  // 问题：arg 总是左值
}

wrapper(10);  // 传入右值，但 arg 是左值
```

**解决方案：万能引用 + std::forward**：
```cpp
template<typename T>
void wrapper(T&& arg) {  // 万能引用
    target(std::forward<T>(arg));  // 完美转发
}

// 工作原理：
// - 传入左值：T 推导为 T&，arg 类型为 T&
// - 传入右值：T 推导为 T，arg 类型为 T&&
```

**引用折叠规则**：
```
T& &   → T&   (左值引用 + 左值引用 = 左值引用)
T& &&  → T&   (左值引用 + 右值引用 = 左值引用)
T&& &  → T&   (右值引用 + 左值引用 = 左值引用)
T&& && → T&&  (右值引用 + 右值引用 = 右值引用)

简单记忆：只要有左值引用，结果就是左值引用
```

### 5. std::forward 的实现原理

**简化版实现**：
```cpp
template<typename T>
T&& forward(remove_reference_t<T>& arg) {
    return static_cast<T&&>(arg);
}

// 工作原理：
// 1. 如果 T = int&，返回 int& &&（折叠为 int&）
// 2. 如果 T = int，返回 int&&
```

**使用场景**：
```cpp
// 1. 工厂函数
template<typename T, typename... Args>
unique_ptr<T> make_unique(Args&&... args) {
    return unique_ptr<T>(new T(std::forward<Args>(args)...));
}

// 2. 包装器函数
template<typename Func, typename... Args>
auto wrapper(Func&& func, Args&&... args) {
    return std::forward<Func>(func)(std::forward<Args>(args)...);
}

// 3. emplace 方法
template<typename... Args>
void emplace_back(Args&&... args) {
    new (ptr) T(std::forward<Args>(args)...);
}
```

### 6. 万能引用 vs 右值引用

**万能引用（Universal Reference）**：
```cpp
template<typename T>
void func(T&& param);  // 万能引用（模板参数推导）

auto&& x = expr;       // 万能引用（auto 推导）
```

**右值引用**：
```cpp
void func(Widget&& w);  // 右值引用（非模板）

template<typename T>
void func(vector<T>&& v);  // 右值引用（非推导）
```

**区别**：
- 万能引用：可以绑定到左值或右值
- 右值引用：只能绑定到右值

### 7. 性能对比

**三种方式的性能**：
```cpp
// 方式1：拷贝（最慢）
for (int i = 0; i < N; i++) {
    Buffer b(size);
    vec.push_back(b);  // 拷贝构造 + 析构
}

// 方式2：移动（快）
for (int i = 0; i < N; i++) {
    Buffer b(size);
    vec.push_back(move(b));  // 移动构造 + 析构
}

// 方式3：直接构造（最快）
for (int i = 0; i < N; i++) {
    vec.push_back(Buffer(size));  // 移动构造
}

// 性能排序：方式3 ≈ 方式2 > 方式1
```

## 🎯 重要知识点

### 1. 移动语义最佳实践

**推荐做法**：
```cpp
// ✅ 移动操作标记为 noexcept
MyClass(MyClass&& other) noexcept { ... }
MyClass& operator=(MyClass&& other) noexcept { ... }

// ✅ 移动后清空源对象
other.data = nullptr;
other.size = 0;

// ✅ 自我赋值检查
if (this != &other) { ... }

// ✅ 优先使用直接构造
vec.push_back(MyClass(args));  // 而非先构造再移动
```

**避免做法**：
```cpp
// ❌ 移动操作不标记 noexcept
MyClass(MyClass&& other) { ... }  // STL 容器会退化为拷贝

// ❌ 移动后不清空源对象
// 可能导致 double free

// ❌ 过度使用 std::move
return std::move(local_var);  // 阻止 RVO
```

### 2. 完美转发最佳实践

**推荐做法**：
```cpp
// ✅ 使用万能引用 + std::forward
template<typename T>
void wrapper(T&& arg) {
    target(std::forward<T>(arg));
}

// ✅ 可变参数模板 + 完美转发
template<typename... Args>
void func(Args&&... args) {
    target(std::forward<Args>(args)...);
}
```

**注意事项**：
```cpp
// ⚠️ 万能引用只在模板参数推导时才是万能引用
template<typename T>
void func(T&& param);  // 万能引用

void func(Widget&& w);  // 右值引用，不是万能引用

// ⚠️ 完美转发不能转发大括号初始化列表
wrapper({1, 2, 3});  // 编译错误
```

### 3. 何时使用移动语义

**适合使用移动的场景**：
- 管理动态分配资源的类（指针、文件句柄等）
- 大型对象（容器、字符串等）
- 临时对象和函数返回值

**不需要移动的场景**：
- 基本类型（int、double 等）
- 小型对象（几个字节）
- 没有动态资源的类

## ❓ 遇到的问题与解决

**问题1**：为什么移动操作必须标记为 noexcept？

**解答**：
- STL 容器（如 vector）在扩容时需要移动元素
- 如果移动操作可能抛异常，容器会退化为拷贝（保证异常安全）
- 标记为 noexcept 后，容器会使用移动（性能更好）

**验证**：
```cpp
// 示例9 中验证了这一点
cout << noexcept(String(declval<String&&>())) << endl;  // 输出 1

// vector 扩容时使用移动而非拷贝
```

**问题2**：std::move 和 std::forward 有什么区别？

**解答**：
- **std::move**：无条件将参数转换为右值引用
  ```cpp
  string s = "hello";
  string s2 = std::move(s);  // 总是转换为右值引用
  ```

- **std::forward**：根据模板参数类型有条件转发
  ```cpp
  template<typename T>
  void wrapper(T&& arg) {
      target(std::forward<T>(arg));  // 保持原始值类别
  }
  ```

**问题3**：什么时候使用万能引用，什么时候使用右值引用？

**解答**：
- **万能引用**：需要接受左值和右值时使用
  ```cpp
  template<typename T>
  void func(T&& param);  // 可以接受左值和右值
  ```

- **右值引用**：只接受右值时使用
  ```cpp
  void func(Widget&& w);  // 只接受右值
  ```
