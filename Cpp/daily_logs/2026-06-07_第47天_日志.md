## 📖 学到的知识点

1. **QNetworkAccessManager**：网络请求管理器，一个应用通常只需一个实例
2. **QNetworkRequest**：封装请求 URL、Header、超时等信息
3. **manager->get(request)**：发送 GET 请求，立即返回 QNetworkReply*（异步）
4. **manager->post(request, data)**：发送 POST 请求，data 为 QByteArray
5. **reply->finished() 信号**：请求完成时触发，在槽函数中处理响应
6. **reply->error()**：检查错误类型（NoError = 成功）
7. **reply->readAll()**：读取全部响应体（QByteArray）
8. **reply->deleteLater()**：必须调用，否则内存泄漏
9. **setTransferTimeout(ms)**：设置请求超时时间（Qt 5.15+）
10. **QJsonDocument::fromJson()**：解析 JSON 字节数组，失败时 isNull() 返回 true
11. **QJsonParseError**：解析错误信息（errorString、offset）
12. **QJsonObject**：JSON 对象，用 obj["key"] 访问字段
13. **QJsonArray**：JSON 数组，用 arr[i] 或 for 循环遍历
14. **QJsonValue::type()**：判断字段类型（String/Double/Bool/Array/Object/Null）
15. **QJsonDocument(obj).toJson()**：将 JSON 对象序列化为字节数组
16. **QJsonDocument::Compact / Indented**：紧凑格式 vs 缩进格式
17. **request.setRawHeader()**：设置自定义请求头（如 Authorization）
