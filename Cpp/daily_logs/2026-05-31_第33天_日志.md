## 📚 学习内容

### 1. C++20 概念基础

**什么是概念（Concepts）？**

概念是 C++20 引入的重要特性，为模板参数提供命名的约束：
- 比 SFINAE 更清晰、更易读
- 编译错误信息更友好
- 是现代 C++ 模板编程的最佳实践

**概念的定义语法**：
```cpp
// 基本语法
template<typename T>
concept 概念名 = 约束表达式;

// 示例1：整数概念
template<typename T>
concept Integral = std::is_integral_v<T>;

// 示例2：可加概念
template<typename T>
concept Addable = requires(T a, T b) {
    { a + b } -> std::same_as<T>;
};

// 示例3：容器概念
template<typename T>
concept Container = requires(T t) {
    typename T::value_type;
    { t.size() } -> std::convertible_to<std::size_t>;
    { t.begin() };
    { t.end() };
};
```

**概念的四种使用方式**：

```cpp
// 方式1：requires 子句
template<typename T>
requires std::integral<T>
void func(T value) { }

// 方式2：简写形式（推荐）
template<std::integral T>
void func(T value) { }

// 方式3：尾置 requires
template<typename T>
void func(T value) requires std::integral<T> { }

// 方式4：auto 参数（C++20）
void func(std::integral auto value) { }
```

**标准库提供的概念**：

```cpp
// 核心语言概念（<concepts>）
std::same_as<T, U>           // T 和 U 是相同类型
std::derived_from<T, U>      // T 派生自 U
std::convertible_to<T, U>    // T 可以转换为 U
std::integral<T>             // T 是整数类型
std::floating_point<T>       // T 是浮点类型
std::signed_integral<T>      // T 是有符号整数
std::unsigned_integral<T>    // T 是无符号整数

// 比较概念
std::equality_comparable<T>  // T 支持 == 和 !=
std::totally_ordered<T>      // T 支持 <, >, <=, >=

// 对象概念
std::movable<T>              // T 可以移动
std::copyable<T>             // T 可以拷贝
std::semiregular<T>          // T 可以默认构造和拷贝
std::regular<T>              // T 是规则类型

// 可调用概念
std::invocable<F, Args...>   // F 可以用 Args... 调用
std::predicate<F, Args...>   // F 是谓词（返回 bool）
```

### 2. requires 表达式详解

**requires 表达式的四种形式**：

**1. 简单要求（Simple Requirements）**
```cpp
template<typename T>
concept Addable = requires(T a, T b) {
    a + b;  // 表达式必须有效
};
```

**2. 类型要求（Type Requirements）**
```cpp
template<typename T>
concept HasValueType = requires {
    typename T::value_type;  // 必须有 value_type 类型
    typename T::iterator;    // 必须有 iterator 类型
};
```

**3. 复合要求（Compound Requirements）**
```cpp
template<typename T>
concept HasSize = requires(T t) {
    { t.size() } -> std::convertible_to<size_t>;  // 返回类型约束
    { t.empty() } noexcept -> std::same_as<bool>;  // noexcept 约束
};
```

**4. 嵌套要求（Nested Requirements）**
```cpp
template<typename T>
concept SortableContainer = requires(T t) {
    requires Container<T>;  // 嵌套概念
    requires std::totally_ordered<typename T::value_type>;
};
```

**约束的组合**：

```cpp
// 逻辑与（&&）
template<typename T>
concept SignedIntegral = std::integral<T> && std::signed_integral<T>;

// 逻辑或（||）
template<typename T>
concept Numeric = std::integral<T> || std::floating_point<T>;

// 逻辑非（!）
template<typename T>
concept NotPointer = !std::is_pointer_v<T>;

// 复杂组合
template<typename T>
concept StringLike =
    std::convertible_to<T, std::string> ||
    std::same_as<T, const char*> ||
    std::same_as<T, char*>;
```

**概念的特化**：

```cpp
// 基础概念
template<typename T>
concept Arithmetic = std::integral<T> || std::floating_point<T>;

// 通用版本
template<Arithmetic T>
T multiply(T a, T b) {
    return a * b;
}

// 特化版本（整数优化）
template<std::integral T>
T multiply(T a, T b) {
    cout << "整数乘法优化" << endl;
    return a * b;
}
```

### 3. 使用概念重写通用打印函数

**概念定义**：
```cpp
// 算术类型概念
template<typename T>
concept Arithmetic = std::integral<T> || std::floating_point<T>;

// 字符串类型概念
template<typename T>
concept StringLike =
    std::same_as<T, string> ||
    std::same_as<T, const char*>;

// 容器概念（排除 string）
template<typename T>
concept Container = requires(T t) {
    typename T::value_type;
    { t.begin() };
    { t.end() };
} && !std::same_as<T, string>;
```

**打印函数实现**：
```cpp
// 1. 打印算术类型
template<Arithmetic T>
void print(const T& value) {
    cout << value;
}

// 2. 打印字符串
template<StringLike T>
void print(const T& value) {
    cout << "\"" << value << "\"";
}

// 3. 打印容器
template<Container C>
void print(const C& container) {
    cout << "[";
    bool first = true;
    for (const auto& item : container) {
        if (!first) cout << ", ";
        print(item);
        first = false;
    }
    cout << "]";
}

// 4. 可变参数打印
template<typename... Args>
void println(Args&&... args) {
    (print(args), ...);
    cout << endl;
}
```

**使用示例**：
```cpp
// 打印基本类型
println(42, ", ", 3.14, ", ", true);

// 打印容器
vector<int> vec = {1, 2, 3, 4, 5};
println(vec);

// 打印嵌套容器
vector<vector<int>> nested = {{1, 2}, {3, 4}};
println(nested);

// 打印复杂结构
map<int, string> m = {{1, "one"}, {2, "two"}};
println(m);
```

## 🎯 重点知识总结

### 1. 概念的核心优势

**对比 SFINAE**：

| 特性 | SFINAE | 概念（Concepts） |
|------|--------|------------------|
| 可读性 | 复杂，难以理解 | 清晰，易于理解 |
| 错误信息 | 冗长，难以定位 | 简洁，直接指出问题 |
| 复用性 | 需要重复写约束 | 可以命名和复用 |
| 组合性 | 嵌套复杂 | 使用 &&、\|\| 组合 |
| 意图表达 | 间接 | 直接明确 |

**SFINAE 方式**：
```cpp
template<typename T>
enable_if_t<is_integral<T>::value && is_signed<T>::value>
func(T value) { ... }
```

**概念方式**：
```cpp
template<std::signed_integral T>
void func(T value) { ... }
```

### 2. requires 表达式的四种形式

| 形式 | 语法 | 用途 |
|------|------|------|
| 简单要求 | `a + b;` | 表达式必须有效 |
| 类型要求 | `typename T::value_type;` | 必须有该类型 |
| 复合要求 | `{ t.size() } -> std::convertible_to<size_t>;` | 返回类型约束 |
| 嵌套要求 | `requires Container<T>;` | 嵌套其他概念 |

### 3. 标准库概念分类

**核心语言概念**：
- `std::integral<T>` - 整数类型
- `std::floating_point<T>` - 浮点类型
- `std::signed_integral<T>` - 有符号整数
- `std::unsigned_integral<T>` - 无符号整数

**比较概念**：
- `std::equality_comparable<T>` - 支持 ==、!=
- `std::totally_ordered<T>` - 支持 <、>、<=、>=

**对象概念**：
- `std::movable<T>` - 可移动
- `std::copyable<T>` - 可拷贝
- `std::regular<T>` - 规则类型

**可调用概念**：
- `std::invocable<F, Args...>` - 可调用
- `std::predicate<F, Args...>` - 谓词

### 4. 概念的使用场景

**适合使用概念的场景**：
- 模板函数的参数约束
- 模板类的类型约束
- 函数重载选择
- 编译期类型检查
- 泛型算法实现

**概念的最佳实践**：
1. 优先使用标准库概念
2. 自定义概念要语义清晰
3. 使用简写形式（`template<Concept T>`）
4. 组合概念使用 &&、||
5. 避免过度约束

### 5. 概念 vs SFINAE 选择

**使用概念的理由**：
- C++20 及以上项目
- 需要清晰的代码
- 需要友好的错误信息
- 需要复用约束

**仍使用 SFINAE 的情况**：
- C++17 及以下项目
- 需要兼容旧代码
- 编译器不支持 C++20
