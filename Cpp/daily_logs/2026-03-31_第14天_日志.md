## 📚 知识点总结

### 1. 继承基础（45_inheritance_basics.cpp）

**语法**：
```cpp
class Dog : public Animal {  // Dog is-a Animal
    // 继承 Animal 的所有 public/protected 成员
};
```

**三种继承方式**：
| 继承方式 | 父类public | 父类protected | 父类private |
|---------|-----------|--------------|------------|
| public  | public    | protected    | 不可访问    |
| protected | protected | protected  | 不可访问    |
| private | private   | private      | 不可访问    |

**关键规则**：
- `protected`：类外不可访问，子类内可访问
- is-a 关系：子类对象可赋给父类指针/引用
- 最常用：`public` 继承

---

### 2. 继承中的构造与析构（46_inheritance_constructor.cpp）

**顺序口诀**：
```
构造：父类 → 成员对象（声明顺序）→ 子类
析构：子类 → 成员对象（逆序）    → 父类
```

**子类调用父类构造函数（初始化列表）**：
```cpp
Dog(string name, int age, string breed)
    : Animal(name, age),  // 必须在初始化列表中调用
      breed(breed) {}
```

**注意**：若不显式调用，编译器自动调用父类默认构造函数

---

### 3. 方法重写与override（47_inheritance_override.cpp）

**重写 vs 隐藏**：
| | virtual函数 | 非virtual函数 |
|--|------------|---------------|
| 子类同名函数 | **重写**（override） | **隐藏**（hiding） |
| 父类指针调用 | 动态绑定（调用子类版本）| 静态绑定（调用父类版本）|

**override 关键字**：
```cpp
void draw() const override;  // 编译器验证父类有同名virtual函数
```

**final 关键字**：
```cpp
void func() override final;  // 禁止子类继续重写
```

**重要规则**：多态基类析构函数必须是 `virtual`，否则通过父类指针 delete 时不会调用子类析构函数 → 资源泄漏
