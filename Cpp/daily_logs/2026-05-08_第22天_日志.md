## 📖 学到的知识点
1. **智能指针概念**：智能指针是自动管理动态内存的类模板，利用 RAII 原则，构造时分配内存，析构时自动释放，无需手动 delete。
2. **unique_ptr**：独占所有权的智能指针，一个资源只能有一个 unique_ptr 拥有，不能拷贝只能移动（std::move），性能最高零开销，是默认选择。
3. **shared_ptr**：共享所有权的智能指针，多个 shared_ptr 可以共享同一个资源，使用引用计数管理，最后一个释放时才释放资源。
4. **weak_ptr**：弱引用智能指针，不拥有资源不增加引用计数，用于打破 shared_ptr 的循环引用问题，必须配合 shared_ptr 使用。
5. **RAII 原则**：资源获取即初始化（Resource Acquisition Is Initialization），在对象构造时获取资源，在对象析构时释放资源，利用 C++ 的自动析构机制管理资源。
6. **异常安全**：智能指针和 RAII 保证即使抛出异常也能正确释放资源，离开作用域时自动调用析构函数。
7. **所有权语义**：unique_ptr 独占所有权，shared_ptr 共享所有权，weak_ptr 不拥有所有权，明确谁负责释放内存。
8. **make_unique/make_shared**：创建智能指针的推荐方式，更安全、性能更好、异常安全。
9. **循环引用问题**：shared_ptr 互相持有会导致引用计数永远不为 0，造成内存泄漏，用 weak_ptr 打破循环。
10. **智能指针应用**：unique_ptr 用于类成员变量和容器元素，shared_ptr 用于共享资源池和观察者模式，weak_ptr 用于打破循环引用。

## 💭 今日心得
今天学习了现代 C++ 的核心特性——智能指针和 RAII 原则，这是 C++ 内存管理的革命性改进。

智能指针彻底改变了 C++ 的内存管理方式。以前需要手动 new/delete，容易忘记释放导致内存泄漏，或者异常抛出时跳过 delete 语句。现在有了智能指针，内存管理变得自动化、安全化，离开作用域时自动释放，即使抛出异常也能正确清理。

unique_ptr 是默认选择，独占所有权，零开销，和裸指针一样快。shared_ptr 用于需要共享资源的场景，通过引用计数管理，最后一个释放时才释放资源。weak_ptr 解决了 shared_ptr 的循环引用问题，不拥有资源，不增加引用计数。

RAII 原则是现代 C++ 的核心思想——资源获取即初始化。不仅用于内存管理，还可以管理文件、锁、网络连接等各种资源。构造函数获取资源，析构函数释放资源，利用对象生命周期自动管理资源，简单而优雅。

通过综合练习，实现了学生管理系统、共享资源池、观察者模式、树形数据结构等实际应用，深刻体会到智能指针的强大和便利。特别是树形结构中，用 shared_ptr 管理子节点，用 weak_ptr 管理父节点，完美解决了循环引用问题。

从今天开始，应该彻底告别手动 new/delete，全面使用智能指针。这不仅让代码更安全，也让代码更现代、更符合 C++ 最佳实践。智能指针是现代 C++ 的标配，掌握它是成为优秀 C++ 程序员的必经之路。
