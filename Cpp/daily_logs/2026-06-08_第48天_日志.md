## 📖 学到的知识点

1. **downloadProgress 信号**：`(qint64 received, qint64 total)`，实时获取下载进度
2. **total = -1**：服务器未返回 Content-Length 时 total 为 -1，需设置不确定进度条 `setRange(0,0)`
3. **reply->abort()**：取消下载，触发 finished() 信号，error() 返回 OperationCanceledError
4. **下载速度计算**：用 QTimer 每秒计算 `当前字节 - 上次字节` 得到速度
5. **流式写入**：大文件应用 readyRead 信号边下载边写入，避免 readAll() 占用大量内存
6. **QFile 保存文件**：`open(WriteOnly)` → `write(data)` → `close()`
7. **QUrl::toPercentEncoding()**：将中文城市名编码为 URL 安全格式
8. **wttr.in API**：无需 API Key 的天气接口，返回 JSON 格式数据
9. **JSON 嵌套解析**：`json["current_condition"].toArray()[0].toObject()["temp_C"].toString()`
10. **QScrollArea**：可滚动内容区域，适合内容长度不固定的界面
11. **动态清除布局**：`takeAt(0)` 循环清除布局中的所有控件
12. **QFrame 卡片样式**：用 border-radius + border + background 实现卡片效果
13. **QUrl::toPercentEncoding()**：中文城市名需要 URL 编码才能正确传递
