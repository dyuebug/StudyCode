### 1. Qt 更多控件详解

**文件**：`qt_basics/05_more_widgets_demo.cpp`（约200行）

**核心内容**：

#### QComboBox（下拉框）
- **核心功能**：提供下拉选项供用户选择，节省界面空间
- **关键方法**：
  - `addItem()`：添加单个选项
  - `addItems()`：批量添加选项
  - `currentText()`：获取当前选中的文本
  - `currentIndex()`：获取当前选中的索引
  - `setCurrentIndex()`：设置默认选项
- **常用信号**：`currentIndexChanged(int)`
- **示例代码**：
```cpp
QComboBox *combo = new QComboBox();
combo->addItems({"北京", "上海", "广州", "深圳", "杭州"});
connect(combo, QOverload<int>::of(&QComboBox::currentIndexChanged),
        [=](int index) {
    QString city = combo->currentText();
    // 处理选项改变
});
```

#### QCheckBox（复选框）
- **核心功能**：允许用户多选，可以设置选中/未选中状态
- **关键方法**：
  - `setChecked(bool)`：设置选中状态
  - `isChecked()`：获取选中状态
  - `setTristate()`：设置三态模式
- **常用信号**：`stateChanged(int)`
- **示例代码**：
```cpp
QCheckBox *hobby1 = new QCheckBox("读书");
QCheckBox *hobby2 = new QCheckBox("运动");
connect(hobby1, &QCheckBox::stateChanged, [=]() {
    QStringList hobbies;
    if (hobby1->isChecked()) hobbies << "读书";
    if (hobby2->isChecked()) hobbies << "运动";
    // 处理爱好改变
});
```

#### QRadioButton（单选按钮）
- **核心功能**：只能选择一个选项，配合 QButtonGroup 实现互斥
- **关键方法**：
  - `setChecked(bool)`：设置选中状态
  - `isChecked()`：获取选中状态
  - `QButtonGroup`：管理按钮组，确保互斥
- **常用信号**：`toggled(bool)`
- **示例代码**：
```cpp
QRadioButton *maleRadio = new QRadioButton("男");
QRadioButton *femaleRadio = new QRadioButton("女");
maleRadio->setChecked(true);

QButtonGroup *group = new QButtonGroup();
group->addButton(maleRadio);
group->addButton(femaleRadio);

connect(maleRadio, &QRadioButton::toggled, [=](bool checked) {
    QString gender = checked ? "男" : "女";
    // 处理性别改变
});
```

#### QSpinBox（数字输入框）
- **核心功能**：限制输入为数字，可以设置范围和步长
- **关键方法**：
  - `setRange(min, max)`：设置范围
  - `setValue(int)`：设置当前值
  - `value()`：获取当前值
  - `setSingleStep(int)`：设置步长
  - `setSuffix(QString)`：设置后缀
- **常用信号**：`valueChanged(int)`
- **示例代码**：
```cpp
QSpinBox *ageSpinBox = new QSpinBox();
ageSpinBox->setRange(18, 100);
ageSpinBox->setValue(25);
ageSpinBox->setSuffix(" 岁");
connect(ageSpinBox, QOverload<int>::of(&QSpinBox::valueChanged),
        [=](int value) {
    // 处理年龄改变
});
```

### 2. Qt 高级布局管理

**文件**：`qt_basics/06_advanced_layouts.cpp`（约250行）

**核心内容**：

#### QGridLayout（网格布局）
- **核心功能**：按行列排列控件，支持跨行跨列
- **关键方法**：
  - `addWidget(widget, row, col)`：添加控件到指定位置
  - `addWidget(widget, row, col, rowSpan, colSpan)`：跨行跨列
  - `setSpacing(int)`：设置间距
  - `setContentsMargins()`：设置边距
- **适用场景**：计算器、表格、网格布局
- **示例代码**：
```cpp
QGridLayout *grid = new QGridLayout();

// 显示屏（跨4列）
grid->addWidget(display, 0, 0, 1, 4);

// 按钮（4x4网格）
grid->addWidget(btn7, 1, 0);
grid->addWidget(btn8, 1, 1);
grid->addWidget(btn9, 1, 2);
grid->addWidget(btnDiv, 1, 3);
// ...

grid->setSpacing(5);
```

#### QFormLayout（表单布局）
- **核心功能**：专门用于表单布局，自动对齐标签和控件
- **关键方法**：
  - `addRow(label, widget)`：添加标签-控件对
  - `addRow(labelText, widget)`：添加文本-控件对
  - `setLabelAlignment()`：设置标签对齐方式
- **适用场景**：设置对话框、注册表单、信息输入
- **示例代码**：
```cpp
QFormLayout *form = new QFormLayout();
form->addRow("姓名：", new QLineEdit());
form->addRow("年龄：", new QSpinBox());
form->addRow("性别：", new QComboBox());
form->setLabelAlignment(Qt::AlignRight);
```

#### 布局嵌套技巧
- **核心思想**：组合使用多种布局，实现复杂界面
- **常见模式**：
  - 主垂直布局 + 水平子布局（顶部工具栏 + 底部按钮）
  - 主水平布局 + 垂直子布局（左右分栏）
  - 网格布局 + 表单布局（复杂表单）
- **示例代码**：
```cpp
QVBoxLayout *mainLayout = new QVBoxLayout();

// 顶部：水平布局
QHBoxLayout *topLayout = new QHBoxLayout();
topLayout->addWidget(title);
topLayout->addStretch();
topLayout->addWidget(closeBtn);
mainLayout->addLayout(topLayout);

// 中间：表单布局
QFormLayout *formLayout = new QFormLayout();
formLayout->addRow("姓名：", nameEdit);
mainLayout->addLayout(formLayout);

// 底部：水平布局
QHBoxLayout *bottomLayout = new QHBoxLayout();
bottomLayout->addStretch();
bottomLayout->addWidget(submitBtn);
mainLayout->addLayout(bottomLayout);
```

### 3. 用户注册表单实战

**文件**：`qt_basics/07_registration_form.cpp`（约300行）

**核心内容**：

#### 表单设计
- **8个表单字段**：
  1. 姓名（QLineEdit）
  2. 性别（QRadioButton + QButtonGroup）
  3. 年龄（QSpinBox）
  4. 城市（QComboBox）
  5. 邮箱（QLineEdit）
  6. 电话（QLineEdit）
  7. 爱好（QCheckBox x 5）
  8. 简介（QTextEdit）

- **布局结构**：
  - 主布局：QVBoxLayout
  - 表单部分：QFormLayout
  - 爱好部分：QGroupBox + QVBoxLayout
  - 按钮部分：QHBoxLayout

#### 表单验证
- **验证规则**：
  1. 姓名：非空，长度2-20字符
  2. 年龄：范围18-100
  3. 邮箱：包含@和.
  4. 电话：11位数字
  5. 爱好：至少选择一项
  6. 简介：长度50-200字

- **验证代码**：
```cpp
void onSubmit()
{
    // 1. 验证姓名
    QString name = m_nameEdit->text().trimmed();
    if (name.isEmpty()) {
        QMessageBox::warning(this, "验证失败", "请输入姓名！");
        m_nameEdit->setFocus();
        return;
    }

    // 2. 验证邮箱
    QString email = m_emailEdit->text().trimmed();
    if (!email.contains("@") || !email.contains(".")) {
        QMessageBox::warning(this, "验证失败", "邮箱格式不正确！");
        m_emailEdit->setFocus();
        return;
    }

    // 3. 验证爱好
    QStringList hobbies;
    if (m_hobby1->isChecked()) hobbies << "读书";
    if (m_hobby2->isChecked()) hobbies << "运动";
    
    if (hobbies.isEmpty()) {
        QMessageBox::warning(this, "验证失败", "请至少选择一个爱好！");
        return;
    }

    // 验证通过，显示信息
    QMessageBox::information(this, "注册成功", info);
}
```

#### 用户反馈
- **验证失败**：使用 `QMessageBox::warning()` 显示错误信息
- **提交成功**：使用 `QMessageBox::information()` 显示注册信息
- **焦点管理**：验证失败后自动将焦点设置到错误字段

## 🎯 重点知识总结

### 1. 控件选择指南

| 需求 | 推荐控件 | 说明 |
|------|---------|------|
| 单选（预定义选项） | QComboBox | 节省空间 |
| 单选（少量选项） | QRadioButton | 直观清晰 |
| 多选 | QCheckBox | 允许多选 |
| 数字输入 | QSpinBox | 限制范围 |
| 文本输入 | QLineEdit | 单行文本 |
| 长文本输入 | QTextEdit | 多行文本 |

### 2. 布局选择指南

| 场景 | 推荐布局 | 说明 |
|------|---------|------|
| 简单列表 | QVBoxLayout | 垂直排列 |
| 工具栏 | QHBoxLayout | 水平排列 |
| 计算器 | QGridLayout | 网格排列 |
| 表单 | QFormLayout | 标签-控件对 |
| 复杂界面 | 嵌套布局 | 组合使用 |

### 3. 常用信号对比

| 控件 | 常用信号 | 参数 | 触发时机 |
|-----|---------|------|---------|
| QComboBox | currentIndexChanged(int) | 新索引 | 选项改变 |
| QCheckBox | stateChanged(int) | 新状态 | 状态改变 |
| QRadioButton | toggled(bool) | 是否选中 | 状态切换 |
| QSpinBox | valueChanged(int) | 新值 | 值改变 |

### 4. 表单验证最佳实践

1. **即时反馈**：验证失败立即提示
2. **焦点管理**：验证失败后将焦点设置到错误字段
3. **清晰提示**：错误信息要具体明确
4. **友好体验**：使用 QMessageBox 提供反馈
5. **数据清理**：使用 `trimmed()` 去除首尾空格
