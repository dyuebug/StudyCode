## 📖 学到的知识点

### 核心知识点总结

1. **STL 容器与算法体系**
   - 容器选型决策树：vector（默认）、list（频繁插入删除）、map（键值对）、set（去重）
   - 迭代器作为容器和算法的桥梁
   - 常用算法：sort、find、find_if、count、transform、for_each
   - 容器+算法+Lambda 的组合模式

2. **Lambda 表达式与函数式编程**
   - Lambda 语法：`[捕获列表](参数) { 函数体 }`
   - 捕获方式：值捕获 `[=]`、引用捕获 `[&]`、混合捕获
   - 配合 STL 算法使用，简化代码逻辑
   - 替代传统函数对象，更灵活

3. **模板编程与泛型**
   - 函数模板：`template<typename T>`，编译期类型推导
   - 类模板：实现通用容器和算法
   - STL 就是模板编程的典型应用
   - 类型安全的泛型编程

4. **智能指针与 RAII**
   - unique_ptr：独占所有权，零开销
   - shared_ptr：共享所有权，引用计数
   - weak_ptr：打破循环引用
   - RAII 原则：构造获取资源，析构释放资源
   - 自动内存管理，避免内存泄漏

5. **移动语义与性能优化**
   - 左值 vs 右值：有名字 vs 临时对象
   - 右值引用（&&）：绑定到右值
   - 移动构造/赋值：转移所有权，避免深拷贝
   - std::move：将左值转换为右值引用
   - 五法则：析构、拷贝构造/赋值、移动构造/赋值
   - 性能提升：移动比拷贝快100倍以上

6. **现代 C++ 语法糖**
   - auto：自动类型推导，简化代码
   - 范围 for：`for (const auto& x : container)`
   - nullptr：类型安全的空指针
   - 统一初始化：`vector<int> v{1, 2, 3}`
   - constexpr：编译期常量

7. **综合项目：资源管理器**
   - 面向对象：继承、多态、虚函数
   - 智能指针：shared_ptr 自动管理资源生命周期
   - STL 容器：map 存储资源映射
   - Lambda 表达式：实现灵活的资源过滤
   - 模板编程：泛型 filter 函数
   - 移动语义：优化资源转移性能
   - 设计模式：RAII、工厂模式、策略模式

8. **知识点关联体系**
   - 容器 + 迭代器 + 算法 = STL 三大组件
   - Lambda 让算法使用更灵活
   - 模板实现泛型编程
   - 智能指针自动管理内存
   - 移动语义大幅提升性能
   - 现代语法让代码更简洁安全

### 💡 最佳实践总结

**容器选择**：
- 默认使用 vector（性能最好）
- 频繁插入/删除用 list
- 键值对映射用 map
- 去重用 set

**迭代器使用**：
- 优先使用范围 for 循环
- 只读遍历用 const_iterator
- 使用 auto 简化类型

**算法使用**：
- 配合 Lambda 表达式
- 优先使用标准算法而不是手写循环
- 注意算法的前提条件

**智能指针**：
- 默认使用 unique_ptr
- 需要共享用 shared_ptr
- 使用 make_unique/make_shared
- 避免裸指针和 new/delete

**移动语义**：
- 返回大对象时利用移动
- 容器操作使用 std::move
- 移动函数标记 noexcept
- 移动后不再使用源对象

**现代语法**：
- 遍历容器用 const auto&
- 使用 nullptr 替代 NULL
- 使用 {} 初始化
- 使用 auto 简化类型声明
