# coroutine

## 定位

C++20 协程学习材料，覆盖 Promise、`coroutine_handle`、Awaitable、Generator、Task、协程 Reactor 和调度器。

## 内容范围

- `01`-`03`：协程基础、实现机制和 Reactor 结合
- `04`-`07`：调度器、优先级、公平调度和高级策略
- `08`：协程池概念演示
- `09`：超时控制概念演示
- `10`：取消机制概念演示

## 状态与限制

| 项目 | 内容 |
|---|---|
| 状态 | 概念材料完成，真实实现工程化中 |
| 平台 | 主机 C++20；工具链支持需要单独验证 |
| 标准 | C++20 |
| 构建 | 当前为单文件或文档示例，统一 CMake 待补充 |
| 测试 | 缺少协程帧、异常、取消、超时和重复 resume 的生命周期测试 |
| 限制 | `08`-`10` 包含简化实现或概念说明，不能默认视为完整协程池/超时/取消框架 |

## 阅读和验证建议

先验证编译器是否支持 C++20 Coroutines，再阅读 `01`-`03`。涉及 `coroutine_handle` 的代码必须关注 `resume`、`done`、`destroy` 的所有权和异常路径。
