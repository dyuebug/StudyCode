# embedded

## 定位

嵌入式 C++ 原理和驱动设计学习材料。当前目录默认是主机上的概念模拟，不产生可直接烧录的固件。

## 内容范围

- 嵌入式 C++ 特性、内存布局和位操作
- 中断、环形缓冲区、HAL、RTOS 和状态机
- GPIO、UART、SPI、I2C、ADC、PWM、定时器
- Bootloader、OTA、CAN、Modbus 和调试技术

## 状态与限制

| 项目 | 内容 |
|---|---|
| 状态 | 主机模拟学习材料完成 |
| 平台 | 主机 C++；STM32、Arduino、FreeRTOS 等是概念目标，不代表已验证硬件 |
| 标准 | 主要为 C++17，按文件头说明为准 |
| 构建 | 使用主机编译器的单文件构建；无交叉编译工程 |
| 测试 | 暂无真实硬件测试；暂无统一自动化测试 |
| 限制 | 缺少目标芯片、启动文件、链接脚本、HAL/SDK、烧录和板级验证 |

## 使用边界

学习时应区分“主机模拟”和“真实固件实现”。模拟代码用于理解接口和状态机，不能直接替代芯片寄存器、启动代码、ISR 配置或生产级驱动。
