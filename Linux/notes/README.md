# 学习笔记

用于保存概念笔记、源码阅读笔记、机制对比和问题复盘。

建议按以下结构记录：

```text
主题
-> 前置概念
-> 源码入口
-> 数据流或调用链
-> 正常路径
-> 异常路径
-> 当前验证状态
-> 待解决问题
```

源码笔记必须注明文件路径、入口函数、编译产物和实际验证范围。
