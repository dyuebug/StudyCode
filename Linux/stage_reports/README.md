# 阶段复盘

在 Day 7、Day 14 或一个主线阶段结束时创建：

```text
YYYY-MM-DD_阶段复盘.md
```

复盘重点：建立了什么主线、哪些内容只是见过、哪些代码能看懂、哪些代码敢改、下一阶段继续主线还是进入专题。

## 命名与写入规则

- 文件名用复盘**落笔日**，不用覆盖周期的起始日（`2026-10-27_阶段复盘.md` 覆盖 Day15–Day31 这三个日历日）。
- 复盘一经写入不改历史结论；新增一段就单列 `## N. <日期> 追加`，并在文首把覆盖范围同步扩到最大值——
  不把旧结论改写成"当时就料到了"。
- 复盘里出现的数量（实验数、判据数、时长）必须能在日志、周报或产物里对上；对不上就标注"存疑，未回查"。
