# Linux_WEIDS Obsidian 学习导航入口

> [!info] 使用方式
> 建议在 Obsidian 中将 `Linux/Linux_WEIDS` 打开为仓库根目录。这样本导航中的双链可以直接连接学习主线、已有学习计划、每日任务和源码索引。

## 从这里开始

- [[Obsidian学习导航/00_学习主页|学习主页]]：当天学习、记录和复盘的唯一入口。
- [[Obsidian学习导航/10_资料库总索引|资料库总索引]]：查看资料库的分类、平台和使用边界。
- [[Obsidian学习导航/11_新手入门路径|新手入门路径]]：从 STM32F103、外设和 FreeRTOS 开始。
- [[Obsidian学习导航/12_进阶驱动路径|进阶驱动路径]]：进入 Linux 应用、内核模块、设备树和总线驱动。
- [[Obsidian学习导航/13_精通与BSP路径|精通与 BSP 路径]]：学习镜像、启动、板级适配和异构多核。
- [[Obsidian学习导航/14_航空背景项目映射|航空背景项目映射]]：将已有航空 C 软件经验转化为公开、独立、可验证的嵌入式作品。
- [[Obsidian学习导航/16_第三方与参考资料边界|第三方与参考资料边界]]：区分主线学习材料、上游组件、测试依赖和归档资料。
