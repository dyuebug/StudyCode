
阅读目标不是背代码，而是回答：

1. 数据从何处产生？
2. 中断、定时或总线事务如何把数据交给驱动？
3. 驱动何时唤醒应用？
4. 异常、超时或无设备时如何处理？


## 推荐现代化改造练习

课程源码适合解释机制，但部分采用较老内核 API 或教学级简化。完成原例程后，选择一个 GPIO 或 I2C 示例进行改造：

| 课程常见写法 | 改造方向 |
| --- | --- |
| 手动 `ioremap()` + 寄存器读写 | `gpiod_get()` / `devm_gpiod_get()` |
| 全局设备状态 | 每设备私有结构 + `platform_set_drvdata()` |
| 手工资源释放 | `devm_*` 生命周期管理 |
| `register_chrdev()` | `alloc_chrdev_region()` + `cdev_add()` |
| 固定忙等待 `mdelay()` | 合理使用可睡眠等待或完成量 |
| 不检查用户态 / 总线返回值 | 检查 `copy_*_user()`、`i2c_transfer()`、`spi_*()` 返回值 |

> [!warning] 版本边界
> 资料中的外部模块 Makefile 可见 Linux 4.4 / 4.9.88 内核路径。应先在课程对应内核上理解和复现；如果迁移到较新内核，需要查对应 API 的当前文档，不能假设课程代码无修改即可编译。
