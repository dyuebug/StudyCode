# 新手入门路径：从 C 到可验证的嵌入式基础

> [!goal] 本阶段目标
> 不把自己当作“完全不会 C 的新人”，而是将已有 C 语言与航空软件的状态机、接口、验证经验，落到真实硬件、外设时序、RTOS 调度和开发板调试上。

## 入门完成标准

进入 [[12_进阶驱动路径|进阶驱动路径]] 前，应至少满足：

- [ ] 能从工程文件打开、构建、烧录一个 STM32F103 工程。
- [ ] 能从原理图、数据手册和代码中确认一个外设的引脚、时钟、地址或时序。
- [ ] 能解释 GPIO、UART、中断、DMA、I2C、SPI 的数据流。
- [ ] 能创建 FreeRTOS 任务，并正确选择队列、信号量或互斥锁。
- [ ] 能用串口日志、LED、示波器或逻辑分析仪证明程序实际运行。
- [ ] 至少完成一个“正常路径 + 异常路径”的小实验记录。

### 推荐 API / 工程顺序

```text

```

## 新手阶段常见误区

- 只通过 HAL 调用验证“能亮”，不看原理图和寄存器关系。
- 在 ISR 内打印、延时或做复杂逻辑。
- 把队列、信号量和互斥锁混为同一种“线程通信工具”。
- 不记录工程路径、工具链、串口参数和验证现象。
- 过早读 FreeRTOS `tasks.c`，却没有观察到任务、阻塞和唤醒行为。
