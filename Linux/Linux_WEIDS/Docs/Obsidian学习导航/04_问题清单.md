## 固定排查框架

### MCU 工程 / 下载异常

```text
工程路径与芯片型号
-> Device Pack 与下载器配置
-> SWD 连线与供电
-> 时钟、引脚、外设初始化
-> 业务逻辑
```

### FreeRTOS 任务异常

```text
任务是否创建
-> 调度器是否启动
-> 是否被阻塞或被高优先级任务占满 CPU
-> 栈空间是否足够
-> 队列 / 信号量与 ISR API 是否正确
```

### Linux 模块或驱动异常

```text
内核与模块版本
-> dmesg 日志
-> Makefile / Kbuild
-> 设备树节点是否生效
-> compatible 与匹配表
-> probe() 是否被调用
-> 设备节点和测试应用路径
```
