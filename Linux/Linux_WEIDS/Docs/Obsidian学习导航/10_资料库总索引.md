> [!summary] 资料库定位
> `Linux_WEIDS` 是一个多平台、跨层次的嵌入式学习资料库，不是单一 SDK 或可从顶层一次构建的 BSP 工程。主线平台是 **STM32F103、i.MX6ULL / i.MX6ULL-QEMU、STM32MP157**；主线技术是 **MCU 外设 → RTOS → Linux 应用 → Linux 驱动 → Device Tree / BSP → 异构多核通信**。

## 如何使用这个索引

- 以 [[11_新手入门路径|新手入门路径]] 作为首次执行入口，不按磁盘目录顺序学习。
- 完成 MCU 与 RTOS 基础后，进入 [[12_进阶驱动路径|进阶驱动路径]]，严格沿 Linux 驱动的 14 天主线前进。
- 只有完成“设备树 → 驱动 → 测试应用”的最小闭环后，才开始 [[13_精通与BSP路径|精通与 BSP 路径]]。
- 以 [[14_航空背景项目映射|航空背景项目映射]] 将学习成果汇总为可展示、可验证、且不泄密的个人项目。
- 碰到上游组件、测试依赖或归档资料时，先看 [[16_第三方与参考资料边界|第三方与参考资料边界]]，避免偏离当前主线。

## 平台地图

```text
STM32F103 / Cortex-M3
  -> 裸机、HAL、FreeRTOS、RT-Thread
  -> GPIO / UART / I2C / SPI / DMA / 中断

NXP i.MX6ULL / i.MX6ULL-QEMU
  -> Linux 用户态、Kbuild 外部模块、字符设备
  -> platform、设备树、GPIO、I2C、SPI、Framebuffer

ST STM32MP157
  -> Cortex-A7 Linux + Cortex-M4 固件
  -> Device Tree、RemoteProc、OpenAMP、RPMsg、IPCC

AM335X / RK3288 / RK3399
  -> 兼容板卡资料与交叉编译示例
  -> 作为平台迁移对照，不作为第一主线
```

## 资料使用边界

> [!warning] 不要混淆不同层次
> - STM32 HAL / CubeMX 工程不是 Linux 驱动；它训练的是外设、时序、寄存器和中断意识。
> - FreeRTOS API 不能与 Linux 内核 API 机械一一对应；它训练的是任务、同步、资源和实时意识。
> - Linux 用户态应用不是内核模块；`main()`、`printf()` 与 `module_init()`、`printk()` 属于不同执行层。
> - 课程里的外部模块示例多以 Linux 4.4 / 4.9 时代 API 为背景；理解机制后，需要主动对照新内核的资源管理和 descriptor API。
> - 量产、裸机启动、RemoteProc/RPMsg 属于后期系统主题，不能跳过外设、RTOS、字符设备和设备树直接进入。
