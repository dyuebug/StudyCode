### 外部模块 Makefile 的核心模式

```makefile
make -C $(KERN_DIR) M=$(PWD) modules
obj-m += module_name.o
```

必须先确认：

- `KERN_DIR` 对应目标内核且已配置、已构建。
- `ARCH` 与目标架构一致。
- `CROSS_COMPILE` 对应正确工具链。
- 生成的 `.ko` 与运行时内核版本、配置和符号版本匹配。

### 这组源码的阅读顺序

```text
先读 FreeRTOS 最小任务工程
→ 再读 tasks.c 中任务创建、阻塞和调度的局部实现
→ 再读 queue.c，理解任务间通信与 ISR 投递
→ 最后读 FreeRTOS+TCP 的 IP 任务，观察内核机制如何支撑协议栈

Linux 应用侧同步进行：
select 输入示例 → pthread 条件变量示例 → UART termios 示例 → 驱动 poll/epoll
```
