 # 14天学习计划

 ## 使用说明

 - 先配合 `01_学习总路线.md` 使用
 - 每天优先看 `doc_pic/*.md` 或 `doc_pic/*.pdf`
 - 再进入 `source/` 看代码
 - 每天至少写 3 条笔记

 ---

 ## Day 1：建立整体认知

 学习目录：

 - `01_单片机程序和Linux程序从上层到底层的完整比较`

 重点：

 - 理解单片机程序和 Linux 程序的差异
 - 知道应用程序、驱动、内核的大致层次关系
 - 阅读 `source/01_hello_app/hello.c`

 产出：

 - 写一页笔记：单片机开发和 Linux 开发的区别

 ## Day 2：认识第一个驱动

 学习目录：

 - `01_单片机程序和Linux程序从上层到底层的完整比较/source/01_hello_drv`
 - `02_彻底分析第1个驱动程序/doc_pic`

 重点：

 - 理解驱动没有 `main()`
 - 理解 `module_init`、`module_exit`
 - 知道驱动如何加载和卸载

 产出：

 - 画流程：编译 -> insmod -> dmesg -> rmmod

 ## Day 3：彻底分析第一个驱动

 学习目录：

 - `02_彻底分析第1个驱动程序/source`

 重点：

 - 先看 `Makefile`
 - 再看驱动主文件和测试程序
 - 理解设备文件和测试程序的关系

 产出：

 - 整理“第一个驱动最小知识点清单”

 ## Day 4：辅助信息与地址空间

 学习目录：

 - `03_驱动辅助信息及地址空间概念`
 - `04_板子上的第1个驱动程序_实际操作及编译过程/doc_pic`

 重点：

 - 用户空间和内核空间
 - 驱动为什么必须运行在内核里
 - 地址空间概念

 产出：

 - 做一张对比表：单片机 / Linux应用 / Linux驱动

 ## Day 5：开发板上的第一个驱动

 学习目录：

 - `04_板子上的第1个驱动程序_实际操作及编译过程/source`

 重点：

 - 交叉编译流程
 - 模块如何放到板子上
 - 板子上如何测试驱动

 产出：

 - 写“板子上跑驱动的完整步骤”

 ## Day 6：分离思想与驱动模型入门

 学习目录：

 - `05_分离的设计思想与总线设备驱动模型`

 重点：

 - 理解分离思想
 - 认识 device / driver / bus
 - 知道为什么不能把硬件信息都写死在驱动里

 产出：

 - 写“什么是 device/driver 分离”

 ## Day 7：总线设备驱动模型深化

 学习目录：

 - `06_总线设备驱动模型彻底分析`

 重点：

 - probe / remove
 - platform_device / platform_driver
 - 匹配机制

 产出：

 - 画结构图：硬件信息 -> device -> bus -> driver -> probe

 ## Day 8：设备树入门

 学习目录：

 - `07_设备树入门`

 重点：

 - 认识 `.dts`
 - 理解 `compatible`
 - 知道设备树如何描述硬件

 产出：

 - 写“设备树的作用，用 5 句话解释”

 ## Day 9：Pinctrl 和 GPIO

 学习目录：

 - `08_设备树示例_Pinctrl和GPIO`
 - `09_Pinctrl和GPIO`

 重点：

 - pinctrl 的作用
 - gpio 的输入输出
 - 它们和设备树如何配合

 产出：

 - 整理表格：设备树 / pinctrl / gpio 的作用和使用场景

 ## Day 10：APP 与驱动更多交互方式

 学习目录：

 - `10_应用程序和驱动程序的更多交互方式`

 重点：

 - 阻塞和非阻塞
 - 休眠和唤醒
 - poll/select
 - 异步通知
 - ioctl

 产出：

 - 写“用户程序和驱动交互的 5 种方式”

 ## Day 11：总结驱动机制

 学习目录：

 - `11_用一个程序总结驱动机制`
 - `12_驱动开发基础答疑`

 重点：

 - 用整体视角复习前面 10 天的内容
 - 查漏补缺
 - 把零散知识串起来

 产出：

 - 写“到目前为止，我理解的 Linux 驱动主线”

 ## Day 12：进入第一个实战专题

 推荐二选一：

 - `13~16`：SR501
 - `18~20`：DHT11

 重点：

 - 数据从哪里来
 - 事件如何到达驱动
 - 为什么会有多种实现方式

 产出：

 - 画出一个设备的数据流

 ## Day 13：总线或子系统专题

 推荐二选一：

 - `24~25`：I2C + AT24C02
 - `22~23`：HS0038 + input 子系统

 重点：

 - 理解普通字符驱动之外的组织方式
 - 对总线驱动或 input 子系统建立初步认识

 产出：

 - 写“它和普通字符驱动相比，多了什么”

 ## Day 14：SPI / Framebuffer 预览与总复盘

 学习目录：

 - `27_SPI设备驱动开发1_OLED屏幕`
 - `28_SPI设备驱动开发1_OLED屏幕硬件操作`
 - `29_Framebuffer驱动程序框架`
 - `30_使用Framebuffer改造SPI_OLED驱动`

 重点：

 - 知道 SPI 设备驱动大概长什么样
 - 知道为什么显示设备会进入 framebuffer 框架
 - 对后续深入方向建立地图

 产出：

 - 写“14天后，我对嵌入式 Linux 驱动的整体认识”

 ---

 ## 每天固定动作

 1. 先看讲义
 2. 再看代码
 3. 写 3 到 5 条笔记
 4. 尽量动手跑一遍流程

 ## 每周复盘建议

 - 第 7 天晚上复盘 Day1~Day7
 - 第 14 天晚上复盘整个主线
 - 优先检查自己是否真的理解：应用 / 驱动 / 内核 / 设备树 / 总线模型
