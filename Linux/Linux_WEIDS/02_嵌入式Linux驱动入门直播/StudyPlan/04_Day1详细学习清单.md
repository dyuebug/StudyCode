 ### 第四步：看第一个应用程序

 阅读：

 - `01_单片机程序和Linux程序从上层到底层的完整比较/source/01_hello_app/hello.c`

 重点关注：

 - `#include <stdio.h>` 说明它使用的是用户态标准库
 - `main()` 是应用程序入口
 - `printf()` 说明它先是一个普通 Linux 应用，而不是驱动

 你不需要深究每一行，只需要先建立感觉：

 - Linux 下最简单的程序是怎样的
 - 应用程序和后面要学的驱动程序，写法会很不一样

 ## 4. 今天一定要搞懂的 3 个问题

 ### 问题 1：单片机程序和 Linux 程序最大的差异是什么？

 提示方向：

 - 单片机程序更接近直接操作硬件
 - Linux 程序往往先运行在操作系统提供的环境中

 ### 问题 2：为什么课程一开始先讲应用程序，而不是直接讲驱动？

 提示方向：

 - 先建立用户态视角
 - 再逐步进入内核态和驱动层

 ### 问题 3：hello.c 这个程序体现了什么？

 提示方向：

 - 它是最小 Linux 应用程序
 - 它帮助你先熟悉 Linux 程序的基本结构
