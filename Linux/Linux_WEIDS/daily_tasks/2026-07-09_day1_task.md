## 4. 必看源码目录

```text
02_嵌入式Linux驱动入门直播/01_单片机程序和Linux程序从上层到底层的完整比较/source/01_hello_app
```

重点文件：

```text
hello.c
```

阅读时重点观察：

- `#include <stdio.h>`：说明它使用 C 标准库。
- `main(int argc, char **argv)`：说明它是普通应用程序入口。
- `printf()`：说明它通过用户态标准输出打印内容。
- 没有 `module_init`、`module_exit`：说明它不是 Linux 内核模块。
