## 2. 学到的核心知识

### 模块没有 `main()`

内核模块的入口由 `module_init()` 注册，内核在加载时调用；退出由 `module_exit()` 注册，卸载时调用。模块没有进程上下文，也没有 `argv`。

### `printk` 与 `dmesg`

`printk` 写内核环形缓冲区，级别由 `KERN_*` 前缀决定；`dmesg` 只是读取该缓冲区。日志级别缺失时使用默认级别，容易被过滤掉。

### 加载路径

```text
insmod/finit_module
  -> 内核读取 .ko（ELF 可重定位目标文件）
  -> 校验 vermagic 与符号
  -> 执行 module_init 注册的函数
  -> 模块进入已加载列表
```

## 4. 遇到的问题与修正

### 问题 1：`init_module` 返回 `EFAULT`

**原因**：把 .ko 路径当作用户缓冲区传给 `init_module`，内核无法从该地址读取。

**修正**：改用 `finit_module`，由内核直接按文件描述符读取模块内容。

### 问题 2：initramfs 中 `/proc`、`/sys` 不存在

**原因**：打包时只复制了文件和 `init`，没有建挂载点。

**修正**：在 rootfs 中预建 `proc`、`sys`、`dev` 目录后再挂载。
