## 2. 学到的核心知识

### 两段式随机读

```c
struct i2c_msg msgs[2] = {
    { .addr = c->addr, .flags = 0,        .len = 1,   .buf = &mem_addr },
    { .addr = c->addr, .flags = I2C_M_RD, .len = len, .buf = buf      },
};
ret = i2c_transfer(c->adapter, msgs, 2);
```

返回的是**成功传输的消息数**，不是字节数。

### 写周期

AT24C02 每次写后需要约 5ms 内部写周期，期间不响应，立即读会拿到旧值。

## 4. 遇到的问题与修正

### 问题 1：`implicit declaration of platform_set_drvdata`

**原因**：I2C 设备不该用 platform 的 drvdata API，语义和原型都不对。

**修正**：改为 `i2c_set_clientdata` / `i2c_get_clientdata`。

### 问题 2：`.remove` 签名不兼容

**原因**：6.11 起 `i2c_driver.remove` 返回 `void`。

**修正**：加 `LINUX_VERSION_CODE` 分支。
