## 2. 学到的核心知识

### 设备号

主设备号定位驱动，次设备号定位同一驱动下的实例。动态分配避免与已有驱动冲突，代价是应用侧必须从 `/proc/devices` 读取后才能 `mknod`。

### 调用链

```text
应用 open("/dev/hello_chrdev")
  -> 系统调用进入 VFS
  -> VFS 按 inode 的设备号找到 cdev
  -> 调用 file_operations.open
```

## 4. 遇到的问题与修正

### 问题 1：`mknod` 时不知道该填什么主设备号

**原因**：动态分配的主设备号只存在于内核中。

**修正**：从 `/proc/devices` 解析出 `hello_chrdev` 对应的号再建节点。
