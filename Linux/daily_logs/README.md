# 每日学习日志

文件名：`YYYY-MM-DD_第X天_日志.md`

## 生成方式（2026-10-28 起）

**自动生成，无需触发。** 当日出现可核验产物时（实验 `logs/`、测试读数、构建结果、基准数据，
或包含上述产物的提交），Claude 主动生成当日日志；用户说"学习结束"时立即生成，不重复建第二份。

**不生成的情况**：当日只有纯文档整理、索引同步或格式修订。

规则原文见 `CLAUDE.md` §8.2。

## 内容要求

日志记录实际完成内容、学习时长、运行环境、命令、输出、问题定位过程、未验证事项和下一次计划。
不能把任务清单直接当作完成证明——完成判定以产物为准（`CLAUDE.md` §1.1、§8.2）。

每份日志必须有 `## 数据来源` 一节，逐条列出读数来自哪个文件或命令。

时长优先记开始/结束时间戳；无计时时标"推定"并写明估算依据。
