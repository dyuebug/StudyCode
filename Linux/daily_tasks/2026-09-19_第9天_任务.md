## 5. 动手与观察

**无板必做**：给资源卡标“源码已知 / 手册待确认 / 实测待确认”，不能靠猜补齐引脚和电压。比较旧整数 GPIO API 与 descriptor API 的获取与释放方式。

**条件实验**：仅在确认板卡修订、接线电压、占用情况与有效电平后执行。断电接线，不试探不明引脚；先读输入或安全 LED，不连接工作设备/真实控制系统。

构建、加载和退出按 [环境与验证指南](../experiments/驱动入门_环境与验证指南.md) 执行。

**观察点**：设备资源是否取得、引脚复用与逻辑电平、IRQ 是否来自该引脚、释放后有无残留回调。没有仪器/板卡时不编造波形或电平。

## 6. 复盘与故障排查

1. GPIO 读写正确前，为什么仍要检查 pinctrl 和硬件连接？
2. 低有效 GPIO 的逻辑 `1` 是否必然是物理高电平？
3. 来自可睡眠控制器的 GPIO 为什么不能在任意上下文访问？

先核对原理图、电压与资源占用，再查 DTS、复用、获取返回值和中断映射。不要用随意改 GPIO 数字替代定位。
