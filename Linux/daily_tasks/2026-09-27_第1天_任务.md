## 3. 建议阅读顺序

### 第一步：阅读总控和路线

先确认今天只做整体认知，不提前阅读 `hello_drv.c`。阅读时只回答：

- 这套资料从哪里开始？
- 应用、驱动、内核和硬件分别处在哪一层？
- 后续为什么还要学习设备树、RTOS 和开发板？

### 第二步：阅读 `hello.c`

源码位置：

```text
Linux_WEIDS/02_嵌入式Linux驱动入门直播/01_单片机程序和Linux程序从上层到底层的完整比较/source/01_hello_app/hello.c
```

找到并解释：

- `#include <stdio.h>`：使用标准输入输出接口。
- `main(int argc, char **argv)`：普通 C 应用的入口。
- `printf()`：向用户态标准输出打印。
- `return 0`：报告程序正常结束。

手算执行 `./hello Cursor` 时的参数：

```text
argc = 2
argv[0] = ./hello
argv[1] = Cursor
```

### 第三步：建立分层图

在笔记中画出：

```text
用户态应用（main、C 库）
        ↓ 库函数 / 系统调用
Linux 内核（进程、内存、文件系统、驱动框架）
        ↓ 驱动与硬件接口
外设 / 硬件
```

单片机裸机可以先粗略理解为：启动代码和应用逻辑更接近寄存器/HAL；Linux 应用通常通过内核提供的抽象和驱动访问硬件。
