## 4. 源码阅读任务

### 4.1 最小模块

记录以下观察：

- 是否存在 `main()`。
- 是否存在 `module_init()` / `module_exit()`。
- `init_module()` 和 `cleanup_module()` 分别代表什么时机。
- `MODULE_LICENSE("GPL")` 为什么出现在模块源码中。

### 4.2 `printk` 与模块入口

解释以下调用链：

```text
insmod hello_drv.ko
    -> 内核装载模块
    -> 执行 hello_init()
    -> printk() 写入内核日志
    -> dmesg 查看日志

rmmod hello_drv
    -> 内核卸载模块
    -> 执行 hello_exit()
    -> printk() 写入卸载日志
```

### 4.3 字符设备注册

从 `source/03_test/hello_drv.c` 中找出并记录：

- `struct file_operations` 的用途。
- `register_chrdev()` 注册了什么。
- `major` 保存什么信息。
- `unregister_chrdev()` 为什么必须在退出路径执行。

再从 `source/01_hello_drv/hello_drv.c` 中补充：

- `class_create()` 的作用。
- `device_create()` 的作用。
- 为什么这些动作最终让用户态看到 `/dev/hello`。
- `open/read/write/release` 如何成为用户态操作和驱动之间的接口。
