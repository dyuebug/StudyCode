## 3. 可验证产出

全部在 QEMU 10.2.1 `vexpress-a9` + Linux 7.0.0 上实测，证据见 `tests/qemu-vexpress/RESULT.md`：

| 产出 | 证据 |
| --- | --- |
| `hello_module.ko` 加载/卸载与日志 | `hello_module: init` / `exit` |
| `/dev/hello_chrdev` 调用链 | `open`/`write`/`read` 均返回预期值 |
| `copy_to_user`/`copy_from_user` | 123 → 456 往返一致，短读不越界 |
| `led_drv.ko` 交叉编译与生命周期 | ARM ELF，`/dev/myled` 创建成功 |
| platform 匹配 | `probe matched: hello_platform` |
| 多实例 | `/dev/led0`、`/dev/led1`，minor 0/1，pin 3/5 |

## 5. 风险

- **文档高估覆盖度**：本周每日 README 一度写成"未在本机验证"，与实际 QEMU 结果矛盾；已在本周内纠正。
