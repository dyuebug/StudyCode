# 周报

每周从 `../daily_logs/` 汇总实际记录，创建：

```text
YYYY-WXX.md
```

必须包含学习时长、完成任务、可验证产出、遗留问题、风险和下周不超过三个重点目标。

## 周期口径

- 用**ISO 周**（周一至周日），周期写在文件头部，不从文件名反推。
- 一个 Day 编号不等于一天：2026-10-26 编了 Day16–20 五个单元，2026-10-27 编了 Day21–28 八个单元。
  周报按**日历周**归并，不按 Day 编号归并。
- 学习时长一律标注 `（推定）` 并写明推算依据（任务卡分项估算 / 产物计数）；本机没有计时记录，
  不得写成实测时长（`CLAUDE.md` §8.2）。

## 缺号说明

- **2026-W42（2026-10-12 ～ 10-18）无学习记录，不单独出周报。**
  这一段是学习断档期，`daily_logs/` 没有任何对应日志；`2026-W43.md` 头部已注明同一事实。
  按 `CLAUDE.md` §1.1「事实来源优先级」，不允许为了补齐编号而造一份没有日志支撑的周报。
  若后续需要恢复可信度，只能先补做实验与日志，再回填周报。
